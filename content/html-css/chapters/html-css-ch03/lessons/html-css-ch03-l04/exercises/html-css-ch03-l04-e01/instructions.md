## 安全な学習用Contact Cardを完成する

Profile画像と、個人情報を含まないContact情報を1つのCardへまとめます。

1. Profile Avatarへ内容と目的が分かるaltを書きます。
2. 連絡情報をdivではなくaddressで包みます。
3. Linkのhrefを用意されたHTTPSの練習用URLにします。
4. Link Textへ「学習用Contact Pageを見る」のような行き先の説明を書きます。

本名、個人のEmail Address、電話番号は書きません。mailto:はPreviewで拒否されるため、練習用https Linkを使います。
