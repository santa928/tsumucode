## 安全な学習用Contact Cardを完成する

Profile画像と、個人情報を含まないContact情報を1つのCardへまとめます。

1. Profile Avatarの空のaltへ、Tsumu LearnerのAvatarだと分かる説明を書きます。
2. contactクラスを持つdivの開始Tagと終了Tagをaddressへ変更します。
3. Contact Linkのhrefを#contactからスライド例の外部Contact URLへ変更します。
4. 用意された「学習用Contact Pageを見る」というLink Textは残します。

本名、個人のEmail Address、電話番号は書きません。mailto:はPreviewで拒否されるため、練習用https Linkを使います。
