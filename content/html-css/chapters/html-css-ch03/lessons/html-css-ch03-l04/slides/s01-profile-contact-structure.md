`address`は、近くにある記事やページの作者・組織へ連絡するための情報を表します。単に住所を斜体にするTagではありません。

学習用Profile Cardなら、Profile画像、名前となる見出し、説明、連絡方法を1つのSectionへまとめ、その中の連絡情報をaddressへ入れられます。

```html
<address>
  <a href="HTTPSの練習用URL">学習用Contact Pageを見る</a>
</address>
```

:::practice
prompt: 作者へのContactと、旅行先の住所一覧のどちらがaddressの目的に合うか考えます。
expectedAction: 作者への連絡情報を選び、見た目ではなく役割で説明する
estimatedMinutes: 2
:::

次は、公開練習で本物の個人情報を使わない方法を確認します。
