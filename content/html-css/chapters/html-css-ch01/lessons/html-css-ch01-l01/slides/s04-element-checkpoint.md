演習にはh1とpの開始Tag・終了Tagが用意されています。山かっこの記号は消さず、その間に題名と自己紹介を書きます。これが完成例を見て一部分を埋める`fill`です。

`doctype`、`head`、`meta`、`link`は今回は触りません。ページを支える周辺構造として残し、学ぶ順番が来たら意味を確かめます。

:::practice
prompt: h1には題名、pには自己紹介を入れると声に出し、触らない周辺構造も確認します。
expectedAction: 変更する2箇所と、変更しないhead内の行を区別する
estimatedMinutes: 2
:::

演習では、空欄を上から1つずつ埋めます。
