Attributeは、Elementへ追加情報を渡す書き方です。開始Tagの名前の後へ、`名前="値"`の順で書きます。`lang="ja"`では`lang`が名前、`ja`が値、equals `=`が2つを結びます。値はquote `"`で挟みます。

```html
<html lang="ja"></html>
```

:::practice
prompt: コード例でAttribute名、equals、quoteで囲まれた値を順に指します。
expectedAction: langが名前、jaが値であり、開始Tagへ書くと説明する

:::
