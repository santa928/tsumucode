Gallery全体のRowとColumnを揃えるならGridが向きます。Card内部のButtonを横1列へ並べるならFlexboxが素直です。

どちらが新しいかではなく、制御したい関係で選びます。外側のGrid ItemであるCardが、内側でFlex Containerになることもできます。

:::
