kind: comparison

最初に1列や流動幅のBase Styleを書き、十分な幅ができた地点でMedia Queryから拡張します。小さい画面向けの上書きを後から大量に戻す構成を避けられます。

:::practice
prompt: 390pxで必要なBase LayoutをMedia Queryの外へ書く
expectedAction: 小さい画面の条件を標準として説明する
estimatedMinutes: 2
:::

次の観察または実習で、Viewportごとの最終結果を確認します。
