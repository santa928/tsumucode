concept: responsive-image-boundary

Imageへ`max-width: 100%`と`height: auto`を指定すると、元のAspect Ratioを保ちながらContainerより大きくならないよう縮みます。幅だけ固定して高さも別値にすると歪みます。

:::practice
prompt: 320px Container内へ正方形Imageを比率のまま収める
expectedAction: WidthとHeightが320pxになると答える
estimatedMinutes: 2
:::

次の観察または実習で、Viewportごとの最終結果を確認します。
