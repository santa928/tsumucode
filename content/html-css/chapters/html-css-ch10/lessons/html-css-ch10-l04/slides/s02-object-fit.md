固定したImage Boxでは`object-fit: cover`がBoxを埋め、必要なら端を切り取ります。`contain`は全体を見せます。まずAspect Ratioを保つか、切り取りを許すか目的を決めます。

:::practice
prompt: Avatarの正方形Boxを隙間なく埋める値を選ぶ
expectedAction: object-fit coverを選ぶ
estimatedMinutes: 2
:::
