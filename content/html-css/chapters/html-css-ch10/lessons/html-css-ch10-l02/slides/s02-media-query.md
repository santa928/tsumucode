Mobile Firstでは`@media (min-width: 768px)`の中でRow Layoutなどを追加します。幅768px以上だけに適用され、Source OrderでもBase Styleの後から意図的に上書きします。

:::practice
prompt: 768px以上でflex-directionをrowへ変える
expectedAction: min-width Media Queryを書く
estimatedMinutes: 2
:::

次の観察または実習で、Viewportごとの最終結果を確認します。
