見た目で少しはみ出しているだけでも、横ScrollやCTAの操作阻害につながります。Document全体と主要Containerの`scrollWidth`と`clientWidth`を比較します。

:::practice
prompt: 390pxで固定幅1100pxのContainerが起こす問題を答える
expectedAction: Horizontal Overflowが発生すると答える
estimatedMinutes: 2
:::

次の観察または実習で、Viewportごとの最終結果を確認します。
