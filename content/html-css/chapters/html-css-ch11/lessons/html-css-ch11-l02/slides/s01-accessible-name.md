Accessible Nameは、支援技術がInput、画像、Linkなどを識別するときに使う名前です。見た目にTextがあっても、対象との関係が機械的に伝わらなければ名前にならない場合があります。

:::practice
prompt: 名前が空のInputを読み上げた利用者が困る理由を答える
expectedAction: 入力目的を判断できないと答える
estimatedMinutes: 2
:::

次の観察または実習で、要素ごとの名前の与え方を確認します。
