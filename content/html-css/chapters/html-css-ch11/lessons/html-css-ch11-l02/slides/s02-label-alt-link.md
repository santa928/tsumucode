Form Controlには`label`、意味のある画像には内容を表す`alt`、Linkには移動先を予測できるTextを使います。「こちら」だけではなく、「プロフィール作品を見る」のように単独でも目的が分かる言葉にします。

prompt: Input、意味のある画像、Linkへ名前を与える方法を順に答える

estimatedMinutes: 2
:::
