title: Motionを減らす利用者設定を尊重する
kind: concept
concept: reduced-motion-preference
assets: []
---

`@media (prefers-reduced-motion: reduce)`の中で、装飾Animationを止めるか極めて短くします。情報の理解や操作に必要な状態変化は残し、長い移動や点滅だけを減らします。

:::practice
prompt: reduce指定時に800msの装飾Animationをどう変更するか答える
expectedAction: 停止または極めて短いdurationへ変更すると答える
estimatedMinutes: 2
:::

次の観察または実習で、最終Auditの順番を確認します。
