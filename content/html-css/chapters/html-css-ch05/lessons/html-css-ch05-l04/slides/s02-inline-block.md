`display: inline-block`のLinkは横に並びつつPaddingやmin-heightを持てます。Navigationの操作領域を44px以上へ整えるのに使えます。

大きさだけでなくKeyboard Focusが可能で、Accessible Nameがあることも操作要素の条件です。
