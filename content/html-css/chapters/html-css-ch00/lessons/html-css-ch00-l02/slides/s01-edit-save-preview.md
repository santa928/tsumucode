演習は、1箇所を編集し、保存済みを確認し、Previewで変化を見て、最後に判定する順で進めます。一度に多くを変えないと、予想と違ったときも原因を1箇所へ絞れます。

![編集から判定までの循環](asset:diagram-edit-preview-loop)

:::practice
prompt: 図の矢印をたどり、編集の次から判定までを順番に読みます。
expectedAction: 編集、保存、Preview、判定の4段階を順番どおり説明する
estimatedMinutes: 2
:::

次は、File Tabを切り替えて同じ流れを2回行います。
