## 2つのFileを順番に更新する

File Tabを切り替え、1箇所ずつ「編集 → 保存済み → Preview → 判定」を行います。

1. `index.html`の`h1`にある日本語だけを「つむぎ」へ置き換えます。
2. 保存済みとPreviewの題名を確認します。
3. `styles.css`へ切り替え、用意された`background-color`の値`#ffffff`だけを`#eef6f4`へ置き換えます。
4. 保存済みとPreviewの背景を確認してから判定します。

`doctype`、`head`、`meta`、`link`、`body`などの周りの記号と、CSSのほかの行は今回は触りません。
