## Profile名とAccent Colorを更新する

EditorとPreviewを往復しながら、Profile Cardの内容と見た目を更新します。

1. `index.html`の`.profile-name`へ、自分で選んだ空でない名前を書きます。
2. `styles.css`の`:root`へ`--accent: #0f766e;`を指定します。
3. 保存済みになったらPreviewで名前とButtonの青緑色を確認します。
4. 判定結果を読み、未達なら関係するFileを1箇所だけ直します。

名前は例と同じでなくて構いません。Accent Colorは指定された値を使います。
