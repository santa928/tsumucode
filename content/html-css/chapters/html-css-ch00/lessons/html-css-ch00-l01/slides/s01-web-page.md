Webページ作りでは、内容を表すHTML、見た目を整えるCSS、両方を読んで画面にするBrowserが協力します。最初から全部を覚える必要はありません。どの役割を直しているかを区別できれば、迷ったときに見る場所が分かります。

Browserは保存されたHTMLとCSSを読み直し、Previewへ最新の画面を組み立てます。文章を変えたいときはHTML、色や余白を変えたいときはCSSを見るのが最初の手掛かりです。

![HTMLとCSSをBrowserが画面へ組み立てる流れ](asset:diagram-web-flow)

:::practice
prompt: 図のHTML、CSS、Browserを順に見て、それぞれが受け持つ役割を1つずつ声に出します。
expectedAction: 内容はHTML、見た目はCSS、表示はBrowserと区別する
estimatedMinutes: 2
:::

次は、内容と意味を受け持つHTMLだけに注目して確認します。
