文字を変えるならHTML、背景色を変えるならCSSを選びます。演習では完成した行を新しく覚えて書くのではなく、示された場所の日本語と色の値だけを変更します。

今回は`doctype`、`head`、`meta`、`link`、`class`には触りません。これらはページを支える準備として置いてあり、後のLessonで順番に学びます。

:::practice
prompt: 「題名を変える」「背景色を変える」の2つについて、index.htmlとstyles.cssのどちらを開くか答えます。
expectedAction: 題名はindex.html、背景色はstyles.cssを選ぶ
estimatedMinutes: 2
:::

演習では、1箇所ずつ変更してPreviewを確認します。
