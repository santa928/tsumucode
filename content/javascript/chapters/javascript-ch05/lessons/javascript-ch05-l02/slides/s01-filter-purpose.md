問題一覧からHTMLの問題だけを練習したいとします。元のArrayから必要な要素を選び、新しいArrayへまとめるのが`filter`です。

`map`がすべての要素を別の値へ変換するのに対し、`filter`は要素の形を変えず、条件に合うものだけを残します。
