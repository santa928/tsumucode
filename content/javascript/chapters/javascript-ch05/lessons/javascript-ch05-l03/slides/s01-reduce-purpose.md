3問のpointを合計して総得点を求めたいとします。`reduce`はArrayの要素を先頭から計算へ使い、最終的に1つの値へまとめるmethodです。

`map`は同じ件数のArray、`filter`は選んだArrayを返しました。`reduce`は数値の合計など、Arrayとは別の1つの結果を作れます。
