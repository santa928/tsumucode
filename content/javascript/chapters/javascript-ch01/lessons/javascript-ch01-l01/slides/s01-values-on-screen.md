JavaScriptは、文字や数などの「値」を使って処理します。画面を変える前に、コードが扱う値をConsoleで観察します。

```js
console.log('問題1');
```

Consoleは、コードの結果を上から順に表示する確認場所です。まずは値の種類を見分けます。

:::practice
prompt: コードが扱っている値を探します。
expectedAction: 引用符で囲まれた「問題1」を指す
estimatedMinutes: 1
:::
