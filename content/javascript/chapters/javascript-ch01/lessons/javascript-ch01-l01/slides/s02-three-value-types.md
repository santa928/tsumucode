最初に使う値は3種類です。見た目と意味を分けて読みます。

```js
'問題1'; // 文字列：引用符で囲む
3; // 数値：引用符で囲まない
true; // 真偽値：正しい／違うを表す
```

`'3'`は文字列、`3`は数値です。引用符の有無で種類が変わります。
