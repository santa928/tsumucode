文字の入力や削除で入力欄の値が変わると、inputイベントが届きます。clickの代わりにinputを登録すると、文字が変わるたびにhandlerが呼ばれます。

```html {"label":"HTML", "role":"input"}
<label for="name">名前</label>
<input id="name" />
<p id="message">入力待ち</p>
```

```js {"label":"script.js", "role":"input"}
const field = document.querySelector('#name');
field.addEventListener('input', () => {
  document.querySelector('#message').textContent = field.value;
});
```

```text {"label":"表示の変化", "role":"output"}
入力前: 入力待ち
つむと入力: つむ
```

valueは入力欄が持つ、現在の文字列です。labelは欄の名前、inputは入力欄を表すHTMLです。今回は別の場所へ移動して確定するchangeではなく、入力中に届くinputを使います。

:::practice
prompt: つむの後ろにぎを入力したとき、欄を離れる前にどの文字が表示されますか。
expectedAction: inputが届き、つむぎになると予測する
estimatedMinutes: 1
:::
