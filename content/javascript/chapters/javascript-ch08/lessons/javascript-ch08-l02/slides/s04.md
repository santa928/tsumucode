一度表示できたら、別の文字に変え、最後にすべて消して確かめます。入力を消したときのvalueは、文字を含まない空文字列です。

```html {"label":"HTML", "role":"input"}
<label for="name">名前</label>
<input id="name" />
<p id="message">入力待ち</p>
```

```js {"label":"script.js", "role":"input"}
const field = document.querySelector('#name');
const message = document.querySelector('#message');
field.addEventListener('input', (event) => {
  message.textContent = '名前: ' + event.currentTarget.value;
});
```

```text {"label":"順番に入力した場合", "role":"output"}
春 → 名前: 春
夏 → 名前: 夏
すべて消す → 名前:
```

![入力のたびに現在の値を読み表示へ渡す](asset:input-flow)

今回は空でもそのまま表示します。空欄をエラーにする入力検証は後の単元です。演習でも固定の文字を入れるだけでなく、毎回変わる入力と表示を比べましょう。

:::practice
prompt: すべて消したとき、前に入れた夏が残っていたら何を確かめますか。

:::
