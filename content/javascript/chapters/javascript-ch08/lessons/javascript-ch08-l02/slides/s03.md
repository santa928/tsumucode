handlerの外で読んだ文字列は、その後の入力に合わせて自動では変わりません。読み込んだ直後の空の文字列を使い続ける例を見ます。

```html {"label":"HTML", "role":"input"}
<label for="name">名前</label>
<input id="name" />
<p id="message">入力待ち</p>
```

```js {"label":"script.js（読み取りが早すぎる例）", "role":"input"}
const field = document.querySelector('#name');
const firstValue = field.value;
field.addEventListener('input', () => {
  document.querySelector('#message').textContent = firstValue;
});
```

```text {"label":"春と入力した場合", "role":"output"}
入力欄: 春
表示: 空のまま
```

firstValueは最初に取得した文字列です。現在の入力を表示したいなら、handler内でfield.valueまたはevent.currentTarget.valueを読み直します。constをletに変えるだけでは、読む時点は変わりません。
