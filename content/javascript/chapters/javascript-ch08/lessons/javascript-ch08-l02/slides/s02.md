ブラウザはhandlerを呼ぶとき、出来事の情報をEventというObjectにして渡します。次は引数eventで受け取ります。Objectのpropertyを点で読む書き方を思い出しましょう。

```html {"label":"HTML", "role":"input"}
<label for="name">名前</label>
<input id="name" />
<p id="message">入力待ち</p>
```

```js {"label":"script.js", "role":"input"}
const field = document.querySelector('#name');
const message = document.querySelector('#message');
field.addEventListener('input', (event) => {
  message.textContent = event.currentTarget.value;
});
```

```text {"label":"春と入力した場合", "role":"output"}
event.currentTarget: listenerを登録した入力欄
そのvalue: 春
```

currentTargetは今動いているhandlerの登録先です。この例ではfieldと同じ入力欄なので、続く.valueで今の文字を読めます。eventという引数名は自由ですが、currentTargetとvalueは決まったproperty名です。
