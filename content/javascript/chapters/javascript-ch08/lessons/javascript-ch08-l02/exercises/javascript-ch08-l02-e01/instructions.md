## 入力した題名を読書メモへ映す

今のコードは、読み込み直後の文字を使い続けます。まず本の題名へ文字を入れて、表示と比べましょう。値を読む時点を直して、入力するたびに現在の題名を表示します。

- Preview更新直後は「入力待ち」
- 入力欄を離れる前に「読みたい本: 」に続けて現在の題名を表示
- 別の題名へ変えたときも、すべて消したときも更新
- メモの「メモを残そう」は変更しない

EventのcurrentTargetでも、登録した入力欄の変数でも現在のvalueを読めます。変数名は自由です。Previewで何度か入力を変えてから判定しましょう。「判定する」は初期状態と複数の入力、空へ戻す操作を新しく実行して確認します。
