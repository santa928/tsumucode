名前付きのFunctionもhandlerにできます。Function名だけなら処理そのものを渡します。括弧を付けた呼出しとは違う点を確認しましょう。

```html {"label":"HTML", "role":"input"}
<button id="hello">挨拶する</button>
<p id="message">待っています</p>
```

```js {"label":"script.js", "role":"input"}
function greet() {
  document.querySelector('#message').textContent = 'こんにちは';
}
const button = document.querySelector('#hello');
button.addEventListener('click', greet);
```

```text {"label":"表示の変化", "role":"output"}
登録後: 待っています
クリック後: こんにちは
```

greetを渡すとクリック時に呼ばれます。greet()と書くと登録より先に今呼び、戻り値を渡してしまいます。このgreetはreturnを書いていないので戻り値はundefinedです。Arrowと名前付きFunctionのどちらでも、呼ぶ時点を分けることが大切です。

:::practice
prompt: greet()へ変えると、押す前の表示とaddEventListenerへ渡す値はどうなりますか。
expectedAction: 押す前にこんにちはになり、Functionではなくundefinedを渡すと答える
estimatedMinutes: 1
:::
