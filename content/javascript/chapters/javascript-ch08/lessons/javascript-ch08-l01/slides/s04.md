これまでのtextContentは、読み込み中にすぐ実行されました。操作を待ちたいときは、その変更をhandlerの中へ置きます。

```html {"label":"HTML", "role":"input"}
<button id="show">知らせを読む</button>
<p id="notice">お知らせあり</p>
```

```js {"label":"script.js", "role":"input"}
const show = document.querySelector('#show');
const notice = document.querySelector('#notice');
show.addEventListener('click', () => {
  notice.textContent = '確認しました';
});
```

```text {"label":"確認する二つの状態", "role":"output"}
操作前: お知らせあり
操作後: 確認しました
```

![登録、待機、クリック、表示変更の順序](asset:event-flow)

演習では本を開くボタンを作ります。プレビューを更新した直後と、実際にボタンを押した後を両方見ます。最初から完成後の表示にするだけでは、操作へ反応するコードにはなりません。
