listenerを付けた要素が操作を待ちます。文字を書き換える要素は別でも構いません。次は朝のボタンだけに処理を登録します。

```html {"label":"HTML", "role":"input"}
<button id="morning">朝</button>
<button id="evening">夕方</button>
<p id="message">選んでください</p>
```

```js {"label":"script.js", "role":"input"}
const morning = document.querySelector('#morning');
const message = document.querySelector('#message');
morning.addEventListener('click', () => {
  message.textContent = 'おはよう';
});
```

```text {"label":"最初からそれぞれ押した場合", "role":"output"}
夕方だけ: 選んでください
朝: おはよう
```

morningは登録先、messageは書換先です。夕方のボタンにはhandlerがないので、それを押しても表示は変わりません。selectorとcallbackの中を分けて読みましょう。
