## 送信を止めて読書メモへ登録する

本の題名を入力し、メモへ登録を押してみましょう。今のhandlerは文字を表示しますが、標準の送信を自分では止めていません。コメントの位置へ、受け取ったEventで標準動作を取り消す処理を追加します。

- 最初の表示は「登録待ち」
- 入力するだけでは表示を変えず、登録時に「登録: 」と現在の題名を表示
- 別の題名へ変えて再び登録しても更新
- 「感想も残そう」は変更しない
- Formのsubmit handlerでpreventDefaultを実行する

Previewには誤送信を止める安全装置があるため、取消忘れでも画面は残ります。判定は表示だけでなく、自分のhandlerが標準送信を止めたことも確認します。入力欄でEnterを押す操作も試せます。判定時は新しいPreviewで入力と登録を繰り返します。
