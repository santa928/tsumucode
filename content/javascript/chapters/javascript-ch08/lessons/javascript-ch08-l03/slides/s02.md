送信を始めるとFormへsubmitイベントが届きます。listenerはボタンではなくformへ登録します。ボタン操作と入力欄のEnterを、同じ処理で受け取れます。

```html {"label":"HTML", "role":"input"}
<form id="entry">
  <label for="name">名前</label><input id="name" />
  <button type="submit">確認</button>
</form>
<p id="message">送信待ち</p>
```

```js {"label":"script.js", "role":"input"}
const form = document.querySelector('#entry');
form.addEventListener('submit', () => {
  document.querySelector('#message').textContent = '届いた';
});
```

```text {"label":"確認を押した直後", "role":"output"}
届いた
```

一般のページではhandlerの後もブラウザ標準の送信処理が進み、ページが移動することがあります。このPreviewは誤送信を防ぐため移動を止めています。次で、自分のコードから標準動作を止める方法を学びます。
