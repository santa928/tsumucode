EventのpreventDefault()は、ブラウザがそのイベントで行う標準動作を取り消すメソッドです。メソッドはObjectが持つFunctionです。submitでは標準の送信を止め、画面内で入力を使えます。

```html {"label":"HTML", "role":"input"}
<form id="entry">
  <label for="name">名前</label><input id="name" />
  <button type="submit">確認</button>
</form>
<p id="message">送信待ち</p>
```

```js {"label":"script.js", "role":"input"}
const form = document.querySelector('#entry');
const field = document.querySelector('#name');
form.addEventListener('submit', (event) => {
  event.preventDefault();
  document.querySelector('#message').textContent = '確認: ' + field.value;
});
```

```text {"label":"春を入力して確認", "role":"output"}
確認: 春
```

preventDefaultはhandlerの後続行を止めません。続く行は今のfield.valueを表示します。ここでのevent.currentTargetはFormなので、入力文字はfieldから読みます。入力欄に登録した前の例と区別しましょう。
