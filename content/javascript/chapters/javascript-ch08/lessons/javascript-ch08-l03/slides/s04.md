入力欄を変えただけでは、submitのhandlerは動きません。送信するときに現在のvalueを読みます。前に確認した内容と、まだ入力中の内容を分けて確かめましょう。

```html {"label":"HTML", "role":"input"}
<form id="entry">
  <label for="name">名前</label><input id="name" />
  <button type="submit">確認</button>
</form>
<p id="message">送信待ち</p>
```

```js {"label":"script.js", "role":"input"}
const form = document.querySelector('#entry');
const field = document.querySelector('#name');
form.addEventListener('submit', (event) => {
  event.preventDefault();
  document.querySelector('#message').textContent = '確認: ' + field.value;
});
```

順に操作すると、春を入力しただけでは送信待ちです。確認で「確認: 春」に変わり、夏へ書き換えても表示は同じ。もう一度確認すると「確認: 夏」になります。

![入力の変更だけでは表示を保ち、送信時に取消と現在値の表示を行う](asset:submit-flow)

演習の判定は、表示に加えてhandler内のpreventDefaultも確認します。Preview側の安全装置が止めただけでは合格しません。空欄の扱いは次の単元で学びます。
