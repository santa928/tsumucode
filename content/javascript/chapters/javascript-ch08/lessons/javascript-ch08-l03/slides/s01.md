Formは、入力欄と送信ボタンをまとめるHTMLの要素です。formの内側にinputとbuttonを置きます。buttonのtype="submit"は、そのFormを送信するボタンという意味です。

```html {"label":"HTML", "role":"input"}
<form id="entry">
  <label for="name">名前</label><input id="name" />
  <button type="submit">確認</button>
</form>
<p id="message">送信待ち</p>
```

```text {"label":"画面にできるもの", "role":"output"}
名前の入力欄
確認ボタン
送信待ちの表示
```

この構成では確認を押すほか、名前の欄でEnterを押しても送信を始められます。入力中に毎回変えるinputとは違い、まとまった内容を確認する時点で処理したいときに使います。
