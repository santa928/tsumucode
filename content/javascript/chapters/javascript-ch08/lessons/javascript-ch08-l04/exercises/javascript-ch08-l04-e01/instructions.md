## 空白だけの題名を登録しない

今のコードは空文字を断れますが、スペースだけの題名を登録してしまいます。titleへ入れる値を、前後の空白を除いた文字列に変えてください。

- 空欄とスペースだけなら「題名を入力してください」と案内し、登録済みの表示を保ちます。
- 題名があれば「登録しました」と案内し、「登録済み: 春の本」のように表示します。
- 入力だけでは表示を変えず、送信で確かめます。春の本→スペースだけ→夏の本でも試しましょう。
- Formの標準送信を止める処理と、対象外の「感想も残そう」は残します。

入力欄自体の前後の空白を消す課題ではありません。trimの戻り値を比較と表示に使います。Previewの安全装置だけの取消では合格しません。
