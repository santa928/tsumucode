文字列のtrim()は、前後の空白を除いた別の文字列を返すメソッドです。文字列の途中の空白は残ります。返された値を変数へ入れて使います。

```js {"label":"戻り値を別の変数で使う", "role":"input"}
const original = '  春 の 本  ';
const title = original.trim();
console.log(title === '春 の 本');
console.log(original === '  春 の 本  ');
console.log('   '.trim() === '');
```

```text {"label":"Console", "role":"output"}
true
true
true
```

originalの値は変わりません。field.value.trim()を使っても、入力欄そのものを書き換えるわけではありません。空かを確かめる処理と、その後の表示に、返された文字列を使いましょう。
