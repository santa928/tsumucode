最初のHTMLに次のscript.jsを組み合わせます。前の単元と同じsubmitで標準送信を止め、現在のvalueをtrimします。既習の===で空文字と比べ、ifとelseの片方だけを実行します。

```js {"label":"script.js", "role":"input"}
const form = document.querySelector('#entry');
const field = document.querySelector('#name');
const message = document.querySelector('#message');
form.addEventListener('submit', (event) => {
  event.preventDefault();
  const name = field.value.trim();
  if (name === '') {
    message.textContent = '名前を入力してください';
  } else {
    message.textContent = '確認: ' + name;
  }
});
```

スペースだけで確認すると「名前を入力してください」。春と入力して確認すると「確認: 春」です。入力中には変えず、送信のたびに条件を確かめ直します。
