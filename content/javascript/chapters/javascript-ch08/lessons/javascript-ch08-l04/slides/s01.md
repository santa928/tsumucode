入力検証は、受け取った値がこの画面の条件に合うか確かめることです。今回は「名前が空でない」を条件にします。空なら入力を促し、名前があれば確認します。

```html {"label":"この単元で使うHTML", "role":"input"}
<form id="entry">
  <label for="name">名前</label><input id="name" />
  <button type="submit">確認</button>
</form>
<p id="message">入力待ち</p>
```

空の入力欄のvalueは空文字です。空文字は文字が0個の文字列で、コードでは''と書きます。一方、スペースだけの文字列には空白の文字が入っています。同じ空に見えても、そのまま比べると区別されます。

```js {"label":"空文字との比較", "role":"input"}
console.log('' === '');
console.log('   ' === '');
```

```text {"label":"Console", "role":"output"}
true
false
```
