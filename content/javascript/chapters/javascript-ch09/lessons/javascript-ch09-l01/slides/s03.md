次のHTMLとscript.jsを組み合わせます。countをhandlerの外で一度作り、handlerは外側の変数を参照します。既習のClosureと同じ仕組みで、次のclickでも更新後の値を使えます。

```html {"label":"index.html", "role":"input"}
<button id="read" type="button">一冊読んだ</button>
<p id="count">読んだ冊数: 0</p>
```

```js {"label":"script.js", "role":"input"}
const button = document.querySelector('#read');
const label = document.querySelector('#count');
let count = 0;
button.addEventListener('click', () => {
  count = count + 1;
  label.textContent = '読んだ冊数: ' + count;
});
```

最初の表示は0、一度押すと1、もう一度押すと2です。先にcountを増やし、その後で表示を作っています。順序を逆にすると、画面には増やす前の値が出ます。
