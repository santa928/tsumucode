state（状態）は、画面が今どんな状況かを表す値です。読書メモなら「読んだ冊数」を数値で持てます。stateは特別な構文ではなく、これまでの変数で表せます。

```js {"label":"最初の状態", "role":"input"}
let count = 0;
console.log(count);
```

```text {"label":"Console", "role":"output"}
0
```

countは数値0です。「読んだ冊数: 0」という画面の文字は、その値を人に伝える表示です。数値を更新することと、文字を画面へ書くことは別の処理です。
