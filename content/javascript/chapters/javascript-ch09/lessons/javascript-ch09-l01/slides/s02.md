Functionの中で宣言した変数は、その呼出しで使う変数です。次の例は呼ぶたびにlet count = 0を実行するため、前のcountを引き継ぎません。既習のローカルスコープを思い出しましょう。

```js {"label":"呼ぶたびに作り直す", "role":"input"}
function readBook() {
  let count = 0;
  count = count + 1;
  console.log(count);
}
readBook();
readBook();
```

```text {"label":"Console", "role":"output"}
1
1
```

clickのhandlerでも同じです。毎回0から1へ進むだけなら、足し算の行だけでなく、0を用意する場所を確かめます。
