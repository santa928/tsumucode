2枚目の例でcountの宣言を外へ移すと、呼出しの間で値を保持できます。count = count + 1は、今の値から次の値を作る処理です。

```js {"label":"宣言の場所を変えた例", "role":"input"}
let count = 0;
function readBook() {
  count = count + 1;
  console.log(count);
}
readBook();
readBook();
```

```text {"label":"Console", "role":"output"}
1
2
```

![同じcountを操作ごとに更新し、更新後の値を表示する](asset:state-flow)

演習では同じ考えをclickのhandlerへ使います。Previewを更新し直すとコードが最初から動き、countも0へ戻ります。実行中のstateは学習の下書き保存とは別です。下書きに保存されるのはコードで、押した回数ではありません。
