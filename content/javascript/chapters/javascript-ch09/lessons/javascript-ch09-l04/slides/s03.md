1枚目のHTMLとstateから始めます。既習の一覧renderに、前のvisibleの計算を入れます。forEachの対象をstate.itemsからvisibleへ変え、book.titleを表示します。

```js {"label":"条件を更新した後で描画","role":"input"}
document.querySelector('#unread').addEventListener('click', () => {
  state.onlyUnread = true;
  render();
});
document.querySelector('#all').addEventListener('click', () => {
  state.onlyUnread = false;
  render();
});
```

render内の件数表示も、表示用と元のArrayを分けて作ります。listとcountは前の単元と同じIDの要素を取得します。

```js {"label":"render内の件数表示", "role":"input"}
count.textContent = '表示: ' + visible.length + ' / 全体: ' + state.items.length;
```

未読は星・森、すべては星・海・森です。ボタンは一覧の外へ置き、renderでは一覧の子だけを作り直します。
