1枚目のstateに続けて実行します。filterは条件を満たす要素を持つ新しいArrayを返します。元のstate.itemsへ戻さず、表示用のvisibleへ入れます。

```js {"label":"未読だけを選ぶ","role":"input"}
state.onlyUnread = true;
let visible = state.items;
if (state.onlyUnread) {
  visible = state.items.filter((book) => book.done === false);
}
console.log(visible.length);
console.log(state.items.length);
```

```text {"label":"Console","role":"output"}
2
3
```

visibleは星と森の2冊です。元は海も含む3冊のままです。visibleはrenderの中で毎回計算し、別のstateとして保存しません。
