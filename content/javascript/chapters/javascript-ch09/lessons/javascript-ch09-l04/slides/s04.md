renderの絞り込み部分を比べます。変更前は元のitemsを上書きします。「すべて」に戻しても海の本がありません。変更後はvisibleだけを変えます。後続の描画はvisible.forEachを使います。

```js {"label":"変更前：元のデータが減る","role":"input"}
let visible = state.items;
if (state.onlyUnread) {
  state.items = state.items.filter((book) => book.done === false);
  visible = state.items;
}
```

```js {"label":"変更後：表示用のArrayだけ変える","role":"input"}
let visible = state.items;
if (state.onlyUnread) {
  visible = state.items.filter((book) => book.done === false);
}
```
