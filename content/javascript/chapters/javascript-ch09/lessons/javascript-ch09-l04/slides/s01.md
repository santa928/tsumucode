「未読だけ」と「すべて」を切り替える一覧を作ります。doneは読了済みかを表すbooleanです。onlyUnreadは未読だけにするか、という表示条件です。最初はfalseなので全3冊を使います。

```js {"label":"元の本と表示条件","role":"input"}
const state = {
  items: [
    { title: '星の本', done: false },
    { title: '海の本', done: true },
    { title: '森の本', done: false },
  ],
  onlyUnread: false,
};
```

```html {"label":"切替ボタンと表示先","role":"input"}
<button id="unread" type="button">未読だけ</button>
<button id="all" type="button">すべて</button>
<ul id="books"></ul>
<p id="count">準備中</p>
```

絞り込みは本の削除ではありません。元のitemsを3冊のまま残せば、あとで「すべて」に戻せます。
