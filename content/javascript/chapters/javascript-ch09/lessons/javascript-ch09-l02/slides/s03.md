1枚目のコードから始め、末尾にrender();と次の登録を追加します。最初のcountは0です。押すたびにstate.countを増やしてからrenderを呼びます。

```js {"label":"clickで更新して表示する", "role":"input"}
const button = document.querySelector('#read');
button.addEventListener('click', () => {
  state.count = state.count + 1;
  render();
});
```

1回目は冊数1と次は2冊目、2回目は冊数2と次は3冊目です。どちらの文章もrenderが今のstateから作るため、handlerごとに文章の計算を繰り返す必要はありません。

renderを更新の前に呼ぶと、古いcountを表示してしまいます。「state更新→render」の順を確かめましょう。
