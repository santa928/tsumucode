前の登録に、0へ戻すボタンの処理を加えます。state.countを0にして同じrenderを呼ぶと、冊数は0、次は1冊目へそろいます。

```js {"label":"Resetも同じrenderを使う", "role":"input"}
const reset = document.querySelector('#reset');
reset.addEventListener('click', () => {
  state.count = 0;
  render();
});
```

![読了と0に戻す操作がstateを更新し、同じrenderで2つの表示をそろえる](asset:render-flow)

renderはstateを読むだけにします。renderの中でcountを増やすと、最初の表示や0に戻す操作でも冊数が増えてしまいます。同じstateでrenderを2回呼んでも、表示する値は同じです。
