renderは、今のstateを使って表示を作る処理の名前です。特別な構文ではなく、普通のFunctionです。ここではObjectのcountを、2つの表示に使います。

```html {"label":"この単元のHTML", "role":"input"}
<button id="read" type="button">一冊読んだ</button>
<button id="reset" type="button">0に戻す</button>
<p id="count">準備中</p>
<p id="next">準備中</p>
```

```js {"label":"表示用Functionを用意する", "role":"input"}
const state = { count: 0 };
const label = document.querySelector('#count');
const next = document.querySelector('#next');
function render() {
  label.textContent = '読んだ冊数: ' + state.count;
  next.textContent = '次は' + (state.count + 1) + '冊目';
}
```

同じstate.countから冊数と次の冊数を作ります。宣言しただけではrenderは実行されません。次のスライドで呼び出してみましょう。
