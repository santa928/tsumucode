前のHTMLとコードに、次の呼出しを追加します。state.countは0なので、renderは0を使って表示します。

```js {"label":"最初の表示", "role":"input"}
render();
```

```text {"label":"画面", "role":"output"}
読んだ冊数: 0
次は1冊目
```

stateだけを2へ変えても、画面は自動では変わりません。renderをもう一度呼ぶと、2つの表示が現在のstateから作り直されます。

```js {"label":"続けてstateを変えて表示する", "role":"input"}
state.count = 2;
render();
```

```text {"label":"更新後の画面", "role":"output"}
読んだ冊数: 2
次は3冊目
```
