1枚目のHTMLと準備コードに、次を追加します。forEachが各文字列をtitleへ渡し、createElementで作ったliへ文字を入れて接続します。これらのDOM操作は要素作成の単元で扱いました。

```js {"label":"毎回、今のArrayから作る", "role":"input"}
function render() {
  list.replaceChildren();
  state.items.forEach((title) => {
    const item = document.createElement('li');
    item.textContent = title;
    list.appendChild(item);
  });
  count.textContent = '冊数: ' + state.items.length;
}
render();
```

一覧は「星の本」、件数は「冊数: 1」です。renderをもう一度呼んでも、先に古い行を消すので1件のままです。replaceChildrenを省くと、呼ぶたびに同じ行が増えます。
