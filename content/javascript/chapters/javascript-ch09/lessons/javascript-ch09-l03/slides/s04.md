1枚目の準備と前のrenderに、次の登録を加えます。[...state.items, '海の本']は元の項目と追加分を持つ新しいArrayです。既習のspreadを使い、更新してから描画します。

```js {"label":"Arrayを更新した後で描画", "role":"input"}
document.querySelector('#add').addEventListener('click', () => {
  state.items = [...state.items, '海の本'];
  render();
});
document.querySelector('#clear').addEventListener('click', () => {
  state.items = [];
  render();
});
```

空のArrayではforEachは0回です。それでも古い行の消去と件数の表示は実行されるので、一覧は空で「冊数: 0」になります。空にする操作を2回続けても同じです。
