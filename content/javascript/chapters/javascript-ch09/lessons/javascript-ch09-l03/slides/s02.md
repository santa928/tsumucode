前のコードの続きで実行します。replaceChildren()を引数なしで呼ぶと、その要素の子をすべて取り除きます。ここでは#booksの中だけを空にします。ul自体やボタンは残ります。

```js {"label":"一覧の子だけを消す", "role":"input"}
list.replaceChildren();
console.log(state.items.length);
```

```text {"label":"実行後", "role":"output"}
一覧の「古い表示」が消える
Console: 1
```

DOMを消してもArrayは変わりません。逆にArrayを変えても、描画を呼ぶまではDOMは変わりません。次は残っているstateから新しい行を作ります。
