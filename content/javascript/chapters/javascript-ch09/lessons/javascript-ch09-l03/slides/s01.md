前の単元では数を持ちました。今回はArrayをstate.itemsに持ちます。itemsは自分で付けたproperty名です。画面の行を覚えるのではなく、このArrayを一覧の元にします。

```html {"label":"この単元のHTML", "role":"input"}
<button id="add" type="button">海の本を追加</button>
<button id="clear" type="button">一覧を空にする</button>
<ul id="books"><li>古い表示</li></ul>
<p id="count">準備中</p>
```

```js {"label":"一覧の元と表示先", "role":"input"}
const state = { items: ['星の本'] };
const list = document.querySelector('#books');
const count = document.querySelector('#count');
```

itemsには「星の本」が1つあります。まだ描画していないので、画面は「古い表示」のままです。Arrayのlengthは今の件数を表します。
