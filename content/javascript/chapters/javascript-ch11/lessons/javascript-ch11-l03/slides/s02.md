既習のtextContentは値を文字として表示します。ボタンの名前もこの方法で更新できます。stateのopenedがtrueなら、次の操作は閉じることです。

```js {"label":"今の状態から次の操作名を決める","role":"input"}
button.textContent = opened ? 'ヒントを閉じる' : 'ヒントを開く';
```

openedはtrue/falseの既習stateです。「開いている」と「開く」は違います。今は開いているので、ボタンには次にできる「閉じる」と表示します。文字を入れるためにinnerHTMLへ替える必要はありません。
