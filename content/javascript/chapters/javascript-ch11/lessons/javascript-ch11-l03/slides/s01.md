「切り替え」だけでは何を変えるか分かりません。「ヒントを開く」なら結果を予測できます。標準buttonの文字は、支援技術へ操作を伝えるAccessible Name（アクセシブルネーム）の元にもなります。

```js {"label":"見える文字で操作の目的を伝える","role":"input"}
button.textContent = 'ヒントを開く';
```

アイコンだけに頼らず、まず文字で分かる名前にします。この教材のbuttonにはaria-labelによる別名を付けず、見える文字と名前を一致させます。
