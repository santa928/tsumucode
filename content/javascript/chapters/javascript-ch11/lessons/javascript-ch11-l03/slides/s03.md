aria-expanded（エリア・エクスパンデッド）は、操作対象が今開いているかを支援技術へ伝える属性です。true/falseという文字列を入れます。属性だけ変えても表示は開閉しません。

```js {"label":"同じstateを属性へ文字列として渡す","role":"input"}
button.setAttribute('aria-expanded', String(opened));
```

配布HTMLのaria-controls="hint"は対象のidを示します。表示をhidden属性で切り替える処理は用意済みです。名前・実際の表示・aria-expandedを同じstateへ合わせます。
