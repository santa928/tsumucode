Starterは表示だけ切り替わり、名前が曖昧なまま、aria-expandedもfalseのままです。render内の2行をstateに合わせて直します。

```js {"label":"変更後：同じstateから名前と状態を更新","role":"input"}
button.textContent = opened ? 'ヒントを閉じる' : 'ヒントを開く';
button.setAttribute('aria-expanded', String(opened));
```

![閉じた状態はヒントを開くとfalse、開いた状態はヒントを閉じるとtrue。表示と名前と状態を往復して確認](asset:control-flow)

EditorはEsc→Tabで抜けます。ボタンへTabで移り、Enterで開く・Spaceで閉じる・Enterで再び開くを試します。名前が今の状態でなく「次の操作」を示すか確認しましょう。
