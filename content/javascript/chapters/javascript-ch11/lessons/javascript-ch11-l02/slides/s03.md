「説明へ戻る」を押した後は、もう一度始められる開始ボタンへ戻します。移動先を明確にすると、キーボード利用者が自分の位置を見失いにくくなります。

```js {"label":"説明へ戻るhandler：起点へ戻す","role":"input"}
back.addEventListener('click', () => {
  question.textContent = '始めると問題が出ます';
  answer.value = '';
  start.focus();
});
```

backは戻るbutton、startは開始buttonです。開始時と戻る時の両方向を決めます。Tabを封じたり、いつも同じ要素へFocusを戻したりはしません。
