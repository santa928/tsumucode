要素.focus()は、その要素をキーボード操作の現在位置にします。この教材では標準inputとbuttonを使います。枠線が移ることと、そのまま入力できることの両方を確認します。

```js {"label":"回答欄を取得しFocusする","role":"input"}
const answer = document.querySelector('#answer');
answer.focus();
```

focus()は既にある要素を操作先にするだけです。回答を記入したり、採点したりはしません。何も操作していない読書中に繰り返し呼ぶと、利用者の現在位置を奪います。
