「問題を始める」を押して問題文が出ても、Focusが開始ボタンのままだと、そのまま文字を入力できません。表示を変えた後で回答欄へFocusを移すと、次の操作がつながります。

```js {"label":"開始handlerの中：表示してから回答欄へ","role":"input"}
question.textContent = '1 + 1 は？';
answer.value = '';
answer.focus();
```

questionは問題文、answerは回答用inputです。valueは入力欄の文字です。空文字を代入すると、前の回答を消してから次を始められます。
