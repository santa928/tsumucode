Starterは表示と入力文字を更新しますが、Focusを動かしていません。開始handlerの最後へanswer.focus()、戻るhandlerの最後へstart.focus()を加えます。

```js {"label":"2つの操作に、それぞれの移動先を指定","role":"input"}
// 開始handlerの最後
answer.focus();
// 戻るhandlerの最後
start.focus();
```

![開始ボタンから回答欄へFocusし、説明へ戻ると開始ボタンへFocusを戻す](asset:focus-flow)

EditorはEsc→Tabで抜けます。開始ボタンへTabで進み、Enterで開始→回答を入力→Tabで戻るボタンへ→Enterで戻ります。開き直して回答が空かも確かめましょう。
