すべてのキーで閉じると、Tabで移動したいときにも表示が消えます。ifでEscapeだけを選び、他のキーでは何もしません。

```js {"label":"keydown handlerの中：Escapeだけに反応","role":"input"}
if (event.key === 'Escape') {
  closeHint();
}
```

closeHintはヒントを閉じる用意済みFunctionです。この教材ではヒントを開くボタンにFocusがある間だけEscapeが効きます。画面全体や別の操作先を捕まえる処理ではありません。
