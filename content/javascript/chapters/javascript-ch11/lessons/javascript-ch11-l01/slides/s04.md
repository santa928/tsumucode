StarterはどのキーでもcloseHintを呼びます。keydown内の1行をifで囲み、Escapeのときだけ閉じるよう直してください。

```js {"label":"変更後：ほかのキーを妨げない","role":"input"}
button.addEventListener('keydown', (event) => {
  if (event.key === 'Escape') {
    closeHint();
  }
});
```

![Tabでボタンへ、EnterまたはSpaceで開く、Escapeで閉じる。右矢印では開いたまま](asset:keyboard-flow)

Editor内ならEsc→Tabで抜け、PreviewへTabで入り、枠がボタンへ来たらEnterで開きます。右矢印で開いたまま、Escapeで閉じることを確認し、Spaceでも開き直します。
