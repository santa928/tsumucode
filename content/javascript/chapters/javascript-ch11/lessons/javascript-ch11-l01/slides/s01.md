Tabで操作先を選ぶと、枠線で現在位置が分かります。この位置をFocus（フォーカス）と呼びます。標準buttonは、Focus中にEnterやSpaceでも押せます。

```html {"label":"操作の意味が分かる標準ボタン","role":"input"}
<button id="open" type="button">ヒントを開く</button>
```

```js {"label":"マウスとキーボードで同じ処理","role":"input"}
button.addEventListener('click', showHint);
```

showHintはヒントを表示する既習のFunctionです。標準buttonにはキー専用のclick再実行を追加しません。二重に開いたり得点が二重加算されたりする原因になります。
