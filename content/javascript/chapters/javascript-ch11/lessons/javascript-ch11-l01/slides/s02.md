keydown（キーダウン）はキーを押したときのEventです。handlerが受け取るeventのkeyに、押されたキーの名前が入ります。

```js {"label":"ボタンにFocusした状態でキーを押す","role":"input"}
button.addEventListener('keydown', (event) => {
  console.log(event.key);
});
```

Escapeなら'Escape'、右矢印なら'ArrowRight'です。Spaceのkeyは空白1文字' 'です。キーボードの見た目の表記をそのまま使えるとは限りません。
