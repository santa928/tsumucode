要素のclassListは、今付いているclassを扱う窓口です。addは指定した名前を追加します。CSS selectorの.bookと違い、classの名前を渡すときは先頭の点を付けません。

```html {"label":"開始時のHTML", "role":"input"}
<p id="first" class="book pending">一冊目</p>
```

```js {"label":"script.js", "role":"input"}
const item = document.querySelector('#first');
item.classList.add('done');
```

```text {"label":"実行後のclass", "role":"output"}
book pending done
```

addしてもpendingは残ります。同じdoneをもう一度addしても、doneが2つに増えることはありません。見た目が変わっただけで、classがすべて狙いどおりとは限りません。
