removeは指定したclassだけを外します。bookまで消す必要はありません。付いていないclassをremoveしても、ほかのclassは変わりません。

```html {"label":"開始時のHTML", "role":"input"}
<p id="first" class="book pending done">一冊目</p>
```

```js {"label":"script.js", "role":"input"}
const item = document.querySelector('#first');
item.classList.remove('pending');
```

```text {"label":"実行後のclass", "role":"output"}
book done
```

文字を変えるtextContentと、classの付け外しは別の操作です。このコードでは「一冊目」という文字は変わりません。HTML全体を置き換えず、同じ要素の状態だけを変えています。
