HTMLのclassは、CSSのルールを選ぶ目印です。空白で区切ると複数を同時に付けられます。bookは共通の余白、pendingは未読の見た目、と役割を分けます。

```html {"label":"HTML", "role":"input"}
<p class="book pending">一冊目</p>
```

```css {"label":"用意したCSS", "role":"input"}
.book {
  padding: 12px;
}
.pending {
  border-left: 6px dashed #777;
}
.done {
  border-left: 6px solid #16764b;
}
```

bookを残してpendingをdoneへ変えると、余白を保ったまま点線が緑の実線になります。色だけでなく線の形も変わります。JavaScriptでは、前の単元で取得した要素のclassを操作できます。
