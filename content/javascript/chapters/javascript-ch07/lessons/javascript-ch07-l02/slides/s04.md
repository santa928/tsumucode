次は別の要素で練習します。noticeは共通の見た目、quietとactiveは状態の目印です。quietを外しactiveを付けても、noticeは残します。

```html {"label":"HTML", "role":"input"}
<p id="notice" class="notice quiet">お知らせ</p>
```

```js {"label":"完成例", "role":"input"}
const note = document.querySelector('#notice');
note.classList.remove('quiet');
note.classList.add('active');
```

```text {"label":"実行後のclass", "role":"output"}
notice active
```

classの並び順は本質ではありません。active noticeでも同じ2つのclassです。演習ではbookを残し、pendingを外してdoneを付けます。2冊目や表示する文字は変えません。classListは、ほかのclassを残して操作しやすい方法です。
