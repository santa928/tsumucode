## 一冊目だけを読了の見た目にする

HTML/CSSは用意済みです。前の単元のquerySelectorで一冊目を取得し、script.jsでそのclassを変更します。

- bookは残す
- pendingを外す
- doneを付ける
- 二冊目の状態と両方の文字は変えない

今のコードは共通のbookを外し、CSSで使っていないreadyを付けています。残すもの・外すもの・付けるものを考えて直しましょう。左の点線が緑の実線に変わり、余白は残ります。

classListはほかのclassを保ちながら操作しやすい方法です。判定は実際のclassと文字を確認し、変数名やclassの順序を固定しません。Preview更新は実行結果の確認、判定するは課題達成の確認です。
