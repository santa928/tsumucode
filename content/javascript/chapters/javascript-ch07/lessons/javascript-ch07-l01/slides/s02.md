selectorの#はid、.はclassを探す目印です。同じclassは複数の要素へ付けられます。querySelectorが返すのは、ページの順で最初に一致した1要素だけです。

```html {"label":"HTML・上からこの順番", "role":"input"}
<p class="book">一冊目</p>
<p class="book">二冊目</p>
```

```js {"label":"script.js・完成例", "role":"input"}
const book = document.querySelector('.book');
book.textContent = '読み終わりました';
```

```text {"label":"ページの表示・上から順番", "role":"output"}
読み終わりました
二冊目
```

.bookに一致する要素が2つあっても、2つ目は変更していません。要素が複数あることと、全部を選ぶことは違います。
