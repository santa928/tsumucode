演習では.bookの先頭だけを「読書を始めます」に変更します。2つ目の「二冊目」は残してください。HTMLとCSSは読む専用で、script.jsを編集します。

```js {"label":"別の目印を使う例", "role":"input"}
const notice = document.querySelector('.notice');
if (notice !== null) {
  notice.textContent = 'お知らせがあります';
}
```

```text {"label":".noticeの要素がある場合の表示", "role":"output"}
お知らせがあります
```

例の目印と文字を、演習のHTMLと目標へ合わせます。変数名は役割の分かる別の名前でも構いません。Previewでどの要素が変わったかを見て、判定します。困ったら段階ヒントやこの説明へ戻り、直してもう一度試せます。
