querySelectorは見つからなかったときnullを返します。nullは「該当する要素がない」を示す値です。要素ではないので、そのtextContentを変更しようとするとエラーになります。

```html {"label":"HTML", "role":"input"}
<p id="message">準備中</p>
```

```js {"label":"script.js・見つからない例", "role":"input"}
const note = document.querySelector('#missing');
console.log(note === null);
if (note !== null) {
  note.textContent = '準備できました';
}
```

```text {"label":"Consoleとページの結果", "role":"output"}
Console: true
ページ: 準備中
```

!== nullは「nullではない」という比較です。既習のifで、見つかった場合だけ変更します。エラーなく終了しても、狙った文字に変わったとは限りません。目印がHTMLと合っているか、表示も確かめます。
