HTMLの見出しや段落を、ブラウザは操作できる要素として持っています。この仕組みをDOMと呼びます。documentは今のページを表し、querySelectorはCSSのselectorで要素を1つ探します。

```html {"label":"HTML", "role":"input"}
<p id="message">準備中</p>
```

```js {"label":"script.js・完成例", "role":"input"}
const message = document.querySelector('#message');
message.textContent = '準備できました';
```

```text {"label":"ページの表示", "role":"output"}
準備できました
```

messageには文字列のコピーではなく、見つけた要素への参照が入ります。参照を使ってtextContentを書き換えると、元のページが変わります。constでも要素の文字は変えられます。変数へ別の値を再代入する操作とは別です。
