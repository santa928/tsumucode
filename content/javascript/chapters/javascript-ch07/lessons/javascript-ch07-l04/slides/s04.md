別のお知らせで流れを確認します。複数のnoticeを選び、各要素のquietを外しactiveを付けます。取得した集合と、callbackで受け取る1要素を混同しないようにします。

```html {"label":"HTML", "role":"input"}
<p class="notice quiet">朝のお知らせ</p>
<p class="notice quiet">夕のお知らせ</p>
```

```js {"label":"script.js", "role":"input"}
const notices = document.querySelectorAll('.notice');
notices.forEach((notice) => {
  notice.classList.remove('quiet');
  notice.classList.add('active');
});
```

```text {"label":"実行後のclass", "role":"output"}
朝: notice active
夕: notice active
```

演習では3冊すべてを読了にします。forEachは同じ処理を各要素へ適用しやすい方法です。同じ結果になる既習のfor ofも使えます。文字と対象外のメモを保つことまで確かめます。
