forEachは、集合の要素ごとにcallbackを呼ぶ操作です。前にmapで学んだcallbackと同じく、現在の要素を引数で受け取ります。今回は新しいArrayを返す目的ではなく、要素そのものを変えます。

```html {"label":"HTML", "role":"input"}
<p class="book">一冊目</p>
<p class="book">二冊目</p>
```

```js {"label":"script.js", "role":"input"}
const books = document.querySelectorAll('.book');
books.forEach((book) => {
  book.textContent = '確認済み';
});
```

```text {"label":"実行後の表示", "role":"output"}
確認済み
確認済み
```

bookは1回のcallbackが扱う要素です。波括弧内に1件分の操作を書きます。forEachは戻り値から新しいArrayを作らず、0件ならcallbackを1回も呼びません。

:::practice
prompt: booksが0件のとき、確認済みという文字は表示されるでしょうか。
expectedAction: callbackが呼ばれないので表示は変わらないと予測する

:::
