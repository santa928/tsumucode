querySelectorは最初の1件を返しました。querySelectorAllは、条件に合った要素の参照をNodeListという集合で返します。見つからないときもnullではなく0件の集合です。

```html {"label":"HTML", "role":"input"}
<p class="book">一冊目</p>
<p class="book">二冊目</p>
```

```js {"label":"script.js", "role":"input"}
const books = document.querySelectorAll('.book');
console.log(books.length);
```

```text {"label":"Console", "role":"output"}
2
```

lengthは集合の件数です。NodeListはArrayそのものではありませんが、要素を1件ずつ取り出して扱えます。この集合は取得時の結果なので、後で要素を追加しても自動で再検索されません。選んだ要素のclassを途中で外しても、取得済みの集合からは抜けません。
