全件といってもページ全部を変えるのではありません。どの集合を選ぶかはselectorで決めます。.bookを選べば、同じpendingが付いたメモも対象外にできます。

```html {"label":"HTML", "role":"input"}
<p class="book pending">一冊目</p>
<p class="note pending">メモ</p>
```

```js {"label":"script.js", "role":"input"}
const books = document.querySelectorAll('.book');
books.forEach((book) => {
  book.classList.remove('pending');
  book.classList.add('done');
});
```

```text {"label":"実行後のclass", "role":"output"}
一冊目: book done
メモ: note pending
```

bookという共通classと、両方の文字はそのままです。selectorを.pendingにすると、メモも集合に入り変更されます。集合を選ぶ条件と、1件へ行う操作を別々に確かめましょう。
