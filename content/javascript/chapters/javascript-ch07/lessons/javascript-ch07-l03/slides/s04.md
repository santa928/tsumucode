別の手順リストで流れを確認します。作る対象はli、表示する文字は「確認」、接続先はstepsです。3つの役割を分けると、表示が増えない原因を探せます。

```html {"label":"開始時のHTML", "role":"input"}
<ol id="steps">
  <li>準備</li>
</ol>
```

```js {"label":"script.js", "role":"input"}
const steps = document.querySelector('#steps');
const next = document.createElement('li');
next.textContent = '確認';
steps.appendChild(next);
```

```text {"label":"実行後の手順", "role":"output"}
1. 準備
2. 確認
```

作った要素へ文字を入れるだけでは未接続です。演習では本のリストへ応用し、元の項目を残して末尾に新しい本を追加します。既存のリスト全体のtextContentを書き換えると中の子が失われるので、追加する子を操作します。
