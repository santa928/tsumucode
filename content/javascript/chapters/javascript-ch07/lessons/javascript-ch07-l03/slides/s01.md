前の単元のquerySelectorは、ページにある要素を探しました。document.createElementは、新しい要素を作ってその参照を返します。引数はliのようなタグ名です。タグを囲む記号は含めません。

```html {"label":"開始時のHTML", "role":"input"}
<ul id="books">
  <li>読みかけの本</li>
</ul>
```

```js {"label":"script.js", "role":"input"}
const item = document.createElement('li');
```

```text {"label":"ページに表示される項目", "role":"output"}
読みかけの本
```

新しいliは作られていますが、ページにはまだつながっていません。変数itemは、その要素を後から操作するための参照です。
