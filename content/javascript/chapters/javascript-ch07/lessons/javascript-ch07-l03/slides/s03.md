子要素は、別の要素の中に入る要素です。親のappendChildへ要素の参照を渡すと、その親の末尾へ子として接続します。既存の子は消しません。

```html {"label":"開始時のHTML", "role":"input"}
<ul id="books">
  <li>読みかけの本</li>
</ul>
```

```js {"label":"script.js", "role":"input"}
const list = document.querySelector('#books');
const item = document.createElement('li');
item.textContent = '次に読む本';
list.appendChild(item);
```

```text {"label":"ページの項目を上から読む", "role":"output"}
読みかけの本
次に読む本
```

listが親、itemが追加する子です。渡すのは変数名を引用符で囲んだ文字列ではなく、要素の参照です。同じ要素を再びappendChildしても複製されず、移動します。
