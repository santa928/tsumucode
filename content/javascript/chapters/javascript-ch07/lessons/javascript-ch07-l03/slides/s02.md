作った要素にも、既習のtextContentを使えます。文字を設定しても、ページに接続していなければ表示は増えません。

```html {"label":"開始時のHTML", "role":"input"}
<ul id="books">
  <li>読みかけの本</li>
</ul>
```

```js {"label":"script.js", "role":"input"}
const item = document.createElement('li');
item.textContent = '次に読む本';
```

```text {"label":"ページに表示される項目", "role":"output"}
読みかけの本
```

itemの中には文字が入っています。画面のリストに見せるには、次に親へ接続する操作が必要です。textContentへ渡すものは文字列であり、HTMLのタグとして解釈させる操作ではありません。

:::practice
prompt: 文字を設定できているのに、表示が増えない理由を説明します。
expectedAction: itemに文字はあるが、親のリストにまだ接続していないからと説明する
estimatedMinutes: 1
:::
