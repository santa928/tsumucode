## 本のリストへ新しい項目を追加する

HTML/CSSは用意済みです。script.jsで新しいliを作り、本のリストの末尾へ接続します。

- booksにある「読みかけの本」は先頭に残す
- 新しいliの文字は「次に読む本」にする
- booksは合計2項目にする
- 別のメモのリストは変えない

今は要素を作っていますが、文字は仮の名前で、まだページにつながっていません。表示を予測してから文字を直し、接続する1行を書きましょう。

判定は実DOMの項目と文字、およびcreateElementによる生成を確認します。変数名や文字設定と接続の順序は固定しません。Preview更新は実行結果、判定するは課題達成の確認です。
