Arrayは角括弧`[]`で作り、要素をカンマで区切ります。この完成した書き方をArray literalと呼びます。

```js
const questions = ['HTMLの役割は？', 'CSSの役割は？'];
```

上から並べた順番は保たれます。末尾のカンマは、次の要素を加えやすくするため残せます。
