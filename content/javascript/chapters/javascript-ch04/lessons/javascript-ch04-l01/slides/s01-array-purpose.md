これまでは、問題文ごとに別の変数へ名前を付けていました。問題が増えるたびに変数も増えると、全体を順番に扱いにくくなります。

Arrayは、複数の値を「1番目、2番目…」という順番つきで1つにまとめる仕組みです。クイズでは、複数の問題文を並べる入れ物として使えます。
