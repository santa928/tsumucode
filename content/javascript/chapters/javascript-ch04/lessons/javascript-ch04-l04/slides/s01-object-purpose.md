1問には「問題文」「正解」「カテゴリ」など、役割の違う値があります。Arrayだけでは、何番目がどの項目かを順番で覚える必要があります。

Objectは、値へproperty名を付けて1つにまとめる仕組みです。`question`や`answer`の名前から、値の役割を読み取れます。
