Objectは開始と終了の波括弧で作ります。`property名: 値`をカンマで区切った完成形をObject literalと呼びます。

```js
const quiz = {
  question: '2 + 3 は？',
  answer: 5,
};
```

左側がproperty名、右側がそのpropertyの値です。
