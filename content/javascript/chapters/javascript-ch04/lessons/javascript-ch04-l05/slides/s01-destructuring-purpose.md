ObjectやArrayから複数の値を使うたびに、dot accessやindexを繰り返すこともできます。

Destructuringは、右側のデータの形に合わせて左側へ波括弧や角括弧を書き、必要な値へ一度に名前を付ける書き方です。元のObjectやArrayは変更しません。
