すべての問題を表示するとき、`[0]`、`[1]`、`[2]`と1行ずつ増やす方法では、問題数が変わるたびにコードも直します。

`for...of`はArrayの先頭から最後まで、要素を1つずつ順番に処理するLoopです。indexを自分で数えなくても全要素を読めます。
