Arrayの要素には、位置を表すindexがあります。日常の「1番目」と違い、JavaScriptのindexは`0`から始まります。

```js
// 1問目 → index 0
// 2問目 → index 1
// 3問目 → index 2
```

欲しい順番から1を引く、と考えると対応を確かめやすくなります。
