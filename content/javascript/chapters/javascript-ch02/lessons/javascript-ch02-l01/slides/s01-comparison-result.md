JavaScriptでは、2つの値を比べた式にも答えがあります。その答えは真偽値の`true`か`false`です。

```js
'A' === 'A'; // true
'A' === 'B'; // false
```

比較する前の値と、比較したあとのbooleanを分けて読みます。

:::practice
prompt: 1行目の比較結果を答えます。
expectedAction: 左右が同じなのでtrueと答える
estimatedMinutes: 1
:::
