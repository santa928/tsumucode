条件分岐は、比較結果の`true`か`false`に応じて、実行するコードを選ぶ仕組みです。

回答がAと同じなら「正解です」、違うなら「不正解です」と表示するように、2つの道を用意できます。

1回の判定で進むのは片方だけです。

:::practice
prompt: 条件がtrueのときに進む道を選びます。
expectedAction: 正解ですを表示する道と答える
estimatedMinutes: 1
:::
