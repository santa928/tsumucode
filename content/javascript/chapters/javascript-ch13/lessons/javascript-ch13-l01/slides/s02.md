元の問題Arrayを残し、categoryが同じ問題だけfilterして表示用Arrayを作ります。問題/回答/得点/結果の状態を先に決めてから描画します。

```js {"label":"制作へつなぐ局所の例","role":"input"}
const items = [{ category: 'web', text: '例' }];
const visible = items.filter((item) => item.category === 'web');
console.log(visible.length);
```

これは考え方を確認する小例です。クイズの完成Sourceではありません。
