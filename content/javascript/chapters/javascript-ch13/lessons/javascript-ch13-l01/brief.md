## 自分で設計する学習クイズ

2つのカテゴリで知識を確かめる学習クイズを、自分のデザインで作ります。

- 提供するquestions.jsは通信せず、loadQuestions(shouldFail)から問題Arrayを受け取れます。
- Webの2問は「Webページの骨組みを作るのは？」（HTML/CSS）と「見た目を整えるのは？」（JavaScript/CSS）。正答はHTMLとCSSです。
- categoryの値webとlogicで2問ずつ。logicは「1 + 1 は？」（2/3、正答2）と「3 > 5 の結果は？」（true/false、正答false）です。
- 進捗は「問題1 / 2」「問題2 / 2」。正解だけ1点、結果は「2問中N問正解」。
- 再挑戦は選んだカテゴリを保持し、0点・未回答・最初の問題へ戻します。
- native select/buttonを使い、開始/次問/再挑戦で回答へ、回答後は次へ、結果後はもう一度へfocusを移します。
- 正誤案内は「正解です」または「正解は CSS です」の形。得点は「得点: 0」の形です。
- 読み込みは「読み込み中...」、失敗は「読み込めませんでした。開始でやり直せます」。読込中の二重開始を防ぎ、失敗後は開始できます。
- 「読み込み失敗を試す（練習用）」は失敗を観測するためのbuttonです。通信障害ではありません。

構造・Class名・関数名・stateの管理・CSSの配置は自由です。GuideのIDは判定対象の目印なので保持します。

## 提供データの扱い

questions.jsは編集不要の提供Moduleです。内部でJSON文字列をArrayへ戻しますが、この章でJSONの記述は求めません。loadQuestions(shouldFail)の返すPromiseと、問題Objectのtext/choices/correctを使います。データをコードとして実行する処理はありません。

カテゴリごとの問題は取得したArrayをfilterして選びます。固定の問題文だけでは別カテゴリの結果を作れません。
