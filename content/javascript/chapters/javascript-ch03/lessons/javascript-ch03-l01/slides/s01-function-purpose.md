同じ処理を使いたい場所ごとに書き直すと、変更する場所が増えてしまいます。

Functionは、ひとまとまりの処理へ名前を付けて再利用する仕組みです。まず処理を「宣言」で用意し、必要な場所から「呼び出し」ます。
