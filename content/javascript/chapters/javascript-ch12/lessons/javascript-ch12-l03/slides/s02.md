クリック回数を数えると誤答や二重回答も加点されます。現在の問題のcorrectと回答が同じかを比べ、得点を更新してからrenderします。

```js {"label":"制作へつなぐ局所の例","role":"input"}
let score = 0;
function addPoint(correct) {
  if (correct) score += 1;
}
addPoint(true);
console.log(score);
```

これは考え方を確認する小例です。クイズの完成Sourceではありません。
