currentTargetはhandlerを登録したbuttonです。押された文字と今のcorrectを比較し、正誤をfeedbackへ表示します。answeredで回答を1回にします。

```js {"label":"制作へつなぐ局所の例","role":"input"}
let answered = false;
function acceptAnswer(answer) {
  if (answered) return;
  answered = true;
  console.log(answer === 'A');
}
```
