再挑戦は新しい1回です。前回の回答済み状態が残ると押せず、点数が残ると結果が増えます。どのstateを戻すか一覧で考えます。

```js {"label":"制作へつなぐ局所の例","role":"input"}
let state = { count: 3, finished: true };
state.count = 0;
state.finished = false;
console.log(state.count);
```

これは考え方を確認する小例です。クイズの完成Sourceではありません。
