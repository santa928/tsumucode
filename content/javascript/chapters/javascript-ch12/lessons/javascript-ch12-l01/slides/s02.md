問題Arrayの今のindexからObjectを1件取り出します。textを問題文へ、choicesの2件をbuttonの文字へ表示します。

```js {"label":"制作へつなぐ局所の例","role":"input"}
const items = [{ text: '小さな例', choices: ['A', 'B'] }];
const item = items[0];
console.log(item.text);
```
