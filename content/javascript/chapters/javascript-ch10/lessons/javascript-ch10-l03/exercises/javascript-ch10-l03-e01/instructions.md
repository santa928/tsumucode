## 失敗を受け取った後の表示を直す

いまはcatchが空なので、失敗を試しても前の表示が残ります。showQuestions内のcatchでresult.textContentへ「読み込めませんでした」を入れましょう。

- 読む前は「まだ読んでいません」です。
- 「成功を試す」で同梱2問が届き、「問題: 2」になります。
- 「失敗を試す」では「読み込めませんでした」と知らせます。
- その後もう一度成功を試すと「問題: 2」へ戻ります。

loadQuestionsの引数は成功と失敗を教材用に切り替えるためのものです。実通信はしません。catchで0問と表示せず、失敗と成功を区別します。既習thenとcatchで同じ動作を作る別解も判定できます。
