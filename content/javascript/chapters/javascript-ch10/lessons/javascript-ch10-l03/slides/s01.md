Promiseは、成功するとresolveへ渡した値を結果にします。失敗した状態をrejectedと呼び、reject（リジェクト）で理由を渡せます。catchは失敗のときに呼ぶ処理です。

```js {"label":"失敗の理由を受け取る","role":"input"}
Promise.reject(new Error('読込失敗')).catch((error) => {
  console.log(error.message);
});
```

```text {"label":"Console","role":"output"}
読込失敗
```

Errorはエラー情報です。messageに理由の文章が入ります。これは同梱の練習例で、通信には失敗していません。
