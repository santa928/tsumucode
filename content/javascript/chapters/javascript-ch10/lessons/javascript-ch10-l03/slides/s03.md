演習のloadQuestions(shouldFail)は、falseなら同梱2問で成功し、trueなら教材用に失敗します。80ミリ秒以降に結果を渡し、実通信はしません。resultは#resultの要素です。

```js {"label":"変更前：失敗を受け取るだけ","role":"input"}
  } catch (error) {
    // 失敗を受け取っていますが、表示していません
  }
```

```js {"label":"変更後：失敗を画面で知らせる","role":"input"}
  } catch (error) {
    result.textContent = '読み込めませんでした';
  }
```

空のcatchでは前の表示が残り、成功したのか分かりません。「問題: 0」と表示しても、0問を正常に読めたことと区別できません。
