「成功を試す」はshowQuestions(false)、「失敗を試す」はshowQuestions(true)を呼びます。catchを直したら、成功→失敗→成功の順に操作しましょう。

```js {"label":"結果に合わせて表示する","role":"input"}
async function showQuestions(shouldFail) {
  try {
    const questions = await loadQuestions(shouldFail);
    result.textContent = '問題: ' + questions.length;
  } catch (error) {
    result.textContent = '読み込めませんでした';
  }
}
```

![成功は問題数、失敗は案内、再試行の成功で問題数へ戻る](asset:error-retry-flow)

失敗してもボタンを使えるため、もう一度呼ぶと新しいPromiseで試せます。読み込み中の表示や連打への対応は次の単元で扱います。
