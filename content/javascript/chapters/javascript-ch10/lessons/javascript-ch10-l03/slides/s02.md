Error章のtry / catchをawaitへつなげます。try（トライ）には試す処理を書きます。awaitしたPromiseが失敗すると、tryの残りの行を飛ばしてcatch（キャッチ）へ進みます。

```js {"label":"awaitの失敗を受け取る","role":"input"}
async function read() {
  try {
    await Promise.reject(new Error('読込失敗'));
    console.log('成功');
  } catch (error) {
    console.log(error.message);
  }
}
read();
```

```text {"label":"Console：成功は出ない","role":"output"}
読込失敗
```

成功ならawaitの次の行へ進みます。ここではcatchがあるので、失敗を受け取って次の対応を選べます。
