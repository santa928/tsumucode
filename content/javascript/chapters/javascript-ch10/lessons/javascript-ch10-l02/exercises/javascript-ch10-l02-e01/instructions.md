## 結果が届いてから件数を使う

問題を読むと「問題: undefined」になります。showCount内のloadQuestions()の前にawaitを加え、結果Arrayを受け取ってからlengthを使うよう直してください。

- 読む前は「問題: 0」です。
- 結果が届くと、1回目は「問題: 2」、2回目以降は「問題: 3」へ変わります。毎回届いたArrayのlengthを使います。
- 読み直しでデータが変わるので、前回の件数を固定表示しないでください。

async関数と前単元の教材用loadQuestionsを使います。同梱の問題データを返す取得元で、実通信はしません。待ち時間だけを推測して固定表示するのではなく、結果を受け取って使いましょう。既習thenで同じ動作を作る別解も判定できます。
