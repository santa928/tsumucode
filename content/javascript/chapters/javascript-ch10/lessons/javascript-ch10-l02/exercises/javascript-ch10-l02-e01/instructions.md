## 結果が届いてから件数を使う

問題を読むと「問題: undefined」になります。showCount内のloadQuestions()の前にawaitを加え、結果Arrayを受け取ってからlengthを使うよう直してください。

- 読む前は「問題: 0」です。
- 問題を読むと、結果が届いた後に「問題: 2」へ変わります。
- もう一度読んでも2件です。

async関数と前単元の教材用loadQuestionsを使います。同梱の2問を返すだけで、実通信はしません。待ち時間だけを推測して固定表示するのではなく、結果を受け取って使いましょう。既習thenで同じ動作を作る別解も判定できます。
