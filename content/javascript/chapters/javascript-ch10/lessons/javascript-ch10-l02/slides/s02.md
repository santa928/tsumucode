前の単元のloadQuestionsを使います。await（アウェイト）をPromiseの前に置くと、このasync関数の続きを結果が届くまで待たせ、結果をquestionsへ入れます。

```js {"label":"結果を受け取ってから件数を出す","role":"input"}
async function showCount() {
  const questions = await loadQuestions();
  console.log(questions.length);
}
showCount();
```

```text {"label":"結果が届いた後のConsole","role":"output"}
2
```

この教材ではawaitをasync関数の中に書きます。loadQuestionsは同梱2問を80ミリ秒以降に渡す前単元の関数です。実通信はしません。
