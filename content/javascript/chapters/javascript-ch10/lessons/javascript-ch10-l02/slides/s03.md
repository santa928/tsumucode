同じloadQuestionsを使い、Consoleの順番を予測します。showCount()を呼ぶと、まずawaitまで進みます。呼び出した側の次の行は、問題が届く前にも進めます。

```js {"label":"待機中に呼び出し元が進む","role":"input"}
async function showCount() {
  const questions = await loadQuestions();
  console.log(questions.length);
}
showCount();
console.log('先に続ける');
```

```text {"label":"Consoleの順番","role":"output"}
先に続ける
2
```

awaitは待ち時間を指定する命令ではありません。結果が届いた後で関数内の次の行へ進みます。クリック等の他の処理も動けます。
