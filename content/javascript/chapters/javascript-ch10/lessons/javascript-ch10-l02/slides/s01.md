async（エイシンク）をfunctionの前に付けると、その関数はPromiseを返します。returnした値はPromiseの成功結果になります。

```js {"label":"戻り値をthenで受け取る","role":"input"}
async function readCount() {
  return 2;
}
readCount().then((count) => {
  console.log(count);
});
```

```text {"label":"Console","role":"output"}
2
```

readCount()自体を数の2として使わず、結果を受け取ります。asyncを付けるだけで計算を別の場所で実行する仕組みにはなりません。
