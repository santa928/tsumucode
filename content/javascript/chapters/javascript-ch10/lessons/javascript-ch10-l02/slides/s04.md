演習は前単元の同梱データを使います。countは#countの要素です。変更前のquestionsはPromiseなのでArrayのlengthを持たず、「問題: undefined」になります。awaitで結果Arrayを受け取ってから表示します。

```js {"label":"変更前：Promiseのまま使う","role":"input"}
async function showCount() {
  const questions = loadQuestions();
  count.textContent = '問題: ' + questions.length;
}
```

```js {"label":"変更後：結果を受け取って使う","role":"input"}
async function showCount() {
  const questions = await loadQuestions();
  count.textContent = '問題: ' + questions.length;
}
```
