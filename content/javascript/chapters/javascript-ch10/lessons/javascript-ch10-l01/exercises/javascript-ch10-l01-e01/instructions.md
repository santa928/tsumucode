## 届いた問題データを画面へ

「問題を読む」を押しても表示が変わりません。thenの中の固定表示2行を、受け取ったquestionsから作る表示へ直してください。

- 読む前は「問題: 0」「まだありません」です。
- 1回目は「問題: 2」「空は何色？」、2回目以降は「問題: 3」「草は何色？」へ変わります。固定文字ではなく、毎回届いたArrayの件数と先頭のtextを表示します。
- 件数にはArrayのlength、問題文には先頭のObjectのtextを使います。

loadQuestionsは同梱データを返す教材用の関数です。実ネット通信はしません。関数内のデータと80ミリ秒のtimerは残し、thenで届いた結果を使いましょう。
