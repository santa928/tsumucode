ボタンを押してから問題が届く処理を考えます。Promise（プロミス）は、あとで得られる結果を扱う仕組みです。loadQuestions()の戻り値は問題Arrayそのものではありません。

```js {"label":"結果が届いたら件数を出す","role":"input"}
const pending = loadQuestions();
pending.then((questions) => {
  console.log(questions.length);
});
```

```text {"label":"結果が届いた後のConsole","role":"output"}
2
```

thenは成功時の処理を登録します。そのcallbackの引数questionsに結果のArrayが届きます。コードは次のスライドの関数と組み合わせます。
