演習では「問題を読む」のclick処理に次のコードがあります。変更前は結果を受け取っても固定表示のままです。2枚目の関数は残し、then内の表示を直します。

```js {"label":"変更前：届いたデータを使わない","role":"input"}
loadQuestions().then((questions) => {
  count.textContent = '問題: 0';
  question.textContent = 'まだありません';
});
```

```js {"label":"変更後：結果の件数と問題文を使う","role":"input"}
loadQuestions().then((questions) => {
  count.textContent = '問題: ' + questions.length;
  question.textContent = questions[0].text;
});
```
