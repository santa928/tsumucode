この関数は教材に同梱した問題を返します。サーバーへの通信はしません。setTimeoutは指定ミリ秒より後に処理を呼ぶ予約です。80ミリ秒は待ち方を試すための値で、正確な実行時刻の保証ではありません。

```js {"label":"教材用loadQuestions","role":"input"}
function loadQuestions() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve([{ text: '空は何色？' }, { text: '海は何色？' }]);
    }, 80);
  });
}
```

new Promiseへ渡す関数はすぐ実行され、resolveに渡したArrayが成功結果になります。待機を作るのは中のtimerです。Promiseを書くだけで重い計算が別の場所で動くわけではありません。
