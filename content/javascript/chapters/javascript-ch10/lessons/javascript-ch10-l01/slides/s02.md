この関数は教材に同梱した問題を返します。取得元の準備コードは用意済みです。既習のstateと条件で、最初は2件、2回目以降は別の3件を返します。サーバーへの通信はしません。setTimeoutは指定ミリ秒より後に処理を呼ぶ予約です。80ミリ秒は待ち方を試すための値で、正確な実行時刻の保証ではありません。

```js {"label":"教材用loadQuestions","role":"input"}
let reads = 0;
function loadQuestions() {
  reads += 1;
  const questions =
    reads === 1
      ? [{ text: '空は何色？' }, { text: '海は何色？' }]
      : [{ text: '草は何色？' }, { text: '雲は何色？' }, { text: '雪は何色？' }];
  return new Promise((resolve) => {
    setTimeout(() => resolve(questions), 80);
  });
}
```

new Promiseへ渡す関数はすぐ実行され、resolveに渡したArrayが成功結果になります。待機を作るのは中のtimerです。Promiseを書くだけで重い計算が別の場所で動くわけではありません。
