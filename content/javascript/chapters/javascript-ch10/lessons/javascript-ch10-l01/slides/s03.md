次のHTMLと2枚目の関数を使います。querySelector、Arrayのlength、添字0、Objectのtextは既習です。thenのquestionsという引数名は自分で決められます。

```html {"label":"表示する場所","role":"input"}
<button id="load" type="button">問題を読む</button>
<p id="count">問題: 0</p>
<p id="question">まだありません</p>
```

```js {"label":"2件と最初の問題を表示する","role":"input"}
const count = document.querySelector('#count');
const question = document.querySelector('#question');
loadQuestions().then((questions) => {
  count.textContent = '問題: ' + questions.length;
  question.textContent = questions[0].text;
});
```

1回目は「問題: 2」「空は何色？」、2回目以降は「問題: 3」「草は何色？」へ変わります。届いたArrayを毎回読みます。questionsはcallback内の引数です。結果を使う処理をthenの外に出すと、この引数は使えません。
