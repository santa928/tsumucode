## 終わった後も、次の操作をできるようにする

Starterは読み込み中にボタンを止めますが、完了後に戻し忘れています。showQuestions内のfinallyへ、success.disabled = false; と failure.disabled = false; を加えてください。

- 開始すると「読み込み中...」と表示し、両方のボタンを押せなくします。
- 成功後は「問題: 2」、失敗後は「読み込めませんでした」です。
- どちらの結果の後も両方のボタンを再び操作できます。
- 成功→失敗→成功と続けて試せます。

同梱データを250ミリ秒以降に返す教材用の待機です。実通信はしません。見た目だけ変えるのでなくdisabledで操作可否をそろえ、finallyへ共通の後処理を書きます。
