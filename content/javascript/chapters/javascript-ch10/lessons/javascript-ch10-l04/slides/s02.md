disabled（ディセーブルド）はボタンを操作できなくする性質です。trueで無効、falseで再び有効になります。見た目だけを薄くする処理とは違います。successとfailureは2つのボタンです。

```js {"label":"showQuestionsの最初：読み込み中は始め直さない","role":"input"}
if (loading) return;
loading = true;
success.disabled = true;
failure.disabled = true;
```

loadingは最初falseの変数です。読み込み中はtrueにして、関数がもう一度呼ばれてもreturnで終えます。ボタンも無効にするとマウス・キーボードの両方から二重に開始しません。
