演習のStarterはloadingをfalseに戻しますが、ボタンのdisabledがtrueのままです。finallyへ2行加え、成功後も失敗後も次の操作ができるよう直します。

```js {"label":"変更前：ボタンを戻し忘れている","role":"input"}
  } finally {
    loading = false;
    // ボタンも操作できる状態へ戻しましょう
  }
```

```js {"label":"変更後：両方のボタンを有効にする","role":"input"}
  } finally {
    loading = false;
    success.disabled = false;
    failure.disabled = false;
  }
```

![読み込み中はボタン無効、成功または失敗のあとfinallyでボタンを有効へ戻す](asset:loading-flow)

成功→失敗→成功の順で操作します。待機中の案内と無効化、完了後の表示と再操作をセットで確かめましょう。
