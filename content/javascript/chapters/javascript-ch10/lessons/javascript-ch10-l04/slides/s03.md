finally（ファイナリー）は、tryが成功してもcatchへ進んでも最後に実行する部分です。この教材では読み込み完了後、ボタンを戻す場所に使います。

```js {"label":"async関数の中：失敗してもfinallyへ進む","role":"input"}
try {
  await Promise.reject(new Error('教材の失敗'));
} catch (error) {
  console.log('失敗');
} finally {
  console.log('操作を戻す');
}
```

```text {"label":"Console","role":"output"}
失敗
操作を戻す
```

操作を戻す処理をtryの最後だけへ書くと、失敗時にそこを通れません。finallyで成功・失敗の共通処理をまとめます。
