結果が届くまで何も変わらないと、押せたか分からず何度も押したくなります。開始したら「読み込み中...」、成功なら件数、失敗なら案内を表示します。

```js {"label":"async関数の中：待機中と成功後を分ける","role":"input"}
result.textContent = '読み込み中...';
const questions = await loadQuestions(false);
result.textContent = '問題: ' + questions.length;
```

```text {"label":"画面の変化","role":"output"}
読み込み中...
↓ 結果が届いた後
問題: 2
```

resultは#resultの要素です。loadQuestionsは前単元と同じ同梱データ用関数で、この単元では待機を観察できるよう250ミリ秒以降に結果を渡します。通信はしません。
