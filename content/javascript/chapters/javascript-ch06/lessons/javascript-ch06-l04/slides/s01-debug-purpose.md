動くコードでも、結果が期待と違えばBugがあります。手当たり次第に書き換えると、新しいBugを増やしやすくなります。

Debugでは、期待した結果と実際の結果を比べ、関係するFileと行へ範囲を絞り、原因候補を1点ずつ確かめます。

今回は3問×10点が20点になるBugを直します。

:::practice
prompt: Debugで最初に比べる2つを答えます。
expectedAction: 期待した結果と実際の結果と答える
estimatedMinutes: 1
:::
