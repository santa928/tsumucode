Compositionは必要なobjectを属性として持つ組立てです。委譲は、そのobjectのmethodへ仕事を頼むことです。CounterViewはCounterの一種ではなく、表示用にreadを提供します。渡されたcounterを保持し、calculateを呼ぶ責務だけを持たせます。

```python
class Counter:
    def calculate(self):
        return 6
class CounterView:
    def __init__(self, counter):
        self.counter = counter
    def read(self):
        return self.counter.calculate()
view = CounterView(Counter())
print(view.read())
```
