この単元のcalculateは倍率計算のmethodです。class TripledCounter(Counter)はCounterを基底Classとする宣言です。子に同名のmethodがあれば、子の実装を使います。この上書きをoverrideと呼びます。継承は、その種類として扱ってよいobjectを作る選択で、コードを短くするだけの正解ではありません。

```python
class Counter:
    def calculate(self):
        return 2
class TripledCounter(Counter):
    def calculate(self):
        return 3
print(Counter().calculate())
print(TripledCounter().calculate())
```
