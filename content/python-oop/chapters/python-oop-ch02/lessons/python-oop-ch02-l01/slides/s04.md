演習の3つのClassを定義した後の例です。viewはbaseを保持するのでbaseの変更を読みます。childは別Instanceです。計算の種類を差し替えるなら継承、相手へ頼む表示の窓口ならCompositionと目的から選びます。参照の共有は、望むときだけ明示します。

```python
base = Counter(3)
child = TripledCounter(3)
view = CounterView(base)
base.value = 4
print(view.read())
print(child.calculate())
```
