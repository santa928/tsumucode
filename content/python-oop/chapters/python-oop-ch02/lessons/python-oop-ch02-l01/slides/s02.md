子が初期化methodを定義しなければ、この例では基底の初期化を使います。selfは新しい子Instanceです。基底と子で1つのvalueを共有する意味ではありません。複数の基底やsuperによる協調処理には、ここでは広げません。

```python
class Counter:
    def __init__(self, value):
        self.value = value
class TripledCounter(Counter):
    def calculate(self):
        return self.value * 3
child = TripledCounter(3)
print(child.calculate())
```
