文字列表示用dunderが整数を返すと、printがTypeErrorになります。同様に長さ用dunderは0以上の整数が必要です。好きなdunderを大量に増やすのではなく、そのobjectをどの操作で使いたいかと返却値の契約を対応させます。

```python
class WrongText:
    def __str__(self):
        return 2
try:
    print(WrongText())
except TypeError:
    print("文字列が必要")
```
