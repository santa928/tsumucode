print(shelf)やstr(shelf)は、ここで定義した文字列表示用dunderを使います。返すのは文字列です。len(self)で現在の個数を読み、strで文字列へ変えて連結します。個数を固定表示せず、objectの状態と表示を結びます。

```python
class ReadingList:
    def __init__(self, titles):
        self.titles = list(titles)
    def __len__(self):
        return len(self.titles)
    def __str__(self):
        return "本:" + str(len(self))
shelf = ReadingList(["A", "B"])
print(shelf)
```
