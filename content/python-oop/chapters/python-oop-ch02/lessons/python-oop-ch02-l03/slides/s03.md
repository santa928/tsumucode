Listへの代入だけでは同じListを共有します。list(titles)は外側を浅くコピーするので、元Listへのappendがコピー先の個数を変えません。この教材の要素は文字列です。内部に可変objectを入れた場合の深いコピーまでは扱いません。

```python
titles = ["A", "B"]
copied = list(titles)
shared = titles
titles.append("C")
print(len(copied))
print(len(shared))
```
