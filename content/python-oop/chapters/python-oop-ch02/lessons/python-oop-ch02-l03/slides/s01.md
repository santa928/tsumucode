前後に二重の下線を持つ特別なmethodをdunder methodと呼びます。len(shelf)はClassの長さ用dunderを呼び、0以上の整数を要求します。内部Listの長さを返せば、そのobjectを利用する側もlenを使えます。必要な操作だけを定義します。

```python
class ReadingList:
    def __init__(self, titles):
        self.titles = list(titles)
    def __len__(self):
        return len(self.titles)
print(len(ReadingList(["A", "B"])))
```
