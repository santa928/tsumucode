Propertyの読取りと代入を区別し、初期化・代入の値検証と拒否後の値保持を説明できる。

setterで下限0と上限100を検証してから、内部の_valueへ代入します。

Class定義の後に用意した観察行の順序・呼出形式・値は変更せず、定義を修正します。定義内の引数名や乗算の順、1つの途中値を返す書き方など、同じ目的の別解を扱います。

valueを窓口、_valueを保存先とします。範囲外の検証はorによる比較、2つのif、notと連鎖比較、正条件の連鎖比較とelseの別解を扱います。一般descriptorの実装は対象外です。

出力の直書きでは合格しません。同じSourceの実出力と限定AST事実を照合します。実行エラーと未達を区別し、対応外の構文は採点しません。

正しい修正後の出力は次のとおりです。

```text
70
90
50
範囲外
90
範囲外
90
0
100
初期値も範囲外
```
