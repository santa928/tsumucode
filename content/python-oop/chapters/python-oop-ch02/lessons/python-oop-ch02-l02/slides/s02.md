@value.setterは同じ名前valueの書込み処理を定義します。score.value = 90がsetterを呼び、条件を満たしてから_valueへ保存します。内部でもself.valueへ代入すると再びsetterを呼ぶので、保存先を区別します。この最小例は代入から初期値を作ります。

```python
class Score:
    @property
    def value(self):
        return self._value
    @value.setter
    def value(self, value):
        if value < 0 or value > 100:
            raise ValueError("0から100")
        self._value = value
score = Score()
score.value = 90
print(score.value)
```
