演習のScore定義後の例です。0から100を有効とし、範囲外はValueErrorで拒否します。基礎で使ったtryとexceptで、その例外を受け止めます。検証前に内部値を変えると、例外を出しても値は元へ戻りません。

```python
score = Score(70)
try:
    score.value = 101
except ValueError:
    print("範囲外")
print(score.value)
```
