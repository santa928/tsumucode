演習のScore定義後の比較です。初期化でもself.valueへ代入すればsetterの検証を通せます。最初だけ_valueへ直接保存すると、不正な初期値を見逃します。別Instanceは個別の_valueを持ち、一方の更新が他方へ漏れないことも確認します。

```python
first = Score(70)
second = Score(50)
first.value = 90
print(first.value)
print(second.value)
```
