@propertyを付けたvalueは、score.valueという読取りでgetterを呼びます。利用側は括弧を付けません。_valueは内部用という命名の慣習で、秘密を保護する仕組みではありません。ここでは読み書きの窓口だけを学び、descriptor自体の実装は扱いません。

```python
class Score:
    def __init__(self, value):
        self._value = value
    @property
    def value(self):
        return self._value
score = Score(70)
print(score.value)
```
