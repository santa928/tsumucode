演習のwraps付きcount_callsが定義済みとします。checkedの名前を保ち、引数と戻り値と例外を中継します。同じwrapperでは回数を引き継ぎ、別の装飾Functionは別のcountを使います。from functools import wrapsと@wraps(function)の代わりに、moduleをimportする形やwrapper = wraps(function)(wrapper)の明示適用も比較できます。引数付きdecoratorや制作は次の単元で扱います。

```python
@count_calls
def checked(value):
    """負の値を拒否して2倍する。"""
    if value < 0:
        raise ValueError("負の値")
    return value * 2
print(checked.__name__)
print(checked(3))
try:
    checked(-1)
except ValueError as error:
    print(str(error))
```
