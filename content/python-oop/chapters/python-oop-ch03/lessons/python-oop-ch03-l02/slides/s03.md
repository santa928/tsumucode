前のSlideのaddとwrapsを使います。wrapsはmetadataを引き継ぐ補助で、引数の受け渡し・return・例外の伝播を自動で正しくする仕組みではありません。例では名前が一致しても、元のFunctionを実行せず0を返しています。名前の確認と、異なる引数や実エラーの動作確認を組み合わせます。

```python
@wraps(add)
def wrong(value):
    return 0
print(wrong.__name__ == add.__name__)
print(wrong(3))
```
