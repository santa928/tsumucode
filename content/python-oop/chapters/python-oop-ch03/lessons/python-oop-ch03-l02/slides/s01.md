Functionが持つ名前やdocstringなどの説明情報をmetadataと呼びます。docstringは定義本体の最初に置く文字列です。このwrapperはaddへ引数と戻り値を渡せますが、名前と説明はwrapper自身のものです。利用者向けの説明や調査で、元のFunctionの情報を見つけにくくなります。

```python
def hide(function):
    def wrapper(value):
        """中継用の説明。"""
        return function(value)
    return wrapper
def add(value):
    """1を足す。"""
    return value + 1
wrapped = hide(add)
print(wrapped.__name__)
print(wrapped.__doc__)
print(wrapped(3))
```
