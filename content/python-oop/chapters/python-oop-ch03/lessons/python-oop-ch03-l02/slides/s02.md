標準ライブラリfunctoolsのwrapsをimportします。@wraps(function)をwrapperへ付けると、元の名前やdocstringなどを引き継ぎ、元のFunctionへの参照も付けます。最後のisは同じobjectへの参照かを比較します。wrapperは別のFunctionのままであり、元のFunctionそのものに置き換わるわけではありません。

```python
from functools import wraps
def keep(function):
    @wraps(function)
    def wrapper(value):
        return function(value)
    return wrapper
def add(value):
    """1を足す。"""
    return value + 1
wrapped = keep(add)
print(wrapped.__name__)
print(wrapped.__wrapped__ is add)
```
