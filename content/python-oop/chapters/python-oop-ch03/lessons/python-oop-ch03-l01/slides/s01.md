Functionは呼び出すだけでなく、値として変数へ代入し、引数に渡せます。addはFunction object、add(3)は実行した結果です。ここでは変換用のtransformへaddを渡し、新しいwrapperを受け取ります。元のaddの計算はそのまま残り、convertedだけに後処理が加わります。

```python
def add(value):
    return value + 1
def transform(function):
    def wrapper(value):
        return function(value) * 2
    return wrapper
converted = transform(add)
print(converted(3))
print(add(3))
```
