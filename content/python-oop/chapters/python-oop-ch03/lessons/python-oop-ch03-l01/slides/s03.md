wrapperの定義で、星印1つのargsは位置引数をtupleへ、星印2つのkwargsは名前付き引数をdictへ集めます。呼出し側では、集めたtupleとdictを星印1つ・2つでそれぞれ展開し、元のFunctionへ渡します。argsとkwargsは慣習名で、別の名前も使えます。returnがなければ、元の計算が正しくてもwrapperの結果はNoneになります。

```python
def forward(function):
    def wrapper(*args, **kwargs):
        return function(*args, **kwargs)
    return wrapper
def add(value, extra=0):
    return value + extra
wrapped = forward(add)
print(wrapped(3, extra=2))
```
