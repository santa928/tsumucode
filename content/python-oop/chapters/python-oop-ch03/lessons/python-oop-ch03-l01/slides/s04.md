演習の正しいcount_callsが定義済みとします。@count_callsは、直後のdefで作ったFunctionをcount_callsへ渡し、返ったFunctionを同じ名前へ結び直す記法です。この単一decoratorの例は、defの後のchecked = count_calls(checked)と対応します。装飾時にcheckedの本体を実行するわけではありません。wrapperが捕捉しなければ、元の例外も呼出し元へ届きます。

```python
@count_calls
def checked(value):
    if value < 0:
        raise ValueError("負の値")
    return value * 2
try:
    checked(-1)
except ValueError as error:
    print(str(error))
```
