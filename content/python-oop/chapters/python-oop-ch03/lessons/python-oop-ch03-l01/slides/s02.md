外側の呼出しが終わっても、内側のFunctionは必要な外側の変数を参照できます。これをClosureと呼びます。nonlocalは、この例では1つ外側にあるcountへ再代入する宣言です。make_counterを呼ぶたびに別のcountが生まれ、同じfirstの連続呼出しだけが状態を共有します。これはdecoratorの前に状態だけを確かめる例です。

```python
def make_counter():
    count = 0
    def next_count():
        nonlocal count
        count += 1
        return count
    return next_count
first = make_counter()
second = make_counter()
print(first(), first(), second())
```
