labelは設定時のClosureへ保持します。callsはdecorateの中で0にし、装飾のたびに別の状態を作ります。factory側へcallsを置くと、同じ設定を再利用したwrapper同士で意図せず共有します。

```python
configured = trace_calls("共有設定")
first = configured(add)
second = configured(add)
print(first(2))
print(first(3))
print(second(4))
```
