設定を受け取る層を増やしても、引数・戻り値・例外・metadataは前単元と同じ契約です。回数は元を呼ぶ前に増えるため、例外でも増加は残ります。wrapsだけでは中継や状態分離は保証されません。

```python
@trace_calls("検査")
def checked(value, extra=0):
    """値を検査する。"""
    if value < 0:
        raise ValueError("負の値")
    return value + extra
print(checked(2, extra=3))
try:
    checked(-1)
except ValueError as error:
    print(str(error))
print(checked.__name__)
```
