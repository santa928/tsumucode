3つの時点で実行する本体が変わります。次は関係を表示する短い例です。wrapsと回数は省いて時点だけを観察します。@factory("記録")も、factoryの結果へFunctionを渡す装飾です。

```python
def factory(label):
    print("設定", label)
    def decorate(function):
        print("装飾", function.__name__)
        def wrapper(value):
            print("呼出", label)
            return function(value)
        return wrapper
    return decorate
wrapped = factory("記録")(add)
print(wrapped(2))
```
