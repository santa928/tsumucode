引数付きdecoratorは、設定からdecoratorを作るFunctionです。trace_calls("加算")の戻り値configuredは、まだ元の計算を実行しません。configured(add)が装飾済みFunctionを返します。ここでは既習のtrace_callsとaddを使います。

```python
configured = trace_calls("加算")
wrapped = configured(add)
print(wrapped(3, extra=2))
```
