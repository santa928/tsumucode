selfは呼出先Instanceを受けます。first.doubled()ではfirstが暗黙に先頭へ渡り、Counter.doubled(first)では同じInstanceを明示します。Classから呼ぶ通常methodへ引数を渡さなければ、必要なselfが足りずTypeErrorです。self.valueとself.factorから計算します。

```python
class Counter:
    factor = 2

    def __init__(self, value):
        self.value = value

    def doubled(self):
        return self.value * self.factor

first = Counter(3)
print(first.doubled())
print(Counter.doubled(first))
```

Class内のdefと、Class外の呼出しを分けて読みます。両方6です。
