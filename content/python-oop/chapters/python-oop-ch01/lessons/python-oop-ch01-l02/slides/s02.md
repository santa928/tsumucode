@classmethodは、ここでは先頭へ呼出先Classを渡す指定です。clsはそれを受ける引数の慣習名です。Counter.doubled_from(3)の実引数はCounterと3で、cls.factorを参照します。利用者がCounterをもう一度渡すと余分な引数となります。@記法の一般的な関数変換は後続教材で扱います。

```python
class Counter:
    factor = 2
    @classmethod
    def doubled_from(cls, value):
        return value * cls.factor

print(Counter.doubled_from(3))
Counter.factor = 4
print(Counter.doubled_from(3))
```

Class内で定義したmethodを、Class外から呼び出します。
