演習のCounter全体を定義し、firstのvalueが3、Classのfactorが2の場面です。以下の4行は同じ計算で6になります。通常methodの2つの呼出しも並べ、暗黙の引数を比較します。倍率4へ変えた後の計算は演習で確かめます。

```python
print(first.doubled())
print(Counter.doubled(first))
print(Counter.doubled_from(3))
print(Counter.doubled_value(3, 2))
```
