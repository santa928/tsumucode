@staticmethodはInstanceやClassを先頭へ補いません。ここではvalueとfactorを両方明示し、その値だけから同じ倍率計算を行います。Class内へ置くと関連する計算をまとめられますが、普通のFunctionも選択肢です。どれが常に優れている、という分類ではありません。

```python
class Counter:
    @staticmethod
    def doubled_value(value, factor):
        return value * factor

print(Counter.doubled_value(3, 2))
Counter.factor = 4
print(Counter.doubled_value(3, 2))
```

Class内で定義したmethodを、Class外から呼び出します。
