別Instanceと同じ参照を区別し、Instance属性が同名のClass属性を隠すことを実出力で説明できる。

Class名・Instance名・引数名は変えても構いません。属性value/factorとmethod名、表示する比較の順序はこの演習の契約です。出力の直書きは達成としません。imports・継承・任意decorator・私有属性など説明範囲外の構文は採点せず、Sourceを保持します。

実行前に出力を予測し、変更後は出力欄の値を同じ順序で比べてください。誤ったmethod呼出しは実際のTypeErrorとして表示され、環境障害と未達成を区別します。「ヒントを見る」・「最初に戻す」と保存済みの下書きを使って再試行できます。途中でコースへ戻ったときは「レッスンを再開する」で編集中の演習へ戻れます。
