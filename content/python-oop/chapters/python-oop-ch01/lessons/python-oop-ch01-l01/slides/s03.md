この例では、InstanceにfactorがなければClassのfactorを読みます。first.factor = 7はfirstに同名の属性を作り、Classのfactorを隠します。Classの値を4へ変えてもfirstは7、独自factorを持たないsecondは4です。共有するのはClass上の属性で、個別のvalueとは別です。

```python
class Counter:
    def __init__(self, value):
        self.value = value

Counter.factor = 2
first = Counter(3)
second = Counter(5)
first.factor = 7
Counter.factor = 4
print(first.factor)
print(second.factor)
```
