dataclassで見た個別の値を、今度は自分でClassへ定義します。Classはobjectを作るときの型です。Counter(3)は新しいInstanceを作り、下の初期化methodへそのInstanceと3を渡します。selfはそのInstanceを受ける引数の慣習名です。特別な予約語ではありません。

```python
class Counter:
    def __init__(self, value):
        self.value = value

first = Counter(3)
second = Counter(5)
print(first.value)
print(second.value)
```
