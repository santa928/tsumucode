alias = firstはobjectを複製せず、同じobjectへ別の名前を付けます。Counter(3)をもう一度呼ぶと、値が同じでも新しいInstanceです。isは同じobjectかを比較します。==は型が定める等価性の比較なので、identity確認の代わりにはしません。

```python
class Counter:
    def __init__(self, value):
        self.value = value

first = Counter(3)
second = Counter(3)
alias = first
print(first is alias)
print(first is second)
```
