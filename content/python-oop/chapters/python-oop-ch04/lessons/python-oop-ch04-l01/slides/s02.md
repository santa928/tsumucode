decoratorは回数の表示を受け持ち、bookは通常記録、bonusは2倍の特典を計算し、Ledger.addが値を検証して記録します。wrapperが固定値を返すだけでは、totalも元の戻り値も保てません。metadataも別に確認します。

```python
ledger = Ledger()
print(book(ledger, 2, extra=1))
print(bonus(ledger, 3))
print(book.__name__, bonus.__name__)
print(book.__doc__ == book.__wrapped__.__doc__)
```
