Projectでは記録のtotalをLedgerのInstanceへ置き、回数を各wrapperへ置きます。bookとagainは同じ設定でも別のwrapperです。Ledgerは前章と同じClassとInstance methodで、selfが呼出先を受けます。

```python
first = Ledger()
second = Ledger()
print(book(first, 3, extra=2))
print(book(first, 1))
print(bonus(second, 2, extra=1))
print(first.total, second.total)
```
