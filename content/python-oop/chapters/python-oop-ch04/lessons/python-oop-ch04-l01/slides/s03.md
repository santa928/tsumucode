負値はLedger.addで更新前に拒否します。例外はwrapperから呼出元へ伝わり、回数は増えても記録値は変わりません。Sourceを保存して再読込で再開し、最初に戻すでstarterへ戻せます。移動には既存JSON転送を使います。

```python
ledger = Ledger()
print(book(ledger, 2))
try:
    book(ledger, -1)
except ValueError as error:
    print(str(error))
print(ledger.total)
print(book(ledger, 1))
```
