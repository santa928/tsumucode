catchの失敗もunknownです。instanceof Errorで絞って実messageを渡し、それ以外は不明な失敗として案内します。readButtonはEventのcurrentTargetをHTMLButtonElementか確認した既習処理です。別の対象やnullを、押したbuttonとして決めつけません。

```ts
function failure(error: unknown): string {
  if (error instanceof Error) return error.message;
  return '不明な失敗です';
}
```
