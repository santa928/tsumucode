提供loadQuestionsは通信せず、後でunknownの要素が並ぶ配列を返します。readQuestionsのawait後に各値をdecodeQuestionへ渡します。正しい値は新しいQuestionへ、不正ならinvalidへ。拒否はfailedへ分け、LoadResultのkindから提供UIが表示を選びます。

```ts
type Reply = { kind: 'ready'; text: string } | { kind: 'invalid' };
const reply: Reply = { kind: 'invalid' };
```
