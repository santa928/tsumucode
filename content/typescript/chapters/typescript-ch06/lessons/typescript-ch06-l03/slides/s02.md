object・非null・inとtypeofで項目を確認します。Array.isArrayは配列か調べますが、各要素がstringとはまだ言えません。choices[0]と[1]をunknownとして取り出し、両方string、長さ2、correctがそのどちらかかを確認します。asで決めつける確認とは異なります。

```ts
function label(value: unknown): string | undefined {
  if (typeof value !== 'string') return undefined;
  return value;
}
```
