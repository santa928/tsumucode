型のexport interfaceは別Moduleがその型名を読めるようにします。提供quiz-ui.tsのimport typeは型だけのimportで、実行JSへ残りません。main.tsの通常importは関数を読み込みます。.jsの参照名は変換後の名前で、実Compilerが対応する.tsを探します。提供Fileの編集は不要です。

```ts
export interface Label {
  text: string;
}
// 別のModuleがこの型を読む例
// import type { Label } from './main.js';
```
