選択肢は2つのstringを並べる配列です。readonly string[]は要素の読み取りを許し、この参照からpushや書き込みをさせない型です。実行時にfreezeする処理ではありません。Question[]はQuestionが並ぶ配列で、Questionひとつとは区別します。

```ts
interface OptionSet {
  choices: readonly string[];
}
const set: OptionSet = { choices: ['a', 'b'] };
const last: string | undefined = set.choices[1];
```
