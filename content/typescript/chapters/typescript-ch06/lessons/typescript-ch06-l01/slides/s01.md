既存JS作品と同じWebとLogic、各2問を使います。最初の工程は型付きデータと問題表示です。回答・得点と非同期境界は後の工程です。提供UIはmain.tsのデータと関数を呼びます。型が合っても問題文や正答が正しいとは限らないので、実表示も確認します。

```ts
type Category = 'web' | 'logic';
interface Topic {
  category: Category;
  text: string;
}
const topic: Topic = { category: 'web', text: 'Webの役割' };
```
