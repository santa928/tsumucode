advanceは回答後だけindexを進め、scoreを保ちansweredをfalseへ戻します。提供UIの再挑戦はcreateStateを再利用し、選んだカテゴリを保ちます。文字を消すだけでは、次の回答へ古いscoreやindexが残ります。createStateの0・0・falseを実操作でも確かめます。

```ts
interface Progress {
  readonly index: number;
}
function next(state: Progress): Progress {
  return { index: state.index + 1 };
}
```
