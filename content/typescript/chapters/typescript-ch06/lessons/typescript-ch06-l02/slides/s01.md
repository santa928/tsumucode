QuizStateのindexとscoreはnumber、answeredはbooleanです。readonlyの項目は入力から書き換えず、新しい状態を返してUIへ渡します。readonlyは実行時のfreezeではありません。同じnumber型でも0点と誤った99点は区別できないため、正誤と実得点も判定します。

```ts
interface Counter {
  readonly value: number;
}
function increment(state: Counter): Counter {
  return { value: state.value + 1 };
}
```
