answerはstate・question・choiceを受け取り、QuizStateを返します。回答済みなら前の状態を保ちます。新しい回答では実choiceと実correctを比較し、正解だけ1点を加えます。三項演算子は条件がtrueなら前の値、falseなら後の値を使います。

```ts
function points(choice: string, correct: string): number {
  return choice === correct ? 1 : 0;
}
```
