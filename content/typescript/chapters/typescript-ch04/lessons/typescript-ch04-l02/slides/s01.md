前のLessonでは入出力をnumberとしました。同じ値を返すだけの処理でも、number専用では文字列を受け取れません。タイトルを渡すこのコードは型診断2345と2322になります。

```ts
function keep(value: number): number {
  return value;
}
const title: string = keep('型のクイズ');
```

anyにすると受け取る値と返す値の関係を型で確認できなくなります。型が通ることだけを目標にせず、「渡した型と同じ型が戻る」という関係を表します。
