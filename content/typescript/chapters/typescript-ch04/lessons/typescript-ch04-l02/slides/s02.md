generic（ジェネリック）は、型を受け取って再利用する仕組みです。関数名の後ろで宣言するTは型パラメータという型の名前。同じTを引数と戻り値へ使うと、受け取った型と返す型を結べます。Tという文字自体は変更できます。

```ts
function keep<T>(value: T): T {
  return value;
}
```

処理はreturn valueで受け取った値を返すだけです。型は実行時に値を変換しません。Tの型なら何でも同じ値を返すので、固定の数値を返す実装にはできません。
