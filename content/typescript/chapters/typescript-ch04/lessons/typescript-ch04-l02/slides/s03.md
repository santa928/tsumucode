前のkeepを使います。2を渡すと数値、タイトルを渡すと文字列として結果を受け取れます。呼出しの値からTが推論されます。呼出しでnumberを明記するなど、渡す型を型引数と呼びます。型は明記もできます。

```ts
const points: number = keep(2);
const title: string = keep('型のクイズ');
```

number/stringの受取先注釈で、結果の型が合うかを確認します。numberを型引数にしたkeepへ文字列は渡せず、数値の結果をstringへ代入することもできません。両方受け取るunionだけでは、どちらが戻るかという対応を保てません。
