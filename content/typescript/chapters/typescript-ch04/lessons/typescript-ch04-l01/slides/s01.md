引数の型注釈は受け取る値の型です。戻り値の型注釈は、括弧の後ろの: numberで、returnする値の型を示します。JavaScriptの関数とreturnに、型の確認を加えます。

```ts
function double(value: number): number {
  return value * 2;
}
console.log(double(3));
```

結果は6です。数値を渡し、数値を返す処理を確認できます。引数へ文字列を渡すと型診断2345、文字列をreturnすると2322になります。型は2倍という正しい計算までは決めません。
