関数型は、どんな値を受け取り何を返す関数かを表す型です。(value: number) => numberは数値を1つ受け取り数値を返す関数。type aliasでOperationと名付けます。型の中にも引数名を書きます。

```ts
type Operation = (value: number) => number;
```

callback（コールバック）は、別の関数へ渡し、その中から呼び出してもらう関数です。Operationは型だけなので、実行時の処理は作りません。確認はnumberの入出力、処理は次のコードで分けて書きます。
