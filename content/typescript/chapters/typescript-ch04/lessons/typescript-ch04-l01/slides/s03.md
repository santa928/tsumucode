前のOperationを使います。applyは受け取ったoperationをvalueで呼び、その結果をreturnします。doubleは数値を2倍にするarrow関数です。値の=>の右側は処理、型の=>の右側は戻り値の型です。

```ts
function apply(value: number, operation: Operation): number {
  return operation(value);
}
const double: Operation = (value) => value * 2;
```

doubleにはOperationの型注釈があります。この周囲の型から引数valueがnumberと推論されることを文脈による推論と呼びます。引数をnumberと明記する関数宣言も使えます。型は消えますが、呼出しと計算は実行されます。
