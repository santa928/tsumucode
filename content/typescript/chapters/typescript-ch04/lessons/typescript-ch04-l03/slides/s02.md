配列の...はspread（展開）で、元の配列の要素を新しい配列へ入れます。[...points, 3]は元の要素の後ろへ3を加えた別の配列。入力へpushせず、新しい配列をreturnします。

```ts
function addPoint(points: readonly number[]): number[] {
  return [...points, 3];
}
```

読み取り専用の入力から、変更可能な出力を作れます。points.concat(3)で新しい配列を作る別解もあります。この数値配列では元と結果が別になることを確認します。

:::practice
prompt: 元の入力が1,2なら、新しい配列は何ですか。元は変わりますか。
expectedAction: 新しい配列は1,2,3、元は1,2のまま
estimatedMinutes: 1
:::
