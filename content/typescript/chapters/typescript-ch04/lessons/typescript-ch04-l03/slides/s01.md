readonly（読み取り専用）は、その型の参照からの書込みを型検査で止める指定です。readonly number[]は数値の読み取り専用配列。戻り値のnumber[]は変更可能な配列を表します。

```ts
function addPoint(points: readonly number[]): number[] {
  points.push(3);
  return [...points];
}
```

このコードは型診断2339で止まります。readonlyの配列にはpushがありません。要素への代入も型で止まります。readonlyは実行時に値を凍結する機能ではなく、型が消えた後の値を保護しません。
