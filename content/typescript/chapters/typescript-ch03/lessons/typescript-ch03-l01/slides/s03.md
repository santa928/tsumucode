narrowing（型の絞り込み）は、条件で値を確認し、その場所で扱える型を狭めることです。正解と分かる分岐ではpointsを読めます。elseでは残る不正解のmessageを読めます。

```ts
function label(result: Result) {
  if (result.kind === 'correct') {
    return result.points;
  } else {
    return result.message;
  }
}
```

ifは実行時にも状態を調べます。型を書くだけで分岐するわけではありません。returnする値は引数の中から選び、2やメッセージを固定して返しません。

prompt: kindがincorrectなら、どちらのreturnを通りますか。
