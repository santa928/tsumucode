関数の引数（受け取る値）にも型注釈を付けられます。result: ResultはResultを受け取るという意味です。JavaScriptで学んだreturnは呼出し元へ値を返します。型は1枚目と同じです。

```ts
function label(result: Result) {
  return result.points;
}
```

このコードは型診断2339になります。不正解の値にはpointsがないからです。型検査は宣言した両方の形を考えるため、正解の値だけを渡す例でも、未確認のアクセスには型診断が出ます。
