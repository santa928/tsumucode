union（ユニオン）は、複数の型のどれかを受け取る型です。`|`でつなぎます。literal（リテラル）の型は、ここでは文字列の値をそのまま限定した型です。kindはcorrectかincorrectで、ただのstringより狭くなります。

```ts
type Result = { kind: 'correct'; points: number } | { kind: 'incorrect'; message: string };
```

正解の形にはpoints、不正解の形にはmessageがあります。type aliasで2つの形をResultと名付けました。kindは状態を見分ける共通の項目です。型は正しい答えそのものを決めません。
