undefinedでないと確認した分岐ではhintが文字列に絞られ、lengthを読めます。ない側ではヒントなしを返します。確認はJavaScriptのifとして実行時にも働きます。

```ts
function hintLength(feedback: Feedback) {
  if (feedback.hint !== undefined) {
    return feedback.hint.length;
  } else {
    return 'ヒントなし';
  }
}
```

空文字もundefinedではないので、ある側で長さ0を返します。型の絞り込みと、利用者へ何を返すかという動作を両方確認します。
