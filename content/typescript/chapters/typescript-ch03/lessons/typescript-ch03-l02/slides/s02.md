関数の引数の注釈は1枚目のFeedbackです。文字列の.lengthは長さを読みます。この教材の「見る」は2、空文字は0です。

```ts
function hintLength(feedback: Feedback) {
  return feedback.hint.length;
}
```

型診断18048が出ます。hintはundefinedかもしれず、その長さは読めないからです。型の案内を無視して実行するのではなく、ない場合を先に分けます。
