optional（オプショナル）は、項目を省略できることです。項目名の後ろに?を書きます。undefinedは、ここでは省略された項目を読んだときの値です。

```ts
interface Feedback {
  hint?: string;
}
const present: Feedback = { hint: '見る' };
const absent: Feedback = {};
```

hintを読むとstringかundefinedなので、文字列だけとしては扱えません。この教材の設定では、hintを省略することとhint: undefinedを明示することも区別します。空文字は文字列の値です。
