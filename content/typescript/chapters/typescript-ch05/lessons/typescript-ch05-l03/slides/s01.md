Promiseは、後で成功の値または失敗が決まる処理を表す値です。async関数はPromiseを返します。Promiseの結果型unknownは、成功しても形をまだ確認していないことを示します。

```ts
type LoadMode = 'success' | 'invalid' | 'failure';
async function load(mode: LoadMode): Promise<unknown> {
  if (mode === 'failure') throw new Error('再試行できます');
  if (mode === 'invalid') return { points: 'wrong' };
  return { points: 2 };
}
```

LoadModeはsuccess・invalid・failureのliteral unionです。同梱の3結果を選ぶだけで通信しません。Errorは理由のmessageを持つ失敗の値、throwはその値で処理を失敗させます。
