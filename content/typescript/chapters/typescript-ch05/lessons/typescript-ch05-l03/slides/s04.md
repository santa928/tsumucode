前のshowをボタンから呼びます。void showは戻ったPromiseをここでは値として使わない書き方で、show内のtry/catchが成功と失敗を表示します。

```ts
success.addEventListener('click', () => {
  void show('success');
});
```

正常→不正データ→拒否→正常の順で実DOMを確かめます。編集中の新ソースを古い非同期結果で合格にせず、停止後に再試行しても元TSを保持します。Promiseの型だけの成功を、処理の正しさの代用にしません。
