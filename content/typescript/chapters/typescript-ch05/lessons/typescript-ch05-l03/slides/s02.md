awaitはPromiseの結果を待ちます。既習のformatPointsはunknownの項目を実検証します。正常な結果なら2、不正な項目なら不正なデータです。

```ts
const data: unknown = await load(mode);
output.textContent = formatPoints(data);
```

showはasyncなので、戻り値はvoidを結果とするPromiseです。voidはPromiseの成功結果として使う値がないことを示します。outputのnull確認後にtryの中で待ち、成功した実値をそのまま検証へ渡します。
