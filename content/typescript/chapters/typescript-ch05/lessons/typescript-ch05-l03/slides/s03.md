tryは失敗を受け止めたい処理の範囲、catchは失敗した値を受け取る側です。拒否の操作では再試行できますを表示します。

```ts
try {
  const data: unknown = await load(mode);
  output.textContent = formatPoints(data);
} catch (error: unknown) {
  output.textContent = error instanceof Error ? error.message : '理由が不明です';
}
```

throwできるのはErrorだけではありません。instanceof Errorで種類を確認し、違う値には別の案内を出します。as Errorと書くだけでは検証になりません。元ソースを保持し、拒否後も正常な操作を試せます。
