前のreadAnswerを使います。answerとoutputはquerySelectorで取得し、両方のnull確認が済んだ範囲です。addEventListenerは登録した出来事で関数を呼びます。

```ts
answer.addEventListener('click', (event: Event) => {
  output.textContent = readAnswer(event);
});
```

buttonの内側のspanを押した場合、targetは出発点のspan、currentTargetは登録先のbuttonです。currentTargetはhandlerの実行中に読みます。Eventとその対象を、数値やbuttonの型と取り違えません。
