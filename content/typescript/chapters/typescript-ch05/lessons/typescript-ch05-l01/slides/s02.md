Eventはブラウザの出来事を表す値の型です。currentTargetはこのhandlerを登録した対象で、nullの場合もあります。HTMLButtonElementはブラウザのbutton要素の種類です。

```ts
function readAnswer(event: Event): string {
  const target = event.currentTarget;
  if (target instanceof HTMLButtonElement) {
    return target.dataset.answer ?? '未指定';
  }
  return '対象が違います';
}
```

instanceofは実際の種類を調べます。buttonの側だけdatasetのdata-answerを読めます。??はnullかundefinedのときだけ未指定を選びます。表示は2、別要素なら対象が違いますです。
