DOMはページの要素をJavaScriptから扱う仕組みです。querySelectorは指定した要素を探し、見つからなければnullを返します。nullは値がないことを示します。

```ts
const output = document.querySelector('#output');
if (output !== null) {
  output.textContent = '待機';
}
```

見つかった側だけでtextContentへ表示を書きます。型注釈で要素を決めつけても、見つからない可能性は消えません。
