Event: stringのように出来事を文字列と決めつけず、Eventと書きます。datasetはdata-*属性を文字列で読む仕組みで、今回data-answerが2です。

```ts
const target = event.currentTarget;
if (target instanceof HTMLButtonElement) {
  return target.dataset.answer ?? '未指定';
}
```

予測してから修正し、ボタンの2、対象違いの案内、要素未検出の安全な待機を分けます。型確認は実DOMの操作と組み合わせて採点します。固定表示の2だけでは合格になりません。
