前の4条件をformatPointsのifへ入れます。Stringは値を表示用の文字列へ変換します。数値2なら2、文字列の項目とnullは不正なデータです。

```ts
if (
  typeof value === 'object' &&
  value !== null &&
  'points' in value &&
  typeof value.points === 'number'
) {
  return String(value.points);
}
return '不正なデータ';
```

asでpointsの形を書いても、この確認は実行されません。固定の2を返すだけでも、受け取った実値を読んだ証拠になりません。型と実際の3操作の両方を確認します。
