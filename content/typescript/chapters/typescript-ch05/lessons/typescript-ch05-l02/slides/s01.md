unknownは形が分からない値の型です。どんな値も受け取れますが、そのままpointsを読むことはできません。このコードは型エラーになります。

```ts
function formatPoints(value: unknown): string {
  return String(value.points);
}
```

anyは確認を避けて読めてしまいます。unknownは確認を要求する入口です。型が書かれただけで外から来る値が正しくなるわけではありません。今回は通信せず同梱の値で試します。
