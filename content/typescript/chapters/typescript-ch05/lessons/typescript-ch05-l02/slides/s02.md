typeofは実行時の値の種類を文字列で調べます。typeof nullもobjectなので、nullではない確認が必要です。inはその名前の項目があるかを調べます。

```ts
typeof value === 'object' &&
  value !== null &&
  'points' in value &&
  typeof value.points === 'number';
```

pointsがあっても数値とは限りません。最後にnumberかを調べます。条件は左から短絡評価され、前の確認が済んだ値を次で使えます。今回の小さいデータの数値項目だけを検証します。
