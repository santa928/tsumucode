引数は、呼び出す側から関数へ渡す値の受け取り口です。def show_sum(left, right)と定義すると、show_sum(3, 5)の3はleft、5はrightへ入ります。呼ぶたびに値を渡せるため、関数内へ数字を書き直す必要はありません。

```python
def show_sum(left, right):
    print(left + right)
show_sum(3, 5)
```
