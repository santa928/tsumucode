lesson_tools.pyのaddをmain.pyへ取り込みます。importは名前を使えるようにし、呼び出しの括弧で処理を実行します。

lesson_tools.py:

```python
def add(left, right):
    return left + right
```

main.py:

```python
from lesson_tools import add
print(add(3, 5))
```

8です。
