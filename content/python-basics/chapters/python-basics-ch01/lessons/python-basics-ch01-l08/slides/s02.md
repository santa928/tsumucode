まずleft + leftのまま2組の値を渡すと何が表示されるか予測してください。2つの引数を両方使うよう修正し、3と5、4と6をそれぞれ渡す呼び出しを書きます。8と10の2行を確認してください。

自分で決める範囲は「呼び出しに渡す値と関数内の式」です。ヒントは必要な段階だけ開きます。名前の変更や足す順序、計算結果を一時変数に保存する別解も使えます。

:::prediction
prompt: "完成後の出力を、実行前に順番に言えますか。"
answer: "8、10です。"
explanation: "実行の後は、どの行がその値を作ったかも確認します。"
:::
