main.pyとlesson_tools.pyは専用Workspaceの2ファイルです。helperを保存した後に再実行すると新しい関数を使います。任意pathやstdlibのimportは対象外です。

```python
from lesson_tools import add
print(add(3, 5))
print(add(4, 6))
```

正しいhelperでは8、10です。

explanation: "各呼び出しのleftを2回足すためです。修正後は再実行して変化を比べます。"
