returnで値を返さずに関数が終わると、呼び出した場所へNoneが返ります。Noneは「値がないこと」を表す特別な値で、print(None)はNoneと表示します。関数内のprintが8を表示しても、呼び出し元に8が返るわけではありません。表示と値の受け渡しを分けて読みましょう。

```python
def show_sum(left, right):
    print(left + right)
shown = show_sum(3, 5)
print(shown)
```
