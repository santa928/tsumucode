最初に出力の行数と順番を予測してください。表示だけの関数を残し、別に2引数の和を返す関数を自作します。表示だけの関数の戻り値を変数へ受け取って表示し、値を返す関数の戻り値も表示してください。出力は8、None、8の3行です。Noneという文字列を直接表示する方法では違いを確認できません。

自分で決める範囲は「2つの関数の役割と戻り値の表示位置」です。ヒントは必要な段階だけ開きます。名前の変更や足す順序、計算結果を一時変数に保存する別解も使えます。

:::prediction
prompt: "完成後の出力を、実行前に順番に言えますか。"
answer: "8、None、8です。"
explanation: "実行の後は、どの行がその値を作ったかも確認します。"
:::
