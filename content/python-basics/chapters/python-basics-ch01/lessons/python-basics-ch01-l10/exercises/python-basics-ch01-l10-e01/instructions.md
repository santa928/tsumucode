## 今回の仕様

用意された`show_sum`は和を表示しますが、`return`で値を返していません。この関数を呼んだ結果を受け取ると、`None`になります。画面に見えた`8`と、受け取った値を分けて考えましょう。

この関数は残し、別に2つの値の和を返す関数を書いてください。`show_sum(3, 5)`の結果を変数で受け取って表示し、次に自作した関数へ`3`と`5`を渡した戻り値も表示します。実行前に、`8`、`None`、`8`のどの行がどこで表示されるか予想しましょう。

## 自分で書く範囲

表示する関数と、その結果を受け取る2行は用意されています。和を返す別の関数と、最後の表示を書きます。

## 確かめること

表示する関数の呼び出し結果を変数へ受け取って`None`を表示し、別の関数が返した和も表示していることを確認します。文字列の`"None"`を直接表示するだけでは合格しません。

採点はコードと実際の出力を確かめます。理解したことや、ヒントを見ずに書けたことまでは自動判定しません。

実行後は、予想と違った点、開いたヒント、自分で決めた部分を短く振り返りましょう。
