入力をSoraとしたとき、初期コードは何を表示するでしょう。

```python
name = input()
print("name")
```

:::prediction
prompt: "Soraを入力したとき、何が表示されますか。"
answer: "nameと表示されます。"
explanation: "引用符で囲むと変数ではなく文字列です。print(name)へ直すとSoraが表示され、空入力なら空の1行になります。"
:::

演習では引用符を外して変数の値を表示します。個人情報を入力する必要はありません。
