input()は入力行を読み、末尾の改行を除いた文字列を返します。空欄を実行すると空文字列です。文字列"18"と数値18は同じ種類ではありません。

```python
name = input()
print(name)
```

この教材では実行前の入力欄に書いた行を使います。実行中に入力する操作は未対応です。空欄は1行分の入力で、行が尽きた状態（EOF）とは異なります。
