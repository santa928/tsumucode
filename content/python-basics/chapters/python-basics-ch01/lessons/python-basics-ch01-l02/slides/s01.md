input()は1行を読み、末尾の改行を除いた文字列を返します。

```python
name = input()
print(name)
```

1. 「実行前の入力」にSoraを入れて実行すると、ConsoleにSoraと出ます。
2. 入力欄を空にして実行すると、空の1行が出ます。

![入力: Sora / 出力: Sora](asset:python-control-l02-output)

## 実行環境の違い

- Browser版は事前入力を使い、実行中の追加入力には未対応です。
- PCのLocal CPython版は事前入力のプレビューと、途中で入力できる未採点の「練習実行」を使えます。「判定する」は固定入力の別実行です。

空の1行は、入力行が尽きた状態（EOF）とは別です。文字列"18"と数値18も別の種類です。
