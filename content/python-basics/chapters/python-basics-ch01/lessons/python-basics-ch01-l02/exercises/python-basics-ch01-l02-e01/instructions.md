## 入力した文字列を表示する

名前をそのまま表示するようにmain.pyの初期コードを修正します。

1. 「実行前の入力」にSoraと書きます。
2. printに変数の値を渡すよう、main.pyの引用符を見直します。
3. Consoleの出力を確かめ、入力欄を空にした場合の空の1行とも比べます。

### Browserで試す

コードを編集すると出力を自動更新します。入力欄だけを変えたら「プレビューを更新」を押します。「判定する」はその事前入力とコード条件を確認します。実行中の追加入力には未対応です。

### PCのLocal CPythonで試す

事前入力は「プレビューを更新」で使います。「練習実行」では途中で1行ずつ送れますが、正誤・進捗には反映しません。「判定する」は名前・空文字列・日本語の固定入力で別実行し、すべての出力とコード条件を確認します。

入力は保存・共有されません。空文字列1行は、用意した行が尽きた状態（EOF）とは異なります。

表示の直書きでは合格しません。入力不足・停止・環境障害は採点しません。条件や回数を変えて観察した後は、この課題の条件へ戻して判定してください。
