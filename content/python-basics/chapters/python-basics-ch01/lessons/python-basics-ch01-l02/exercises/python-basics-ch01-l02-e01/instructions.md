## 入力した文字列を表示する

名前をそのまま表示するようにmain.pyの初期コードを修正します。入力欄へSoraと書き、空欄の場合も比べます。

入力は文字列です。printには引用符を付けず変数名を渡します。

Browser版は実行前の入力欄を使い、その入力でプレビューと判定を行います。Local CPython版の事前入力欄は「プレビューを更新」用です。「練習実行」では実行途中に1行ずつ送れますが、正誤・進捗には反映しません。「判定する」は名前・空文字列・日本語の固定入力で別実行し、すべての出力とコード条件を確認します。入力は保存・共有されません。

表示の直書きでは合格しません。入力不足・停止・環境障害は採点しません。条件や回数を変えて観察した後は、この課題の条件へ戻して判定してください。
