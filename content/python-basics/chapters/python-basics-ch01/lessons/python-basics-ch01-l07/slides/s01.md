defはFunctionの名前と括弧内の引数を定義します。コロンの後の字下げ部分が処理です。呼び出すと引数へ順に値が入り、returnで値を返します。定義だけでは処理を実行しません。

```python
def add(left, right):
    result = left + right
    return result
print(add(3, 5))
```

表示は8です。return left + rightと直接返しても同じです。printは表示し、returnは呼び出し元へ値を渡します。
