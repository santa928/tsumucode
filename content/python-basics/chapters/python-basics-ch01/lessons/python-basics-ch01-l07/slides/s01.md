defは処理に名前を付ける書き方です。括弧とコロンを書き、実行する処理を4文字分字下げします。定義しただけでは中のprintは動きません。関数名に()を付けて呼び出すと、中の処理が実行されます。

```python
def show_sum():
    print(3 + 5)
```
