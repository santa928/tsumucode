Function内の引数leftは呼び出しごとのlocalな名前です。外側のleft = 100とは別です。returnがない場合はNoneが返り、戻り値をprintするとNoneを表示します。

```python
left = 100
def add(left, right):
    return left + right
print(add(3, 5))
print(add(4, 6))
print(left)
```

表示は8・10・100です。演習はleft + leftをleft + rightへ直します。right + leftも同じ加算で正解です。
