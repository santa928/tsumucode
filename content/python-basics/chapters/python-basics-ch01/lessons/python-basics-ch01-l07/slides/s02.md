まず呼び出す前の出力を予測してください。その後、定義は残して関数の外に呼び出しを2回書き、8が2行表示されることを確かめます。print(8)を外へ2回書く方法では、定義を再利用したことを確かめられません。

自分で決める範囲は「関数を呼ぶ位置と回数」です。ヒントは必要な段階だけ開きます。名前の変更や足す順序、計算結果を一時変数に保存する別解も使えます。

:::prediction
prompt: "完成後の出力を、実行前に順番に言えますか。"
answer: "8、8です。"
explanation: "実行の後は、どの行がその値を作ったかも確認します。"
:::
