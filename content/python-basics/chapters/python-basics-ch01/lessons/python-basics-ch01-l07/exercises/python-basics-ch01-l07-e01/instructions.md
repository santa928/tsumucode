## Functionの引数とreturn、外側の変数を比べる

2つの引数を足してreturnし、3と5、4と6の2組で呼び出します。 戻り値は8と10、最後に表示する外側のleftは100のままです。

「プレビューを更新」で実出力を見て、「判定する」で課題の条件を確認します。入力欄は使いません。表示の直書きや、使われない正しい構文だけでは合格しません。

外側の変数100→同名の引数を持つ2引数Functionの定義→2組の呼出し→外側の変数の表示、の順を使います。直接returnする形、resultをreturnする形、戻り値を変数へ保存して表示する形、変数名の変更、加算と引数の順序交換も正解です。

returnをprintへ変えた観察コードは合格用の出力とは異なります。観察後は課題の条件へ戻します。停止・環境障害・教材で説明していない構文は採点しません。コードエラーはSourceを残して直し、再試行できます。
