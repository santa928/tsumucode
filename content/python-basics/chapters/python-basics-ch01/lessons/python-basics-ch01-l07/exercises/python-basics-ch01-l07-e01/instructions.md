## 今回の仕様

用意された`show_sum`は、呼ばれたときに`3 + 5`を表示します。まだ呼ぶ行はありません。まず、このまま実行したら何が表示されるか予想しましょう。

関数の外へ、`show_sum`を呼ぶ行を2つ書いてください。実行して、`8`が2行出ることを確かめます。数字を直接表示するのではなく、同じ関数を2回使います。

## 自分で書く範囲

関数の定義は用意されています。関数を動かす行を、どこへ何回書くか考えます。

## 確かめること

同じ引数なしの関数を2回呼び、その中の処理から`8`、`8`が順に出ることを確認します。

採点はコードと実際の出力を確かめます。理解したことや、ヒントを見ずに書けたことまでは自動判定しません。

実行後は、予想と違った点、開いたヒント、自分で決めた部分を短く振り返りましょう。
