Listは複数の値を順番に並べます。`[3, 5]`の角括弧はListを作ります。`numbers[0]`の角括弧は、変数に入ったListの位置を指定します。indexは0から始まります。

```python
numbers = [3, 5]
print(numbers[0])
```

表示は3です。2つ目の値5はindex 1にあります。
