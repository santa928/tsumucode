左辺に`numbers[0]`を書くと、先頭の要素を更新できます。List全体を作り直す処理とは異なります。

```python
numbers = [3, 5]
print(numbers[0])
numbers[0] = 4
print(numbers[0])
```

出力は3、4です。更新より前に実行した表示は3のままです。演習ではこの4行を自分で書きます。

:::prediction
prompt: "numbers[0] = 4の後にnumbers[1]を読むと何ですか。"
answer: "5です。"
explanation: "index 0だけを更新したので、index 1の要素は変わりません。"
:::
