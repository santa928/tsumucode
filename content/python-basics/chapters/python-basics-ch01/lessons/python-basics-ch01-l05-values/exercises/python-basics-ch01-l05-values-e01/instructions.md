## Listを作り、先頭を読んで更新する

コメントを手掛かりに、次の4つの処理を自分で書きます。

1. `numbers` に `[3, 5]` を代入する。
2. `numbers[0]` を表示する。
3. 同じListの先頭を `4` に更新する。
4. 先頭をもう一度表示する。

期待する出力は `3`、`4` の2行です。変数名を変えたり、先頭を一時変数へ入れてから表示しても正解です。表示の直書きや、別のListへの作り直しでは同じ要素を更新したことになりません。

2要素の位置は0と1です。観察としてindex 1も読んでみたら、判定前に上の条件へ戻します。この課題では入力欄を使いません。

「プレビューを更新」で実出力を見て、「判定する」で課題の条件を確認します。コードエラーはSourceを残して直し、再試行できます。
