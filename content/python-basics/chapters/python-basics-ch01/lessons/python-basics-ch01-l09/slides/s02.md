完成した関数は用意していません。2引数の加算関数と呼び出しを自分で書きます。3と5の戻り値を変数へ受け取り2を足して表示し、4と6の戻り値にも2を足して表示してください。10と12の2行が必要です。関数名や結果を保存する変数名は選べます。

自分で決める範囲は「関数名・結果の変数名・戻り値の使い方」です。ヒントは必要な段階だけ開きます。名前の変更や足す順序、計算結果を一時変数に保存する別解も使えます。

:::prediction
prompt: "完成後の出力を、実行前に順番に言えますか。"
answer: "10、12です。"
explanation: "実行の後は、どの行がその値を作ったかも確認します。"
:::
