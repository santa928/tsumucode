returnは計算した値を呼び出し元へ返し、その回の関数を終えます。返った値は変数へ代入でき、さらに計算できます。printは画面へ表示するための処理です。計算結果を再利用したい関数は、表示だけで済ませず値を返します。

```python
def add(left, right):
    return left + right
result = add(1, 2)
print(result + 1)
```
