## 今回の仕様

今回は、2つの値の和を返す関数を自分で書きます。`return`は、値を呼び出した場所へ渡す書き方です。関数の名前は自分で決められます。

まず`3`と`5`を渡した戻り値を変数へ受け取り、`2`を足して表示してください。次に同じ関数へ`4`と`6`を渡し、その戻り値にも`2`を足して表示します。結果は`10`、`12`です。最初の値がどの行から返ってきたかも確かめましょう。

## 自分で書く範囲

関数本体と呼び出しは用意していません。関数名と結果の変数名は自分で決められます。2回目も変数へ受け取る書き方が使えます。

## 確かめること

2引数の和を返す関数を実際に呼び、最初の戻り値を変数へ保存し、両方の戻り値を次の足し算へ使っていることを確認します。別の値でも和になることを確かめます。

採点はコードと実際の出力を確かめます。理解したことや、ヒントを見ずに書けたことまでは自動判定しません。

実行後は、予想と違った点、開いたヒント、自分で決めた部分を短く振り返りましょう。
