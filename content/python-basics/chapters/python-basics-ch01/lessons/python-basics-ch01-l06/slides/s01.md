Dictはkeyとvalueの組です。ここではkeyは文字列、valueは整数です。波括弧の中のコロンで組を作り、角括弧にkeyを渡して読み書きします。

```python
stock = {"red": 3, "blue": 5}
stock["red"] = 4
print(stock["red"])
```

表示は4です。存在しないstock["missing"]を読むとKeyErrorです。
