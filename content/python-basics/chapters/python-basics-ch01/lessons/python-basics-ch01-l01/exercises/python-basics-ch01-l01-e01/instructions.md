## 変数を使って2つの値を表示する

1. 初期コードの出力を2行予測してから実行し、結果と理由を比べます。
2. 数値3に名前を付け、最初のprintでその変数の値を表示します。
3. 次のprintでは、同じ変数に2を足した結果を表示します。

完成時の出力は次の2行です。

```text
3
5
```

print(3)とprint(5)を直接書いた場合は、表示は同じでも変数を使う要件が未達です。変数の名前はcount以外でも構いません。代入と両方のprintで同じ名前を使ってください。

困ったときは、引用符で囲まれた文字列と、引用符のない変数名の違いを確認します。「最初に戻す」で初期コードへ戻ります。「プレビューを更新」で実行結果を見て、「判定する」で実行して要件を確かめます。

このLessonでは数値・変数・加算・printを使います。入力を待つコードやpackageの追加は扱いません。
