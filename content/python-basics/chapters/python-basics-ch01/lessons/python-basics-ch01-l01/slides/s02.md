変数は、値を名前で参照するために使います。=は右側の値を左側の名前へ代入する記号です。

```python
count = 3
print(count)
```

![countへ数値3を代入し、その名前をprintに渡すと値3を表示します。](asset:python-s02-output)

最初の行で数値3にcountという名前を付けます。print(count)はその値を表示し、名前の文字列を表示するわけではありません。

名前は自分で選べます。amount = 3と書いたら、print(amount)と同じ名前で参照します。代入前の名前は、値が見つからないNameErrorになります。再代入や入力待ちはこのLessonでは扱いません。
