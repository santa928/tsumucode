## Listの参照を共有して値を更新する

alias[0]を4へ更新し、numbersの先頭と合計を表示します。 先頭は4、合計は9です。alias = []への再代入と比べます。空Listはnumbers = []とtotal初期化・for集計・print(total)だけを実行し、更新と先頭表示を除いて0を確認します。

「プレビューを更新」で実出力を見て、「判定する」で課題の条件を確認します。入力欄は使いません。表示の直書きや、使われない正しい構文だけでは合格しません。

List作成→aliasへ代入→alias[0]の更新→totalの初期化→for集計→元Listの先頭とtotalの表示、の順を使います。変数名の変更、加算の左右交換、total += itemも正解です。

空Collectionなどの観察コードは合格用の出力とは異なります。観察後は課題の条件へ戻します。停止・環境障害・教材で説明していない構文は採点しません。コードエラーはSourceを残して直し、再試行できます。

+=は左側の現在値に右側を足して代入する省略形です。total = total + itemとtotal += itemは同じ更新です。
