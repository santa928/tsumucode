Listは値を順に並べます。[3, 5]の先頭はindex 0です。alias = numbersは複製を作らず、同じListを指します。角括弧の左辺への代入で要素を更新します。

```python
numbers = [3, 5]
alias = numbers
alias[0] = 4
print(numbers[0])
```

表示は4です。alias = []はaliasを別Listへ向ける再代入で、numbersの要素を変えません。
