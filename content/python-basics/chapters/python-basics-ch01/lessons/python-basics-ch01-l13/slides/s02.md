inputはtryの前です。空文字列1行をinputで読むことはできますが、intへ渡すとValueErrorになります。行不足はinputのEOFErrorです。入力不足は採点せず、行を追加して再実行します。負数、符号付き、前後に空白のある整数文字列もintで変換できます。符号や空白だけの文字列は変換できません。

```python
text = input()
try:
    number = parse_number(text)
    print(number)
except ValueError:
    print("整数を入力してください")
print("終了")
```

abcでも案内の後に終了まで進みます。
