helperで捕まえないValueErrorは呼出し元へ伝わります。tryは失敗する処理を囲み、except ValueErrorは整数変換の失敗だけを処理します。

lesson_tools.py:

```python
def parse_number(text):
    return int(text)
```

main.py:

```python
from lesson_tools import parse_number
text = input()
try:
    print(parse_number(text))
except ValueError:
    print("整数を入力してください")
print("終了")
```

18なら18、終了。abcなら案内、終了です。
