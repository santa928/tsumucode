rangeの引数を変えた場合を予測します。

:::prediction
prompt: "range(0)、range(1)、range(3)で、何回・何を表示しますか。"
answer: "0回で何も表示しない、1回で0、3回で0・1・2を表示します。"
explanation: "0から終了値の直前までを順に渡すためです。終了値そのものは含みません。"
:::

演習ではrange(2)をrange(3)へ直します。観察で0・1へ変えた後は3へ戻して判定します。無限Loopはこの課題の採点範囲外です。
