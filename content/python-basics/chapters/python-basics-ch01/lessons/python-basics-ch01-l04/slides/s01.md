forは渡された値を順に変数へ入れ、字下げした処理を繰り返します。range(3)は0から始まり、終了値3を含みません。

```python
for number in range(3):
    print(number)
```

表示は0・1・2の3行です。printをforの内側へ半角空白4つで字下げします。
