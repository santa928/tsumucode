rangeのLessonでは`range(3)`から値を受け取りました。inの後ろにListを書くと、Listに入っている値を先頭から順に受け取れます。indexを自分で増やす必要はありません。

```python
numbers = [4, 5]
for item in numbers:
    print(item)
```

itemには4、次に5が入り、2行表示します。
