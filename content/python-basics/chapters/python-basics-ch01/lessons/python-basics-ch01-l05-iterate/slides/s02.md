`total = total + item`は、今の合計に今回の要素を足し、その結果をtotalへ入れ直します。初期化はforの前、表示はforの後です。

```python
numbers = [4, 5]
total = 0
for item in numbers:
    total = total + item
print(total)
```

合計は0→4→9となります。演習では初期化・for・加算・表示を自分で書きます。
