## Listの各要素をforで合計する

`numbers = [4, 5]` は用意されています。コメントの位置に、次の処理を自分で書きます。

1. 合計用の変数 `total` を `0` で初期化する。
2. `for item in numbers:` を書き、字下げした行で `item` を `total` に足す。
3. forの外側で `total` を表示する。

期待する出力は `9` の1行です。Listの各要素を順に使い、合計へ足してください。変数名の変更、一時変数の利用、足す左右の順序の交換も正解です。`[1, 3, 5]` など、合計が9になる別の整数のListも使えます。9の直書き、使われないfor、毎回合計を置き換える処理では合格しません。

観察としてListを `[]` に変えると、forが0回なので0を表示します。空Listの0は観察用の出力です。判定では、合計が9になるListを使い、9を表示します。この課題では入力欄を使いません。

「プレビューを更新」で実出力を見て、「判定する」で課題の条件を確認します。コードエラーはSourceを残して直し、再試行できます。
