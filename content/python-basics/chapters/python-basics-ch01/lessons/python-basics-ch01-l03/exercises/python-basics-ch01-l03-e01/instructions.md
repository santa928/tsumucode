## 境界を含む条件で表示を分ける

18以上でadult、それより小さければchildを表示するようにmain.pyの初期コードを修正します。17・18・19を入力し、境界の18もadultになることを確認します。

比較演算子`>=`は同じ値も含みます。ifとelseの中は半角空白4つで揃えます。

実行前の入力欄を使います。入力は保存・共有されません。実行中に入力する操作は未対応です。「プレビューを更新」で実出力を見てから「判定する」でコード条件を確かめます。

表示の直書きでは合格しません。入力不足・停止・環境障害は採点しません。条件や回数を変えて観察した後は、この課題の条件へ戻して判定してください。
