同じコードでも入力で結果が変わります。実行前に予測します。

:::prediction
prompt: "age >= 18なら、17・18・19はそれぞれ何を表示しますか。"
answer: "17はchild、18と19はadultです。"
explanation: ">=は18を含みます。>なら18はchildになり、境界で結果が変わります。"
:::

演習は>を>=へ直す修正課題です。入力欄には半角整数を1行書き、17・18・19を順に試します。空欄はintでエラーになるので、整数へ戻して再実行します。
