input()は文字列なので、int(input())で整数に直します。空文字列や整数でない文字列はValueErrorになります。

```python
age = int(input())
if age >= 18:
    print("adult")
else:
    print("child")
```

比較演算子`>=`は等しい値を含みます。条件が真ならif、偽ならelseの中だけを実行します。コロンと半角空白4つの字下げに注目してください。adultとchildはこの練習用の表示ラベルです。
