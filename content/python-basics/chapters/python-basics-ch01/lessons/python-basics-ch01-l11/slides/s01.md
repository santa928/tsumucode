名前を使える範囲をスコープと呼びます。この例では、外側のleft = 100と引数のleftは別の名前です。関数内で整数の計算結果を引数leftへ代入しても、外側のleftは100のままです。内側で作った値を外で使うには、returnして受け取ります。

```python
left = 100
def add(left, right):
    left = left + right
    return left
print(add(1, 2))
print(left)
```
