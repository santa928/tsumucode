細かい修正手順はありません。外側のleft = 100を残し、引数の1つにleftという名前を使う加算関数を自作します。3と5、4と6の戻り値を順に表示し、最後に外側のleftを表示してください。8、10、100の3行から、同じ名前の使える範囲を説明しましょう。

自分で決める範囲は「関数名・計算の書き方・呼び出しと表示の組み立て」です。ヒントは必要な段階だけ開きます。名前の変更や足す順序、計算結果を一時変数に保存する別解も使えます。
