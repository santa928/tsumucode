## 今回の仕様

外側には`left = 100`があります。2つの値の和を返す関数を自作し、引数の1つにも`left`という名前を使ってください。

同じ関数へ`3`と`5`、次に`4`と`6`を渡し、それぞれの戻り値を表示します。最後に関数の外で`left`を表示してください。結果は`8`、`10`、`100`です。同じ名前でも、どの`left`を読んでいるか確かめましょう。

## 自分で書く範囲

外側の値だけを用意しています。関数名、もう1つの引数名、呼び出しと表示の組み立ては自分で決めます。`left`を2番目の引数にする書き方も使えます。

## 確かめること

同名の引数を使う2引数の関数を2組の値で呼び、和が戻り値から表示され、最後の外側の`left`は`100`であることを確認します。

採点はコードと実際の出力を確かめます。理解したことや、ヒントを見ずに書けたことまでは自動判定しません。

実行後は、予想と違った点、開いたヒント、自分で決めた部分を短く振り返りましょう。
