両Sourceを保存し、reload後もhelperを選択できます。最初に戻すと両starterへ戻ります。入力は保存せず再入力します。ZIPは固定2.pyとREADMEだけです。

```python
def add(left, right):
    result = right + left
    return result

def parse_number(text):
    return int(text)
```

名前変更・左右交換・一時変数returnでも同じ合計です。
