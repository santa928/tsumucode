inputを左から順に2回呼び、Listに入れます。importのカンマは同じmoduleの2つの関数名を区切ります。helperはaddとparse_numberを定義します。

```python
from lesson_tools import add, parse_number
texts = [input(), input()]
total = 0
try:
    for text in texts:
        total = add(total, parse_number(text))
    print(total)
except ValueError:
    print("整数を入力してください")
print("終了")
```

3、5なら8、終了です。
