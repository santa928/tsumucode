iter(cursor)は同じiteratorを返します。先頭へ戻すには元のListから新しく作ります。空Listのiteratorは最初のnextからENDです。list(cursor)は残り全部を消費し、元のListの複製を返す操作とは限りません。

```python
fresh = iter(numbers)
print(next(fresh, "END"))
empty_cursor = iter([])
print(next(empty_cursor, "END"))
```

:::prediction
prompt: "fresh = iter(cursor)にすると先頭の3を得られますか。"
