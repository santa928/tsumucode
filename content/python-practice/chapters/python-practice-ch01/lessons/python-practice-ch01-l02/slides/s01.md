Listはiterで新しいiteratorを作れるIterableです。iteratorは次の値の位置を持ちます。next(cursor, "END")は1個進め、枯渇していればdefaultのENDを返します。defaultなしで枯渇するとStopIterationです。

```python
numbers = [3, 5]
cursor = iter(numbers)
print(next(cursor, "END"))
print(next(cursor, "END"))
print(next(cursor, "END"))
```
