yieldを含むFunctionはGeneratorを作ります。呼び出すだけでは本体を実行しません。nextでyieldまで進み、値を渡して中断します。次のnextはその続きです。開始・生成のprintは今回の流れを読む目印です。

```python
def doubles(numbers):
    print("開始")
    for number in numbers:
        print("生成")
        yield number + number

items = doubles([3, 5])
print("作成済み")
print(next(items, "END"))
```

:::prediction
prompt: "作成済みと開始はどちらが先ですか。"
answer: "作成済みです。"
explanation: "作成では本体を進めず、最初のnextで開始・生成・6を表示します。"
:::
