最後の10をyieldした直後も中断位置にいます。追加nextで本体の終わりへ進んで初めて枯渇します。空でも最初のnextで本体に入り、値を生成せずENDです。list(gen)は残りを全部生成して消費します。遅延生成が常に速いとは限りません。

```python
print(next(items, "END"))
print(next(items, "END"))
fresh = doubles([3, 5])
print(list(fresh))
print(next(fresh, "END"))
```

:::prediction
prompt: "list(fresh)後のnext(fresh, \"END\")は何ですか。"
answer: "ENDです。"
explanation: "listが残り全部を消費しています。比較のやり直しには新しいGeneratorを作ります。"
:::
