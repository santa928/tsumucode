同じ変換のfor版ではappendで末尾へ追加します。内包表記も新しいListを作り、元のnumbersは変えません。empty = []からは0回の反復なので[]です。演習の採点は一段の内包表記を対象とし、for版は比較用です。

```python
result = []
for number in numbers:
    if number >= 0:
        result.append(number + number)
print(result)
```

:::prediction
prompt: "変換せず[number for number in numbers if number >= 0]なら何ですか。"
answer: "[0, 3]です。"
explanation: "残す条件は同じでも、変換する式が異なります。"
:::
