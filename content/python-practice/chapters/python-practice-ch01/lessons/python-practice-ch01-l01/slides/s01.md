List・for・Functionは基礎で学びました。内包表記は、反復する値と変換を並べて新しいListを作ります。末尾のifは残す条件です。0以上を残して2倍にすると[0, 6]です。

```python
numbers = [-2, 0, 3]
result = [number + number for number in numbers if number >= 0]
print(result)
```
