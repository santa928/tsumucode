Type hintは値の種類を書く注釈で、Pythonが値を自動検証する仕組みではありません。dataclassは標準libraryで、Classの注釈付きfieldから初期化などの処理を生成します。Classは設計、Instanceはそこから作る1件、attributeはその値です。

```python
from dataclasses import dataclass
@dataclass
class Record:
    label: str
    amount: int
sample = Record("記録", "4")
print(isinstance(sample.amount, str))
```

isinstanceは値が指定した型かを調べます。amount:intでも文字列を渡せて、Trueになります。生成処理は整数変換や負値の拒否をしません。

:::prediction
