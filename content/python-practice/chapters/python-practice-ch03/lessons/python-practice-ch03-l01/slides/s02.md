値を受け入れる条件は、自分で明示します。int(line)は整数へ変換し、不正文字列ならValueErrorを出します。負値もifとraiseで拒否します。

```python
def read_records(text: str):
    with StringIO(text) as stream:
        for line in stream:
            amount = int(line)
            if amount < 0:
                raise ValueError("負値は使えません")
            yield Record("記録", amount)
```

StringIOは各行を反復できます。このGeneratorをsumが最後まで消費すると、正常時・空・変換失敗のいずれもwithを抜けてstreamが閉じます。Generatorを途中で保持したまま消費をやめる場合は、同じ即時終了を保証しません。
