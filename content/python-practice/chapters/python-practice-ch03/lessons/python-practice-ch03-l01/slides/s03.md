Testは予測した結果と実際の処理を比較する確認です。assertは条件がFalseならAssertionErrorを出します。固定driverはその例外だけを捕捉してTest失敗と表示します。期待値を書き換えて成功にする課題ではありません。

```python
try:
    assert total("2\n4\n") == 6
    assert total("") == 0
    print("Test成功")
except AssertionError:
    print("Test失敗")
```

未捕捉のTypeError等はRuntime Error、教材外構文や環境障害は未採点です。assertは最適化時に省略されるので値検証に使いません。本教材は最適化を指定しません。実際のProjectには不正文字列と負値がValueErrorになるTestもあります。
