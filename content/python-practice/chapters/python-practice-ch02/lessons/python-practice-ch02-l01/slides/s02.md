raise ValueError("中断")は例外を意図的に起こします。その後ろの文へ進まないため、末尾に置いたmanual closeは実行されません。このStringIOでは途中例外でもcloseされ、ValueErrorは外側のexceptへ伝わります。終了処理や例外の扱いは、使うContext managerによって異なります。

```python
try:
    with StringIO("例外") as stream:
        print(stream.closed)
        raise ValueError("中断")
except ValueError:
    print("例外を受け止めた")
print(stream.closed)
```

close後のgetvalue()はValueErrorになります。closeはbufferを利用不能にする処理で、物理メモリの上書きやGC時刻の保証ではありません。両engineでこの動作を確認します。
