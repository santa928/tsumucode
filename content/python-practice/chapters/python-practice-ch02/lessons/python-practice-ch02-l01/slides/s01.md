基礎のFunction・try/exceptを前提にします。ioはPythonに同梱された標準libraryです。StringIOは文字列をメモリ内に持つstreamで、OSファイルを作りません。getvalue()は内容、closedは閉じた状態を返します。Falseは未close、Trueはclose済みです。

Context managerは開始・終了処理を持つobjectです。withはその処理を呼びます。このStringIOでは開始でstreamをasの変数へ渡し、block終了でcloseします。変数はblockの外にも残ります。

```python
from io import StringIO
with StringIO("通常") as stream:
    print(stream.getvalue())
    print(stream.closed)
print(stream.closed)
```
