360pxと800pxを見比べた後、767pxと768pxを確かめます。smは40rem（640px）以上なので、sm:flex-rowでは切替が早すぎます。classの名前だけでなく実際のflex-directionと要素の並びを確認します。

```css
/* md:flex-rowに対応する条件 */
@media (width >= 48rem) {
  /* flex-direction: row */
}
```

:::prediction
prompt: "sm:flex-rowでも767pxの縦並びを保てますか。"
answer: "いいえ、640pxから横並びになります。"
explanation: "誤ったvariantも描画の境界で見分けます。"
:::
