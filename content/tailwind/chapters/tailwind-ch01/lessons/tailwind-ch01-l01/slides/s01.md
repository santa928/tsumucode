![CSSとclassの対応](asset:tailwind-mapping)

HTML/CSSで学んだclassへ、Tailwindが用意した見た目の指定を結びます。Utilityは小さな役割を持つclassです。ここでは3つの指定を対応させます。

```css
.cards {
  display: flex;
  gap: 1rem;
  padding: 1rem;
}
```

```html
<div class="flex gap-4 p-4">...</div>
```

この2つは、今回の固定themeでは同じ3つのCSS指定になります。classを書くと、隔離プレビュー内で必要なCSSが生成されます。親の学習画面のCSSは変わりません。

:::prediction
prompt: "flexを外したら、どの指定がなくなりますか。"
answer: "display: flexです。"
explanation: "gapとpaddingは別のUtilityが指定しています。"
:::
