@layer components は共通の見た目を置く層、@apply はUtilityの宣言をまとめる命令です。.note-cardを2枚で使います。カード固有の内容と親の並び、buttonのfocusとhoverはそれぞれのHTMLに残します。

```css
@layer components {
  .note-card {
    @apply p-card border border-brand bg-paper text-brand;
  }
}
```

```html
<section class="note-card">読む</section>
<section class="note-card">作る</section>
```

:::prediction
prompt: "2枚目が個別のUtility列のままでも.note-cardの変更は届きますか。"
