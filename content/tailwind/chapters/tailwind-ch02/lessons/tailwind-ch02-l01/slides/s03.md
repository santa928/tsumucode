manifestのpackage.jsonは依存名とコマンド、lockfileのpackage-lock.jsonは実際の依存versionと照合情報を固定します。Vite PluginはbuildへTailwindのCSS生成を接続します。distにHTMLと生成CSSができます。Play CDNは開発用なので、この制作の本番CSSは事前生成します。

```sh
npm ci --ignore-scripts
npm run build
npm run preview
```

:::prediction
prompt: "styles.cssを編集した後、previewだけで新しい生成CSSになりますか。"
answer: "先にbuildが必要です。"
explanation: "previewはbuild後のdistを表示します。準備するNode版と通信はREADMEで確認します。"
:::
