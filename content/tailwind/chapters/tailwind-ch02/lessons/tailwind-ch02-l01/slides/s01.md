theme tokenは設計で共有する色や余白の値です。@themeの--color-brandからtext-brandやborder-brandが作られます。通常の:root変数に値を置くだけでは、対応するUtilityは増えません。1か所の値を複数の見た目へつなぎます。

```css
@theme {
  --color-brand: #0f3c4c;
  --color-paper: #fffaf0;
  --spacing-card: 24px;
}
```

:::prediction
prompt: "brandを変えると、同じtokenを使う文字と枠は一緒に変わりますか。"
answer: "はい。どちらも共有する値を参照します。"
explanation: "Utility名を揃えても、異なるtokenを参照する場所には届きません。"
:::
