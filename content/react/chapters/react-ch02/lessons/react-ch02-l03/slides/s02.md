完成した一覧へ、表示条件と2種類の件数を仕様から追加します。未読を順に読了にしていき、最後に「すべて」へ戻して一覧と件数を比べましょう。最初に戻すと表示条件も戻します。

:::prediction
prompt: 未読だけを表示して残りをすべて読了にすると、表示件数と全体の読了件数はいくつになりますか。
answer: 表示は0件、全体の読了は3冊です。
explanation: 表示条件で隠れた本も元の一覧に残るので、全体の読了件数に含まれます。
:::

詳しい表示名と接続IDは演習の指示で確認できます。ヒントは必要な段階だけ開きましょう。
