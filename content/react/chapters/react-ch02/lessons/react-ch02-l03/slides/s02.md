完成した一覧へ、表示条件と2種類の件数を仕様から追加します。未読を順に読了にして0件になっても、すべてへ戻すと3冊残ることを確かめましょう。最初に戻すと表示条件も戻します。

:::practice
prompt: 未読だけを表示して残りをすべて読了にすると、表示件数と全体の読了件数はいくつになりますか。
expectedAction: 表示は0件、全体の読了は3冊になり、すべてへ戻すと3冊残ると予想する
estimatedMinutes: 1
:::

詳しい表示名と接続IDは演習の指示で確認できます。ヒントは必要な段階だけ開きましょう。
