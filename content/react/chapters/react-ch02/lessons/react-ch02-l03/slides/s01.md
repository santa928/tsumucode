filterは条件に合う項目の新しい配列を返します。元の配列は残ります。配列のlengthは項目数です。表示する本と全体の既読件数を同じ配列で数えると、絞り込み中の集計がずれます。どの配列を数えるのか、先に確かめましょう。

```tsx
const values = [2, 5, 8];
const selected = values.filter((value) => value > 4);
const count = selected.length;
```
