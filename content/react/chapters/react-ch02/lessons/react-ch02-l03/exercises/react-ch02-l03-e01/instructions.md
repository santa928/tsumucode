## 今回の仕様

読書リストへ、次の仕様を追加してください。今回は行ごとの修正手順はありません。どの値をStateにし、どの値を今のデータから計算するかを考えます。

- 「すべて」「未読」「既読」で、表示する本を切り替えられる。
- 今選んでいる条件が分かる。
- 今表示している本の数を「2件」の形で表示する。
- 表示条件とは別に、全3冊のうち既読の数を「既読1件 / 全3件」の形で表示する。
- 本の既読状態を変えると、一覧と2つの件数がすぐ更新される。
- 該当する本がないときは「0件」となり、別の条件へ切り替えられる。
- 「最初に戻す」で、本の状態と表示条件が初期状態へ戻る。

未読だけを表示して、残る2冊を順に読み終えてみましょう。0件になった後も「すべて」で3冊に戻り、既読状態が保たれていることを確かめてください。

## 用意されている範囲

配布版の動く一覧とBookCardを土台にします。components.tsxへ絞り込みと件数を追加します。

Bookのid/title/readとBookCardPropsのbook/onToggleは用意された型を使います。

## 表示と採点の接点

見た目の装飾や補助関数の名前は自分で決められます。次のIDと表示は、操作する場所を識別するために使います。

- 本の一覧のidはbooksにします。
- 1冊のbuttonのidはtoggle-と本のidをつなぎます。星の地図ならtoggle-starsです。aria-pressedにはその本のreadを渡します。
- 最初に戻すbuttonのidはreset、表示は「最初に戻す」です。
- 表示条件のbuttonのidはfilter-all、filter-unread、filter-readです。選択中のbuttonだけaria-pressedをtrueにします。
- 表示件数のidはcount、表示例は「2件」です。
- 全体の既読件数のidはsummary、表示例は「既読1件 / 全3件」です。

## 実行後の確認

「プレビューを更新」で表示を確認し、buttonを操作してから「判定する」で確かめます。判定はコードと指定の連続操作を確認します。ヒントなしで書けたことや、説明を理解したことまでは自動判定しません。開いたヒント、自分で決めた部分、予想と違った点を振り返りましょう。
