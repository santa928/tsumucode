## 今回の仕様

3冊を並べる親は用意されています。あなたはBookCard.tsxに、本1冊を表示するBookCardを作ります。

受け取ったbookから題名と「既読」または「未読」を表示してください。buttonの表示は、未読なら「読了にする」、既読なら「未読にする」です。押したときはonToggleへその本のidを渡します。部品の中で本のデータを書き換えず、親へ操作を知らせましょう。

「星の地図」を切り替え、もう一度押して元に戻ることと、他の2冊が変わらないことを確かめます。

## 用意されている範囲

親のStateと一覧を作る処理、型、初期データ、起動処理は配布済みです。自分で書くのはBookCardだけです。

Bookのid/title/readとBookCardPropsのbook/onToggleは用意された型を使います。

## 表示と採点の接点

見た目の装飾や補助関数の名前は自分で決められます。次のIDと表示は、操作する場所を識別するために使います。

- 本の一覧のidはbooksにします。
- 1冊のbuttonのidはtoggle-と本のidをつなぎます。星の地図ならtoggle-starsです。aria-pressedにはその本のreadを渡します。
- 最初に戻すbuttonのidはreset、表示は「最初に戻す」です。

aria-pressedは、読み上げ機能にbuttonの選択状態を伝える属性です。この課題では、既読ならtrue、未読ならfalseになるbook.readを渡します。

## 実行後の確認

「プレビューを更新」で表示を確認し、buttonを操作してから「判定する」で確かめます。判定はコードと指定の連続操作を確認します。ヒントなしで書けたことや、説明を理解したことまでは自動判定しません。開いたヒント、自分で決めた部分、予想と違った点を振り返りましょう。
