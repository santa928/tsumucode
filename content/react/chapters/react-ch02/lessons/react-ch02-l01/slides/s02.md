親は用意されています。本1冊の題名・状態・buttonを自作します。押した本のIDを親へ渡し、同じ本を2回押して元へ戻ること、他の本が変わらないことを確かめます。

:::practice
prompt: 同じ本のbuttonを2回押すと、その本と他の本の状態はどうなりますか。
expectedAction: 押した本だけが読了から未読へ戻り、他の本は変わらないと予想する
estimatedMinutes: 1
:::

詳しい表示名と接続IDは演習の指示で確認できます。ヒントは必要な段階だけ開きましょう。
