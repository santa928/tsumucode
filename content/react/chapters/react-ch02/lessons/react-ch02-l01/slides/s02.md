親は用意されています。本1冊の題名・状態・buttonを自作します。押した本のIDを親へ渡し、同じ本を2回押し、押した本とほかの本の表示を比べます。

:::prediction
prompt: 同じ本のbuttonを2回押すと、その本と他の本の状態はどうなりますか。
answer: 押した本は最初の状態に戻り、ほかの本は変わりません。
explanation: どちらのクリックでも同じIDを親へ渡すため、同じ本だけが2回切り替わります。
:::

詳しい表示名と接続IDは演習の指示で確認できます。ヒントは必要な段階だけ開きましょう。
