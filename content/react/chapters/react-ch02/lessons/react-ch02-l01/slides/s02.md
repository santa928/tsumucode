選択肢の文字列をbuttonの表示・Key・onAnswerへつなぎます。この固定データでは各問内の文字列が一意なのでKeyに使えます。一般の一覧では安定したIDを使います。Keyは兄弟間の目印で、通常のPropsには渡されません。
