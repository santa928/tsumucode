Propsは親から受け取る値です。今回はbookに1冊の情報、onToggleに親へ操作を知らせる関数が入ります。book.readがtrueなら既読、falseなら未読です。表示した時点でonToggleを呼ばず、buttonを押したときに呼びましょう。

```tsx
<button onClick={() => onToggle(book.id)}>切り替える</button>
```
