QuestionCardはquestion・answered・onAnswerをPropsで受け取ります。クイズStateと名前のStateは用意済みの親が持ちます。子は問題文と選択肢を表示し、押された値を親へ渡す責務に絞ります。

```tsx
interface LabelProps {
  readonly text: string;
}
function Label({ text }: LabelProps) {
  return <p>{text}</p>;
}
```
