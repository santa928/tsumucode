## 今回の仕様

今回は、読書リストをまとめる親のAppも作ります。本の現在の状態を親のStateに置き、BookCardへ1冊の情報と、切り替えるための関数を渡してください。

操作されたIDの本だけ、既読と未読を切り替えます。前の配列や本を直接書き換えず、更新した配列をStateへ渡します。一覧のKeyには本のIDを使ってください。「最初に戻す」buttonは3冊を初期状態へ戻します。

同じ本を2回押す、別の本を続けて押す、元に戻してからもう一度押す、を確かめましょう。関数名や、処理をどこで小さく分けるかは自分で決められます。

## 用意されている範囲

BookCard、型、初期データ、起動処理は配布版です。自分で書くのはcomponents.tsxの親です。前の個人Workspaceが自動でコピーされる課題ではありません。

Bookのid/title/readとBookCardPropsのbook/onToggleは用意された型を使います。

## 表示と採点の接点

見た目の装飾や補助関数の名前は自分で決められます。次のIDと表示は、操作する場所を識別するために使います。

- 本の一覧のidはbooksにします。
- 1冊のbuttonのidはtoggle-と本のidをつなぎます。星の地図ならtoggle-starsです。aria-pressedにはその本のreadを渡します。
- 最初に戻すbuttonのidはreset、表示は「最初に戻す」です。

## 実行後の確認

「プレビューを更新」で表示を確認し、buttonを操作してから「判定する」で確かめます。判定はコードと指定の連続操作を確認します。ヒントなしで書けたことや、説明を理解したことまでは自動判定しません。開いたヒント、自分で決めた部分、予想と違った点を振り返りましょう。
