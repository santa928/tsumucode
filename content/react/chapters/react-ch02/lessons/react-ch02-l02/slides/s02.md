Guidedでは1回回答したら正誤にかかわらず回答済みです。正解だけ1点を加え、回答済みなら元のStateを返します。advanceは回答後だけ次問へ進め、再挑戦はcreateStateへ戻します。名前は別Stateなので保持します。

:::practice
prompt: 1問目正解の後、2問目で誤答すると得点はいくつですか。
expectedAction: 累積得点1を保ち回答済みになると予測する
estimatedMinutes: 1
:::
