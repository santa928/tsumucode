今回は親を自作します。親のStateをカードへ渡し、IDが合う本だけを新しい値にします。別の本を続けて切り替え、最初に戻してからもう一度切り替えましょう。

:::practice
prompt: 2冊を切り替えた後に「最初に戻す」を押すと、どの本の状態が戻りますか。
expectedAction: 一覧の全3冊が最初の状態に戻り、その後も個別に切り替えられると予想する
estimatedMinutes: 1
:::

詳しい表示名と接続IDは演習の指示で確認できます。ヒントは必要な段階だけ開きましょう。
