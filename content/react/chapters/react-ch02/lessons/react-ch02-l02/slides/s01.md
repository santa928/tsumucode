本の現在状態を共通の親へ置くと、一覧と「最初に戻す」が同じデータを見られます。子は対象IDを親へ伝え、親はそのIDの本だけを変えます。mapは新しい配列を作ります。変わらない本のIDも、一覧のKeyも保ちましょう。

```tsx
const next = books.map((book) => (book.id === id ? { ...book, read: !book.read } : book));
```
