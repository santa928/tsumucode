親はuseStateを1つ使ってクイズStateを持ち、関数へ前のStateを渡します。純粋な関数は引数だけから次の値を返し、元を変更しません。readonlyは型検査で書込みを防ぎ、実行時のfreezeではありません。

```tsx
const previous = { score: 2 };
const next = { ...previous, score: 3 };
// previous.scoreは2のまま。
```
