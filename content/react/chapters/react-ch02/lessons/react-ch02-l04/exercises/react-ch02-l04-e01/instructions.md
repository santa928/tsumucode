## 今回の仕様

摂氏と華氏で同じ温度を表示するパネルを作ります。起動処理と空のAppだけが用意されています。`components.tsx`の中に、表示を担当する部品を少なくとも1つ自分で作り、受け取った数値を画面に表示してください。

書き始める前に、次の3点を短く説明しましょう。

- どの部品が現在の温度を覚えるか。
- どこを別の表示部品に分けるか。
- 数値と操作を、どのProps・Callbackで渡すか。

部品名・Props名・Callback名・Stateを置く部品は自分で決めます。Appが温度を覚えて表示部品へ渡しても、Appの内側の部品が覚えてその子へ渡しても構いません。Appは起動処理が呼ぶ入口なので、export名だけAppにします。

最初は20℃と68℉です。華氏は「摂氏 × 9 ÷ 5 ＋ 32」で求められます。コードでは、掛け算に`*`、割り算に`/`を使います。同じ温度が変わると、両方の表示も変わるようにしてください。

| 操作               | 摂氏 | 華氏 |
| ------------------ | ---- | ---- |
| 最初の表示         | 20   | 68   |
| 1℃上げる           | 21   | 69.8 |
| もう1回上げる      | 22   | 71.6 |
| 1℃下げる           | 21   | 69.8 |
| 最初に戻す         | 20   | 68   |
| 戻した後に1℃下げる | 19   | 66.2 |
| もう1回最初に戻す  | 20   | 68   |
| 戻した後に1℃上げる | 21   | 69.8 |

## 表示と操作の接点

画面には摂氏・華氏のラベルと単位を表示します。数値だけを入れるspanのidを`celsius`と`fahrenheit`にします。単位はspanの外へ置きます。buttonには`type="button"`を付けます。

| 操作       | buttonのid | buttonの表示 |
| ---------- | ---------- | ------------ |
| 1℃上げる   | increase   | 1℃上げる     |
| 1℃下げる   | decrease   | 1℃下げる     |
| 最初に戻す | reset      | 最初に戻す   |

## 編集できる範囲

編集するのは`components.tsx`です。Propsのinterfaceやtype、複数の部品も同じファイルへ書けます。HTMLと起動処理は読み取り専用です。

この課題では既習のsection/div/h1/h2/p/span/strong/button、id/className/aria-label/aria-labelledby/type/onClick、数値の四則演算と同期したクリック処理を使います。引数のない操作関数はCallbackとして別の部品へ渡せます。Stateの更新は次の数値を直接渡す方法と、直前の数値から求める更新関数の両方を使えます。

Propsには数値・文字列・引数なしの操作関数の型を指定します。JSXの属性をまとめて渡すspread、独立した計算helperの呼出し、Effect・Ref・Context、非同期処理、直接DOM操作はこの小課題の対象外です。

## 実行後の確認

「プレビューを更新」で両表示を見てから、「判定する」で指定の操作を確かめます。判定は、自作した表示部品と値・操作のつながり、指定順の表示結果を確認します。境界を選んだ理由、ヒントなしで書けたこと、一般的な設計能力までは自動判定しません。

完成後は、最初の3点を実装に照らして振り返りましょう。どのヒントや完成例を見たか、予想と違った点、別の部品分けを選ぶなら何を変えるかも説明します。ここで扱った表示と操作を、次のクイズ制作で組み合わせていきます。HTTP・Server・ルーティングはNext側で扱います。
