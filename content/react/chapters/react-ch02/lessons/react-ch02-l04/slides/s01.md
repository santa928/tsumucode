今度は読書リストとは別の、摂氏と華氏の温度表示を作ります。表示を分ける境界、現在の温度をStateで覚える部品、値と操作を渡すPropsの名前を自分で決めます。使われる表示部品を少なくとも1つ作りましょう。

既習のPropsで数値を受け取り、表示する部品の例です。interfaceは受け取る値の型、valueは受け取った数値です。

```tsx
interface ValueTextProps {
  readonly value: number;
}
function ValueText({ value }: ValueTextProps) {
  return <p>{value}</p>;
}
```

![数値を受け取る部品から表示へ](asset:react-ch02-l04-value-flow)

部品名と分け方は一例です。課題では自分で選びます。AppがStateを持っても、内側の部品が持っても構いません。画面のどこで同じ温度が必要かを考えましょう。
