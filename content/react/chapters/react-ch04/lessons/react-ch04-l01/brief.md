## 誤答から再回答できる練習クイズ

別Brief: 計算と比較の2問を繰り返し練習するクイズです。

- 名前は入力した値を表示し、再挑戦でも保ちます。
- 問題文と2つの選択肢をPropsから表示し、選択肢の文字列をKeyと親Callbackへ渡します。各問内で文字列は一意です。
- 正解時だけ1点を加えて回答済みにします。誤答では累積得点と問題を保ち、再回答できます。
- 回答済みの重複得点と未回答の次問を防ぎ、2問の後に結果を表示します。再挑戦は0点・最初の問題・未回答へ戻します。
- 1問目を正解し、2問目で誤答しても1点。同問を正解して2点、重複でも2点です。Guidedのanswerをそのまま移すだけでは満たせません。

固定データは1 + 1（2/3、正解2）、3 > 5（true/false、正解false）です。通信は使いません。名前の入力、選択肢、次問、再挑戦はnative input/buttonでKeyboard操作できます。
