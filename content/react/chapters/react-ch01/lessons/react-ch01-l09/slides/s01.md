Contextは、親から渡した値を子が取得する仕組みです。Providerはその値を提供する親側の境界です。Context自体がStateを作ったり、更新ルールを保存したりするわけではありません。

```tsx
<NameContext.Provider value={{ value: name, onNameChange: setName }}>
  <NameField />
  <NameSummary />
</NameContext.Provider>
```

今回は値を受け取る経路を学ぶためContextを使います。前の単元のPropsも、この短い経路には適切な選択です。
