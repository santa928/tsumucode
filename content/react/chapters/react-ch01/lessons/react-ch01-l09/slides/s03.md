演習ではcomponents.tsxの要約の固定文字列を修正します。Contextを読むだけでは表示は変わりません。受け取る値を入力欄・要約・文字数へ結びます。

Ada、TypeScript、空白、空値、Reactとやり直しを使い、2consumerの一致を確かめます。全ComponentのContext化を勧める課題ではありません。どこから何を渡すかが明瞭なら、Propsを使う判断も保ちます。
