consumerは、提供された値を使う子Componentです。useContextは同じContextの最も近いProviderの値を読みます。この課題ではNameFieldとNameSummaryが1つのProviderを共有します。

```tsx
const provided = useContext(NameContext);
if (provided === null) return <p>Providerが必要です</p>;
```

Providerがない場合のContextの既定値はnullです。この課題のProviderは最初から値のobjectを提供します。先に確認し、その後のarrow handlerから親の更新callbackを呼びます。子の独立Stateや別Contextを作ると同じ値への接続を失います。

:::practice
prompt: 片方だけ別Contextを読むと、同じ値を共有できますか。
expectedAction: 提供元と読取先が同じContextである必要を説明する
estimatedMinutes: 1
:::
