名前と送信した事実はStateに持ち、文字数・不足かどうか・案内はそのStateから計算します。次の演習では、この経路を自分で書きます。型と画面の枠は配布されています。

先に「空値の送信→空白の入力→有効な名前の送信→やり直し」で何が残り、何が変わるか予測しましょう。書く場所だけを示すHintから、必要なときに支援を増やせます。

:::practice
prompt: 有効な名前を送信した後、入力を変えたら案内を何に戻しますか。
expectedAction: 入力でattemptedをfalseに戻し、案内をStateから入力中と計算すると説明する
estimatedMinutes: 1
:::
