## 入力・検証・送信を自分で組み立てる

前の課題では送信の取消を1箇所だけ直しました。ここでは処理は未実装です。画面の枠はありますが、Stateと操作の経路を書いてから型と動作を確認してください。開始時の診断は、その未実装を知らせています。

components.tsxのAppを作ります。useStateとFormState・InputChangeEvent・FormSubmitEventはimport済みです。main.tsx・types.ts・index.htmlは配布済みのまま使います。1つのStateと入力・送信・やり直しの3つのhandlerは同じApp内に置きます。変数名は別名でも構いません。この課題はこの部品内の経路を組み立てる範囲です。

- FormStateのnameは空文字列、attemptedはfalseで開始し、1つのStateとして持ちます。入力欄のvalueと文字数はそのStateから表示します。
- changeでその場のcurrentTarget.valueを読み、nameを更新しattemptedをfalseに戻します。文字列だけを次のStateへ渡します。
- submitで既定の送信を取り消し、名前を保ったままattemptedをtrueにします。やり直しでは両方を初期値へ戻します。
- 空文字列または空白だけなら名前が不足しています。案内は入力中なら「入力中」、送信後は不足なら「名前を入力してください」、それ以外なら「送信を受け付けました」です。案内や不足かどうかは別Stateへ保存せず、その場で計算します。
- inputのaria-invalidは送信済みで名前が不足するときだけtrueにします。これは入力に誤りがあることを読み上げ機能へ伝える属性です。label・各id・案内の文言は枠のまま使います。

最初に、空値を送信した後・空白を入力した後・有効な名前を送信した後のStateと案内を予測します。完成後は空値→空白→Ada→TypeScriptと入力し、間に送信を挟み、最後にやり直します。一度の正しい表示に加えて、続けて操作した表示を確かめましょう。
