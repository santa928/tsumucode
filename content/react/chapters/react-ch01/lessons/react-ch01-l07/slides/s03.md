演習ではAppのNameSummaryへ渡す固定文字列を修正します。入力欄と要約の値を同じ親Stateへ結びます。

Ada、TypeScript、空白、空値、Reactで要約と文字数を予測して確かめます。やり直しも親Stateだけを変えれば両兄弟へ反映できます。Hintは修正位置から値の経路へ順に確認できます。

:::practice
prompt: 文字数を3に固定しても、Adaでは正しく見えます。何を追加で確認しますか。
expectedAction: 異なる長さ、空値とやり直しで派生値と同Stateの関係を確認する
estimatedMinutes: 1
:::
