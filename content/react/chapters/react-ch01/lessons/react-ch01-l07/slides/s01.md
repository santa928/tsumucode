lifting state upは、同じ値を使うComponentの共通の親へStateを置くことです。子ごとに独立したStateを持つと、片方の入力で他方は更新されません。

```tsx
<NameField value={name} onNameChange={setName} />
<NameSummary value={name} />
```

Appが1つのStateを持ち、兄弟へ同じvalueを渡します。子の名前やPropsの受取名が違っても、同じ値への経路は変わりません。
