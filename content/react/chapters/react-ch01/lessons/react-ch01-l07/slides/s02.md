callbackは子から呼ぶ関数のPropsです。onNameChangeは独自Propsで、ReactのonChangeとは別です。子が入力文字列を読み、親の更新関数へ渡します。

```tsx
onNameChange(event.currentTarget.value);
<p id="length">{props.value.length}</p>;
```

1行目は入力handler、2行目は要約の描画です。文字数はvalueから導出します。Effectは描画後に外部システムへ同期する仕組みで、同じ値のコピーを同期するためには不要です。今回は使いません。
