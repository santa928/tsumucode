Refは、再描画を起こさずに参照を保つ入れ物です。useRefは同じRefを次の描画でも返します。inputのrefに渡すと、DOMが表示された後にcurrentへ入力要素が入ります。最初や取り外した後はnullです。

```tsx
const inputRef = useRef<HTMLInputElement>(null);
<input ref={inputRef} />;
```

HTMLInputElementは入力要素の型です。表示用の名前は、前単元と同じStateで保持します。
