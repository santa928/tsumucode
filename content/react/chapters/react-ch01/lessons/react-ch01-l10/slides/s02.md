focusは入力へフォーカスを移すDOMの操作です。描画中にRefを読み書きせず、ボタンのEventから呼びます。?.は左がnullなら呼び出さない書き方です。

```tsx
function focusInput() {
  inputRef.current?.focus();
}
```

Refは入力への参照、Stateは入力した名前と文字数の表示を担当します。Refを表示用のStateの代わりにしません。
