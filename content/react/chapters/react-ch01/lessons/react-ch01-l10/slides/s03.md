演習はcomponents.tsxのfocusInputだけを修正します。空のhandlerでは、入力へ移るボタンを押しても入力へフォーカスが移りません。

ボタンをKeyboardでも操作し、Ada・TypeScript・空白・空値の要約と文字数を確かめます。表示値はStateから導き、Refから別のDOM属性やdocumentを操作しません。
