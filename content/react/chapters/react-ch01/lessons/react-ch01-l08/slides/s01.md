reducerは、現在のStateとactionを受け取って次のStateを返す関数です。actionは「何が起きたか」を示すデータです。dispatchはそのactionをReactへ渡す更新の入口です。

```tsx
dispatch({ type: 'nameChanged', nextName: next });
dispatch({ type: 'submitted' });
```

このFormのStateは引き続き親が所有します。用意済みのuseReducerは、受け取ったactionをreducerへ渡して次の表示につなぎます。
