純粋なreducerは同じStateとactionから同じ次Stateを返します。Stateを書き換えるmutation（元の値への変更）や、通信・ログ出力などの副作用を含めません。

```ts
return { ...state, attempted: true };
```

spreadは元Stateの項目を新しいobjectへコピーします。入力actionでは新しい名前を受け取り、送信では現在の名前を保ち、やり直しでは初期値へ戻します。
