演習ではBに異なる値を用意してから切り替えます。新しい入力通知を待たず、Bの現在値が表示されるか確認します。旧Aへその後に入力しても、Bの表示は変わりません。

非表示中は購読中の数が0で、入力通知も増えません。値を変えてから再表示し、現在値と購読1を確かめます。ここでの後着通知は、解除後の旧DOMへ発火したEventです。通信応答や待機中callbackの検証ではありません。

:::practice
prompt: 依存配列が空ならBへ切り替えた直後の表示はどうなりますか。
expectedAction: Effectが再setupされず古いAの値を残すと予測する
estimatedMinutes: 1
:::
