cleanupはEffectが返す後片付けの関数です。target変更では、古い値のcleanup後に新しいsetupをします。表示開始をmount、取り外すことをunmountといい、unmountでもcleanupします。

```tsx
const stop = subscribe(target, setValue);
return stop;
```

用意済みsubscribeは対象の現在値を渡し、入力Eventを受け取る関数（listener）を外すstopを返します。return stop()は今すぐ解除するので別です。開発時の再setupにも備え、開始と解除を対にします。
