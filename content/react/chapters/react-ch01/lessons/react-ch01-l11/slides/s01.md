Effectは、Componentの外の仕組みと表示を同期する処理です。この課題はReactの外にあるDOM入力を購読します。購読は、入力Eventを受け取る登録です。useEffectは表示への反映後に、同期を始める処理（setup）を行います。

```tsx
useEffect(() => {
  return subscribe(target, setValue);
}, [target]);
```

依存配列にはEffectで使うtargetを入れます。文字数はvalue.lengthから計算できるため、Effectで別Stateへコピーする必要がありません。
