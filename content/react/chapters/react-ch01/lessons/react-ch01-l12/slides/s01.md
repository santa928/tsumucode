Custom Hookは、別のHookを使う処理をまとめたuseで始まる関数です。ここではState・購読・cleanupをuseSourceValueへ移し、Componentは返された値を描画します。

```tsx
const value = useSourceValue(target);
return <p>{value}</p>;
```

通常の補助関数と区別し、HookはComponentやCustom Hookの最上位から呼びます。必要なtargetを受け取り、同期したStateを返す責務に絞ります。
