Custom Hookが共有するのは処理です。同じHookを2回呼んでも、内部のStateはそれぞれの呼出しに属します。入力AとBの値は、別のtargetで独立して更新されます。

同じ外部入力を2つのHookで購読すれば同じ通知を受けますが、それはHookがStateを共有した証拠ではありません。共通のStateを共有する時は親やContextを選びます。文字数は返されたvalueから直接計算します。
