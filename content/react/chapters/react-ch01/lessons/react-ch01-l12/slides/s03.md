演習はsourceHook.tsの返す値を修正します。購読とcleanupが正しくても、固定の空文字を返せば呼出し元は入力した値を表示できません。

Aだけを更新し、Aを非表示にした間はBだけの購読1になります。Aの値を変え、Bも別に更新してからAを再表示します。Hookが現在値を読み直し、両方の表示が独立していることを確かめます。
