Event handlerはクリック時に動く関数です。Stateは描画をまたいでReactが覚える値。useStateはStateとsetter（Stateを更新する関数）を返すHook（Reactの機能を使う関数）です。

```tsx
const [count, setCount] = useState(0);
<button onClick={() => setCount(count + 1)}>増やす</button>
<p>{count}</p>
```

setterを呼ぶと次の描画へ反映します。onClickには呼出し結果ではなく関数を渡します。
