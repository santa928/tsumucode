通常のクリック2回と、1クリック内の更新2回を分けて予測しましょう。

演習ではtwiceだけを修正し、通常2回の後に「2増やす」で4へ進むか確かめます。Stateを表示する位置も追い、型成功だけで完了としません。

:::practice
prompt: 数字の表示だけを4に固定すると、なぜ解決しませんか。
expectedAction: クリックに応じて同じStateが変わることを確かめられないからと説明する
