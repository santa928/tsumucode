Stateはその描画の値です。同じEvent内でcount + 1を2回渡しても、同じ次の値への置換になります。setterへ渡すupdater（次の値を計算する純粋な関数）なら前の更新結果を受け取れます。

```tsx
setCount((current) => current + 1);
setCount((current) => current + 1);
```

2なら3、続いて4を返します。updaterは純粋に次の値を返し、中で別の更新や通信をしません。HookはComponent先頭で使います。

![更新関数が2→3→4を計算](asset:react-ch01-l04-s02-reading-flow)
