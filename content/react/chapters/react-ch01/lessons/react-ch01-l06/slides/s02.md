formのonSubmitは送信時のhandlerです。FormSubmitEventは用意済みの送信Event型です。既定ではページを送信するため、ここではEventを明示的に取り消します。

```tsx
event.preventDefault();
setForm((current) => ({ ...current, attempted: true }));
```

attemptedはnameのコピーではなく、操作の事実です。画面ではnameとattemptedから結果を導きます。送信ボタンと入力欄のEnterのどちらでも同じonSubmitが動きます。

:::practice
prompt: 取消だけを忘れ、attemptedを更新すると何が不足しますか。
expectedAction: Stateの更新だけでは既定のページ送信を取り消せないと説明する
estimatedMinutes: 1
:::
