controlled inputはvalueをStateから渡し、onChangeでその値を更新する入力欄です。用意済みFormStateはname（文字列）とattempted（送信を試したか）を持ちます。

```tsx
<label htmlFor="name">名前</label>
<input id="name" value={form.name} onChange={change} />
```

labelとidを合わせます。InputChangeEventは用意済みの入力Event型です。handlerの同期処理で読んだ文字列を保存し、EventやcurrentTargetをupdaterへ持ち越しません。

![onChangeが次の値を受け取る](asset:react-ch01-l06-s01-reading-flow)
