派生値は今あるStateから計算する値です。missing（空値/空白だけか）、message、文字数を別Stateへ保存しません。

```tsx
const missing = form.name.trim().length === 0;
const next = event.currentTarget.value;
setForm((current) => ({ ...current, name: next, attempted: false }));
```

1行目は描画、後2行は入力handlerの例です。trimは前後の空白を除いた新文字列を返します。文字数表示は元のname.lengthです。入力で送信前へ戻し、送信後はaria-invalid（入力の不正を支援技術へ伝える属性）と案内を同じ条件から描画します。

:::practice

expectedAction: 元文字数は3、trim後は空なので送信時はエラーと予測する

:::
