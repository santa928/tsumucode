immutable updateは元の値を直接変えず、新しい値へ置き換える更新です。Stateの配列にpushやreverseを直接使いません。

```tsx
setTopics((current) => current.filter((item) => item.id !== 'html'));
setTopics((current) => current.toReversed());
```

filterは条件を満たす項目の新配列、toReversedは逆順の新配列を返します。残す項目のIDは保ちます。
