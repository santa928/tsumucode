Listは一覧です。mapで項目をJSXへ変えるとき、KeyはReactに項目の同一性を伝えます。配列内で一意で、操作後も同じ項目には同じKeyを使います。

```tsx
topics.map((item) => <li key={item.id}>{item.label}</li>);
```

indexは位置です。削除・並べ替えで別の項目を指すため、この変化する一覧のKeyには使いません。Keyは通常のPropsとして渡されません。
