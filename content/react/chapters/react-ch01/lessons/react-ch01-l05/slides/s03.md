spreadは配列の項目を新しい配列へ展開します。用意済みのTopicはreadonlyなidとlabelを持ちます。

```tsx
setTopics((current) => [...current.filter((item) => item.id !== 'js'), { id: 'js', label: 'JS' }]);
```

同じJSを再追加してもIDを重複させない例です。IDはクリックのたびに作り直す位置ではなく、項目を識別する値です。
