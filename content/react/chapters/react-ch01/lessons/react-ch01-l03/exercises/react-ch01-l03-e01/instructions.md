## childrenで表示を組み合わせる

枠のComponentが受け取ったchildrenを表示し、呼び出し元で組み合わせたJSXを枠の中へ届けられる。

編集するのはcomponents.tsxです。起動処理・Propsの型・HTMLは用意済みで、変更しません。

LearningPanelのタグの内側に渡しているJSXを読みます。枠で固定の中身を表示する代わりに、受け取ったchildrenを表示してください。

実行すると「学習テーマ」と、HTML／内容を組み立てる、CSS／見た目を整えるの2組が表示されます。2つのカードは枠のsectionの内側に配置します。型の成功と実際の表示を別々に確認し、判定します。

内部Component名・引数名・補助Componentの分け方は自由です。入口のexport Appは残します。同じComponentへ異なるPropsを渡し、受け取った値から表示を作ることも確認するため、完成表示を固定文で写すだけでは達成しません。childrenはこの課題では1つのJSXを受け取り1回表示します。State・イベント・Effectは使いません。
