受け取ったchildrenは、表示する位置へ波括弧で置きます。PanelPropsは今回の1つのJSXを受け取る用意済みの型で、一般のReactで渡せるすべての値を表す型ではありません。

```tsx
<section>
  <h1>学習テーマ</h1>
  {children}
</section>
```

引数で受け取るだけでは表示されません。枠はchildrenを表示し、具体的なカードや渡す値は呼び出し元が決めます。

![childrenとして受け取る](asset:react-ch01-l03-s02-reading-flow)
