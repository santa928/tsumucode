CompositionはComponentを組み合わせて表示を作ることです。呼び出し元が枠のタグの内側へJSXを置くと、枠はchildrenというPropsで受け取ります。

```tsx
<LearningPanel>
  <TopicCard title="HTML" summary="内容を組み立てる" />
</LearningPanel>
```

この課題のchildrenは1つのJSXです。2つのカードを渡すときはdivでまとめます。枠の関数は、中身のComponent名を知る必要がありません。
