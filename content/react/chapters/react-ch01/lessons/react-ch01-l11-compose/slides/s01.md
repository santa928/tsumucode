外部入力の購読はEffectで始め、同じ購読の解除をcleanupへ返します。依存するtargetが変わると、前の解除から次のsetupへ進みます。表示に必要な文字数はStateから直接計算します。

次の演習では、型・購読の関数・表示の枠だけを受け取り、StateとEffectを自分で組み立てます。切替と非表示の後も、古い入力の通知が残らないか予測してから確認しましょう。
