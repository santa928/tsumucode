## 購読の開始・解除・依存値を自分で組み立てる

前の課題では依存配列を1箇所だけ直しました。ここでは処理は未実装です。StateとEffectを書いてから型と動作を確認してください。開始時の診断は、その未実装を知らせています。

components.tsxのSourcePanelを作ります。useState・useEffect・subscribeとPropsの型はimport済みです。外部入力、切替ボタン、起動処理は配布済みです。main.tsx・source.ts・types.ts・index.htmlは変更しません。Stateと解除関数の変数名は自分で決められます。

- 空文字列で始まるStateを1つ持ち、受け取った外部入力の値を表示します。文字数はStateの値からその場で計算し、別StateやEffectで保存しません。
- Stateの次にEffectを1つ書きます。setupでsubscribeへ受け取ったtargetとStateのsetterを渡します。subscribeは現在値をすぐsetterへ渡し、その後の入力も通知します。
- subscribeが返す関数は、その呼び出しで開始した購読を解除します。同じ関数をEffectのcleanupとして返し、setup中には実行しません。
- 依存配列は[target]にします。targetが変わると前の購読を解除し、新しい対象を購読します。表示終了でも購読を解除します。
- 値の表示はid="observed"、文字数の表示はid="length"のままにします。見た目の調整は必要ありません。

まず「Bに値を用意→Bへ切替→旧Aへ入力→非表示→Bへ入力→再表示」の表示値と購読数を予測します。完成後に操作して、切替直後にBの現在値が表示され、旧Aで通知数が増えないことを確認します。非表示中は購読0で通知が増えず、再表示後は現在値と購読1になります。ここで扱うのはDOM入力の購読で、通信応答の競合ではありません。

必要なときだけHintを開けます。判定はこの課題のSourceと連続操作を確認するもので、理解や実務能力の保証ではありません。
