## 同じComponentへ異なるPropsを渡す

呼び出し元と受け取る側を区別し、同じComponentへ渡した異なるPropsがそれぞれの表示になるよう修正できる。

編集するのはcomponents.tsxです。起動処理・Propsの型・HTMLは用意済みで、変更しません。

まず2つのTopicCard呼び出しから見出しと説明を予測します。2つ目のtitleを文字列CSSへ直し、説明を固定文ではなく受け取ったsummaryから表示してください。

実行すると「学習テーマ」と、HTML／内容を組み立てる、CSS／見た目を整えるの2組が表示されます。型の成功と実際の表示を別々に確認し、判定します。

内部Component名・引数名・補助Componentの分け方は自由です。入口のexport Appは残します。同じComponentへ異なるPropsを渡し、受け取った値から表示を作ることも確認するため、完成表示を固定文で写すだけでは達成しません。childrenはこの課題では1つのJSXを受け取り1回表示します。State・イベント・Effectは使いません。
