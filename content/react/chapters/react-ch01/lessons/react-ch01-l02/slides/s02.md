呼び出し元がtitleとsummaryを渡し、受け取る側がPropsを表示します。関数の引数でtitleとsummaryを個別に取り出す書き方は、オブジェクトから同じ名前の値を取り出す分割代入です。CardPropsの型は用意済みです。

```tsx
<section>
  <h2>{title}</h2>
  <p>{summary}</p>
</section>
```

文字列は引用符、値の表示は波括弧を使います。pを固定文にすると、渡したsummaryを変えてもその説明は表示されません。Propsは受け取った側で書き換えません。
