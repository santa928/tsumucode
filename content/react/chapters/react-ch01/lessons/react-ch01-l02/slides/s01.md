同じ形の表示をComponentへまとめると、構造を1か所で読み、呼び出し元で値を変えられます。Componentの定義をタグの内側へ書くのではなく、別の関数として用意します。

```tsx
<TopicCard title="HTML" summary="内容を組み立てる" />
<TopicCard title="CSS" summary="見た目を整える" />
```

2つとも同じTopicCardを使います。違うのはPropsの値です。画面は2つ表示されても、関数の定義は1つで足ります。

![同じTopicCardを2回呼ぶ](asset:react-ch01-l02-s01-reading-flow)
