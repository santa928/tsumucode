## クイズStateを純粋な関数で更新する

Guided: Webの2問を型付きComponentと純粋State関数で段階制作するクイズです。

- 名前は入力した値を表示し、再挑戦でも保ちます。
- 問題文と2つの選択肢をPropsから表示し、選択肢の文字列をKeyと親Callbackへ渡します。各問内で文字列は一意です。
- 正解時だけ1点を加え、正誤にかかわらず1回の回答で回答済みになります。
- 回答済みの重複得点と未回答の次問を防ぎ、2問の後に結果を表示します。再挑戦は0点・最初の問題・未回答へ戻します。
- 工程1は一覧とCallback、工程2は得点と回答済みを完成します。同じ原文を保存し、工程間で引き継ぎます。

固定データはページの骨組み（HTML/CSS、正解HTML）、見た目（JavaScript/CSS、正解CSS）です。通信は使いません。名前の入力、選択肢、次問、再挑戦はnative input/buttonでKeyboard操作できます。
