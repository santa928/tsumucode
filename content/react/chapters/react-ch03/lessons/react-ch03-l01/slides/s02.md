1問目を正解して得点1にした後、2問目で誤答しても得点1を保ちます。同じ問題を正解すると2になり、重複回答では2のままです。誤答時にscoreを0へ戻すのは、累積得点を保つ要求と違います。

:::practice
prompt: 1→誤答→正解→重複回答の得点を順に予測してください。
expectedAction: 1、1、2、2と予測し正誤と前の得点をつなぐ
estimatedMinutes: 1
:::
