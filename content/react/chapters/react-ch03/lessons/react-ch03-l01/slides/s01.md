Capstoneは別のWorkspaceの練習クイズです。Guidedと違い、誤答では同じ問題に再回答できます。正解のときだけ加点し回答済みにします。共通のCardは再利用できますが、Guidedのanswerをそのまま使うと誤答をロックします。

:::practice
prompt: Guidedの完成コードを移しただけで、どの条件が満たせませんか。
expectedAction: 誤答後の再回答と次問の制御がBriefと違うと説明する
estimatedMinutes: 1
:::
