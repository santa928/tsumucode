## 誤答から再回答できる練習クイズ

独立した2FileをBriefに合わせ、正解時だけ加点・回答済みにして、誤答では前の得点と問題を保つ。先に操作後の表示と得点を予測してください。編集できるのはQuestionCard.tsxとquizState.tsです。今回の主な修正先はquizState.tsです。main.tsx・types.ts・data.ts・index.htmlは固定の足場です。

別Briefから必要な更新を選び、誤答でも累積得点を保って同じ問題へ再回答し、独立した作品を完成する。

Guidedとは別の保存・進捗・Resetです。元の作品は保護します。3段階HintとChecklistで修正位置・値の由来・実操作を確かめます。正解例は制作を終えた後の比較に使い、別Briefとの差を説明してください。
