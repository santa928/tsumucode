# 変数の値と計算の結果を表示する

実行前に、次のコードが何をどの順で表示するか予測してください。

```python
count = 3
print("count")
print(count + 2)
```

最初の`print`は、引用符で囲まれた文字列`count`を表示します。次の`print`は、変数`count`の値`3`に`2`を足した結果を表示します。予測した2行と実際の出力を比べ、違いがあれば理由を説明してください。

演習では、両方の`print`で同じ変数を使い、数値の`3`と`5`をこの順で表示します。答えを直接表示するコードでは、変数を参照して計算したかを確かめられません。

最後に、演習で修正したコードの代入値を`3`から`4`へ変えた場合の2つの表示を予測し、理由を説明してください。
