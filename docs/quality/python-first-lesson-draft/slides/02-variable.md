# 値に名前を付ける

変数は、値を名前で参照するために使います。`=`は、右側の値を左側の名前へ代入する記号です。

```python
count = 3
print(count)
```

```text
3
```

最初の行で、数値`3`に`count`という名前を付けます。次の行の`print(count)`は、その名前が参照する値を表示します。`count`という名前そのものを表示しているわけではありません。

変数の名前は自分で選べます。例えば、`amount = 3`と書いたら、表示するときも`print(amount)`と同じ名前を使います。このLessonでは数字の`3`だけを変数へ代入し、再代入や入力待ちは後のLessonで扱います。

まだ代入していない名前を使うと、`NameError`というコードのエラーになります。Pythonが名前の値を見つけられなかった、という意味です。
