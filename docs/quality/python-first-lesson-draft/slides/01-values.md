# 数値と文字列を区別する

Pythonは、数値や文字列などの値を扱う言語です。この最初のLessonでは、数値、変数、表示だけを使います。

`3`は数値、`"3"`は文字列です。文字列は引用符で囲みます。`print(...)`は、括弧の中の値を表示します。

```python
print(3)
print("3")
```

```text
3
3
```

2つの表示は同じに見えますが、渡した値の種類は異なります。表示された文字だけでは、数値か文字列かは分かりません。

数値の`3 + 2`は、足し算の結果の`5`です。文字列の`"3" + "2"`は、文字をつなげた`"32"`です。同じ見た目の出力だけで、計算の意味まで同じとは判断できません。
