# 問題データをQuestionの形に合わせる

この原稿は作者用で、通常の編集画面や自動判定にはまだ接続していません。

問題は「HTMLが受け持つものは？」、選択肢は「内容」「見た目」、正答は最初の「内容」です。Starterでは正答位置を文字列にしています。Questionの型を読み、正答位置を数値へ直してください。

練習の条件:

- interfaceで問題文をstring、選択肢をstring[]、正答位置をnumberとして表し、問題オブジェクトへその形を注釈する。
- 問題文と2つの選択肢を保ち、正答位置を数値0にする。表示用の式はその位置を使って配列から選ぶ。
- 型の確認をなくしたり、型の確認を迂回したりせず、型誤りの値を直す。
- 形の名前を変える場合は、注釈側もそろえてよい。ここでinterfaceを練習するための条件は、ほかのTypeScriptの書き方が一般に不正という意味ではない。

3段階Hint:

1. Questionの`correctIndex`の型と、オブジェクトで渡した値の型を比べる。
2. `'0'`は文字列。正答位置だけを数値にし、問題文と選択肢は文字列のままにする。
3. `correctIndex: 0`に直す。interfaceと`question: Question`の注釈を残す。

予測する結果は「内容」。ただし同じ表示になるだけでは練習条件を満たしたとはいえません。型が通っても位置10を入れればこの配列の範囲外で、型が配列の範囲を保証するわけではありません。
