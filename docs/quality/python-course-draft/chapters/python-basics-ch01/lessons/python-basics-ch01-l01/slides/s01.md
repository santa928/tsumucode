Pythonは数値や文字列などの値を扱う言語です。3は数値、"3"は文字列です。文字列は引用符で囲みます。print(...)は括弧の中の値を表示します。

```python
print(3)
print("3")
```

![数値3と文字列3は種類が違いますが、printではどちらも3と表示されます。](asset:python-s01-output)

上のコードは3を2行表示します。同じ表示でも値の種類は異なり、出力だけでは区別できません。

数値の3 + 2は足し算の5、文字列の"3" + "2"は文字をつなげた"32"です。次は数値に名前を付けます。
