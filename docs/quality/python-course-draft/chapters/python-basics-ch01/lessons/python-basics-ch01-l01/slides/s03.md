実行前に、次のコードが何をどの順で表示するか予測してください。

```python
count = 3
print("count")
print(count + 2)
```

最初のprintは、引用符で囲まれた文字列countを表示します。次のprintは、変数countの値3に2を足した結果を表示します。予測した2行と実際の出力を比べ、違いがあれば理由を説明してください。

演習では、両方のprintで同じ変数を使い、数値の3と5をこの順で表示します。答えを直接表示するコードでは、変数を参照して計算したかを確かめられません。

最後に、演習で修正したコードの代入値を3から4へ変えた場合の2つの表示を予測し、理由を説明してください。

:::prediction
prompt: "初期コードは何をどの順で表示しますか。"
answer: "count、5の順で2行を表示します。"
explanation: "引用符の中は文字列です。次の行は数値3に2を足します。"
