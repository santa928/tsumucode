# Question/interface初回演習の型条件

Issue #110。`typescript-ch02-l01-e01`だけの有限な`question-interface-v1`を既存Compiler Workerへ接続する。PR #80の作者用固定名観察スクリプトを製品採点器へ流用しない。型の形、元TSの練習条件、実行結果は別々に確認する。

## この演習で確認するもの

単一`main.ts`のトップレベルに、1つのinterface、型注釈を付けた1つのオブジェクト、最後の`console.log`を置く。3つの必須項目は`prompt: string`、`choices: string[]`、`correctIndex: number`。問題文「HTMLが受け持つものは？」と選択肢「内容」「見た目」を保持し、そのオブジェクトの`choices.at(correctIndex)`を出力する。

型名・変数名の改名、項目順、引用符付きの項目名、文字列の引用符、`Array<string>`、数値だけの位置の計算、プロパティのドット/文字列添字表記を許す。位置の式は有限ASTで読み、非負の安全な整数に限定する。上限を配列長へ結び付けず、型条件と範囲の確認を分ける。名前の単純一致だけで型条件を判定せず、宣言の対応と有限構文を原文ASTで確かめる。追加宣言・宣言merging・継承・関数・複数ファイル・更新処理はこの初回演習の範囲外で、汎用TypeScriptの不正とは説明しない。

作者原稿の動的な添字アクセスは既存Previewの安全制約により実行できないため、通常教材では既存に許可された`.at()`へ適応する。Previewの汎用computed access制約は緩めない。学習目標はinterfaceの必須項目と型・値の境界であり、配列アクセス方式の習得へ置き換えない。`.at()`は4枚目で説明する。一般の`.at()`は負数や小数も受け取るが、このクイズの正答位置は0から数える整数として扱う。負数や小数で同じ表示になる入力を元TSの練習条件で拒否し、汎用JavaScriptの不正とは扱わない。

type aliasや型推論も一般に有効だが、この演習はinterface注釈の練習を要求する。optional・union・anyへの型の拡大、assertion・non-null assertion、診断抑制、参照directiveは学習条件を満たさない。これらの構文を事前知識にはしない。公開説明は「型の確認をなくす・弱める・無視する・強制する書き方」と練習範囲を案内する。

## 型と動作のAND

通常の型検査・実行に加え、対応範囲を通った元TSのコピーだけに信頼側のexportを付ける。非emitの正例2件と負例6件で、同じオブジェクト型が別の値を受理し、3項目それぞれの欠落と誤型を拒否することを確かめる。負例成功には、検査専用fileの診断件数・code・line・columnの一致を要求する。無関係な診断を成功に数えず、コピー・AST・probeの診断・生成物はRunner/保存/画面へ渡さない。

正例に空文字・空配列・位置10を含め、形の型検査が内容や配列範囲を保証しないことを保持する。元TSの位置10や位置1は型条件を通るが、実Consoleの「内容」が1回という必須動作条件を通らない。固定表示や別の問題文は、同じ出力でも元TSの練習条件を通らない。型成功だけでは合格にしない。

## 世代・保存・停止

Compiler Clientの既存request/session/revision照合、入力コピー、置換時の中止、10秒期限とWorker破棄を使う。Question専用guardは有限のboolean factだけを受け取り、他profile・余分なpayload・成立しない正負検査を拒否する。

Validatorは既存の元TS/HTMLとruntime/session/revisionを束ねたSHA256証拠を照合し、その原文を同世代で再型検査する。古い実行に新しいコードを組み合わせた採点は環境失敗として閉じる。型失敗は未実行・未採点、実行失敗はcode-error、形または出力の不足はincomplete。環境失敗を学習者の不正解へ置き換えない。型消去後のJavaScript ASTで型の習得を判定しない。

元TS・履歴・passing snapshotの保存形式は変えない。既存のRuntime隔離・通信/時間上限、Compiler遅延読込、16file/131072文字の通常入力上限を維持する。この小演習の学習検査は8192文字・2048 AST node・深さ64以内に限定し、超過や検査基盤の失敗はsystem-errorにする。性能の達成値を新たに保証するものではない。
