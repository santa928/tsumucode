# 初学者ペルソナ試用後の説明・持ち出し導線

2026-10-02、異なる3ペルソナの独立エージェントが実画面を操作した結果のうち、説明への戻り方と書き出し内容の分かりにくさを小さな変更で改善する。AIの試用は人の理解・実機・正式公開受け入れの証拠には含めない。

## 要件台帳

| ID          | 区分 | 受け入れ条件                                                                                                                                                                 |
| ----------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| REQ-PER-001 | 追加 | スライドがあるレッスンでは、判定前から演習の「説明を見直す」を利用できる。                                                                                                   |
| REQ-PER-002 | 追加 | 直前の説明を開き、同じレッスン内の他の説明を選べる。教材が参照する過去レッスンの説明も既存の判定導線から開ける。                                                             |
| REQ-PER-003 | 維持 | 説明の開閉・選択は演習のコード、判定履歴、Previewのiframeと実行revisionを変更しない。直接開いた場合は見直しボタンへ、判定結果から開いた場合は既存どおりEditorへFocusを戻す。 |
| REQ-PER-004 | 追加 | ホームの書き出し操作前に、全コースの進捗と編集中のコードを含むJSONであると分かる。読み込みラベルは専門用語のBundleを使わない。                                               |
| REQ-PER-005 | 維持 | Export/Importの形式、検証、バックアップ、保存・隔離処理は既存契約を保つ。                                                                                                    |
| REQ-PER-006 | 維持 | 既存の通常CI、HomeのJavaScript予算、教材レビュー・公開Gateを維持する。今回の変更だけでβ再公開や人の受け入れ完了とはしない。                                                  |
| REQ-PER-007 | 追加 | 長いコード例のある説明でも、説明の選択欄はDrawer本文の左右padding内に収まり、選択操作が見える。                                                                              |

この変更は初版であり、既存要件の保留・削除はない。以下は今回の非対象で、別の改善として追跡する。

- ホームから中断した演習そのものへ再開する導線。
- 背景だけ誤った場合の第一段階ヒント、Promiseのチェック名・次の操作の案内。
- Previewの読みやすい表示倍率と、復元済み状態の案内。
- JavaScript全体のGuided/Capstone、TypeScript・React・Next.jsの正式受け入れ。

## リスクと検証

説明の往復でEditorやPreviewが作り直されるリスクは、実際のCodeMirror編集を含むComponent回帰テストと実ブラウザ操作で確認する。既存の判定由来の復帰Focusも維持する。長いボタン文言と追加操作の収まりは代表的なデスクトップと狭い画面で確認する。説明Drawerの列は最小幅0に固定し、長いコード例が新しい選択欄を画面外へ押し広げる回帰をPromiseの実ブラウザテストで検出する。

Export/Importはラベルと案内のみ変更し、既存の転送テストを新しいラベルに同期する。新規依存・保存schema・教材ソース・Runner・公開先は変更しない。性能目標は既存のHome予算とLearning chunk検査を保持し、今回の変更が触らない全ブラウザ・性能・Lighthouse・公開Gateは公開前または関連入力が変わった際に実施する。
