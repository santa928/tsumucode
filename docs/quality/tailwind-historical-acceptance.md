# Tailwind旧受入の限定移行

2026-11-03の依頼に基づき、後から追加された人数要件のために旧5教材を最初から再検証せず、旧受入を実際の範囲で維持する。これは未公開だったTailwindを「公開済みのbaseline」と扱う操作ではない。通常の新教材・可視内容を変更した教材に求める独立3役の条件も変更しない。

## 固定する事実

`tailwind-historical-acceptance.json`は、旧候補`37e689387f75bc7060739369977e7b7b8df93700`の5教材だけを対象とする。内容レビュー5件、観測Source`e8a077994f5c4cba891e15141dddf5002b1fb7f0`の独立AI観測者**1名**、元のdist、原本照合と現行指紋への対応を保持する。観測者をnovice/recovery/makerの3名へ付け替えず、新しい役割承認件数も増やさない。

独立原本監査では私有ファイル参照54件・26ファイル、ZIP内6ファイルを照合し、不一致・欠落は0だった。過去生成物の10宣言は元bytesがなく未再計測であり、私有reportのhash一致を生成物自体の再計測と混同しない。5教材のGit treeと内容レビューは観測Source・旧候補・照合時のmain `16bbf554`で一致した。元のAI観測はL1〜L4の完了と、同じ担当の継続観測によるL5完了・5/5進捗・コース往復後の原文保持を含む。実人の理解や物理低端末の検証ではない。

履歴のhover、制作の幅/Tab、ZIP成否、JSON移行、reload/restart、L4の800px、過去生成物10宣言等の未確認はJSONに残す。現在の技術検証や後日の別AI観測が成功しても、旧観測者が当時確認したことには書き換えない。私有原本・学習者コード・DOM原文・画像は公開JSONへ含めない。

## 移行時の検査

- 移行receiptの固定digest、旧Source/tree、旧内容レビュー・品質記録の実Git bytes、5教材の指紋と観測Sourceの同一性を照合する。任意Course、任意Source、役割追加、未確認削除には広げない。
- 現候補の学習内容指紋が同じ教材だけを`historicallyAcceptedLessons`へ記録する。内容変更は対象教材の通常承認を必要とし、未変更の他教材は維持する。
- 明示的な承認撤回や既知findingは停止する。現在の内容レビューで拒否されたものも旧承認で覆わない。演習・導線・保存の差分は技術再検証として残す。
- stagingと最終qualificationの両方で同じSource内の固定receiptを照合する。移行が使われた資格は`historical`と表示し、元Source、receipt digest、AI観測者数1、未確認を別欄へ保存する。

## 公開に必要な条件

この移行だけでは公開しない。現在の同一run候補・全必須技術検証・現在main/親版/成果物照合・保護Environment・公開後の実操作と保存・SHA確認はそのまま必須である。権限、セキュリティ設定、公開許可や審査拒否の扱いは変更しない。

Tailwindを公開する変更では、HTML/CSS直後のrecommended登録と、未開始・未完了でも後続requiredへ進める導線を確認する。公開後の開始・再開・採点・保存・Export・別状態Import・recommended導線・持ち出しproduction buildを確認し、未確認や不確定な操作を成功にせず記録してから#131と#13を閉じる。
