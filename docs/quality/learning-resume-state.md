# 演習の保存と再開

通常演習では、選んだ工程と開いているファイルを下書きへ独立して保存します。工程を選ぶと対象ファイルも開きます。ファイルタブだけを切り替えた場合は工程を変えず、その組合せで再開します。工程やタブの操作でSource、採点履歴、過去の成功、実行revisionを変更しません。

旧下書きに工程位置がない場合や、工程が現在の演習に存在しない場合は、保存したファイルに対応する最初の工程を表示します。別の演習で共有しているworkspaceの工程位置は引き継ぎません。教材IDの移行では工程位置だけを落とし、Sourceや有効な履歴を保持します。「最初に戻す」はStarterと最初の工程・対象ファイルへ戻します。

保存予約時点から「保存中」と表示します。工程・タブ変更は既存の保存queueへ直ちに送り、永続保存が終わったら「保存済み」を表示します。「保存中」の間の強制再読込やブラウザー終了では、非同期保存の完了を保証できません。保存失敗は保存状態と既存の復旧案内で示します。

Course Mapは、現在の教材・Lesson・Exercise・workspaceが一致する下書きを読み、「現在のピース」「作業中」と再開リンクへ反映します。下書きだけが残る既存データや複数の作業中Lessonも対象です。Course Mapを読む操作で進捗を書き換えず、完了数や合格は保存済みのCourseProgressだけから求めます。

## JSONと版の互換性

現行schema 2の下書きへ任意の`activeStepId`を追加しています。既存v1/v2データを現行版で読み込むことと、工程位置に対応した現行版同士のJSON往復を対象とします。不正な補助位置だけでSource全体を隔離しません。

新しいJSONを、工程位置に未対応の旧版へ戻すことは保証しません。旧版のstrictな読込処理では、未知フィールドを含む下書き全体が隔離され、通常の再開対象から外れる場合があります。工程位置に対応した版で読み込み、元のJSONを保管してください。新旧版が混在する公開やrollbackには、互換readerの先行導入またはschema版更新などの別途判断が必要です。今回の変更は新規公開の許可ではありません。
